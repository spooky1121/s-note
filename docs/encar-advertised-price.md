# 엔카 광고가격 조회와 판매예정가 입력

차량 상세 상단의 Encar 버튼이나 저장된 광고 링크를 누르면 기존 차량번호·광고 상태 확인에 이어 같은 광고의 가격을 조회한다. 확인된 광고가와 한국 시간 기준 확인 시각을 표시하고 기존 차량 DB에 함께 저장한다. 상세창을 다시 열 때는 마지막 저장값을 표시하며, 새 가격 확인은 버튼·링크의 재조회로 진행한다.

## 사용 방법

1. 차량 상세에서 Encar 버튼을 누른다. 광고 주소를 직접 입력해 확인하는 기존 경로도 지원한다.
2. 가격이 확인되면 `엔카 광고가 …원`과 확인 시각이 나온다. 서버 저장을 확인한 뒤 판매예정가 반영 아이콘이 활성화된다.
3. 반영 아이콘을 누르면 해당 금액만 판매예정가 입력칸에 원 단위 콤마로 채운다. 다른 미저장 입력은 유지한다.
4. 기존 파란 저장 아이콘으로 차량 변경사항을 확정한다. 반영 안내에도 별도 저장이 필요하다고 표시한다. 가격 조회 자체가 기존 판매예정가를 자동 변경하지 않는다.

판매 완료 차량에는 반영 아이콘을 제공하지 않는다. 경리·권한 없는 사용자, 미확정 저장·충돌·저장 중인 화면에서도 가격 반영을 허용하지 않는다. 기존 판매 완료 광고 확인 버튼 숨김과 저장 링크 열람 정책은 유지한다.

## 공급자 설정과 가격

기존 Cloudflare Pages `s-note` Production의 암호화된 `ENCAR_API_KEY`를 사용한다. 분류 샘플 API와 같은 키이며 새 키나 웹호스팅은 필요하지 않다. 키 변경 시 배포에 반영해야 한다. 브라우저·장부·로그에 키를 기록하지 않는다.

공급자는 Encar.com 본사 공식 API가 아닌 `encar-api.com` 독립 서비스다. 고정된 `https://api.encar-api.com/api/car?id=…`에서 문서화된 `Id`와 `Price`만 사용한다. 원본 `Price`는 만원 단위이므로 정확히 10,000을 곱해 정수 원으로 변환한다. EUR 환산값·이전 가격·임의 HTML 숫자는 사용하지 않는다.

가격은 공식 엔카 페이지에서 차량번호·원 광고 ID·광고 중 상태를 확인한 광고에만 붙인다. 공급자 ID도 그 원 광고 ID와 같아야 하며, 응답에 차량번호·통화·판매/리스/렌트 상태가 있으면 추가 검사한다. 0원·상담·음수·소수 원·상한 초과·형식 불명 가격은 반영하지 않는다.

추가 가격 조회는 한 번에 최대 3개 광고, 공유 시간 예산 6초로 제한한다. 키 미등록·한도 초과·판매 종료·접속 오류·가격 불명일 때는 가격 확인 불가로 표시한다. 기존 검증된 광고 링크와 광고 열기는 계속 제공하며 과거 가격의 확인 시각만 새로 바꾸지 않는다.

공식 제공자 자료: [가격 필드](https://www.encar-api.com/docs/listing-fields), [조회와 인증](https://www.encar-api.com/docs).

## 저장과 권한

기존 `cars` JSON의 `encarLinks.listings`에 다음 선택 필드를 추가한다. `version:1` 광고 링크와 가격 필드가 없는 이전 자료를 계속 지원한다. 별도 표·RLS·인증 권한 변경은 없다.

- `priceWon`: 양의 정수 원(최대 1,000,000,000,000원), 확인 실패 시 null
- `priceCheckedAt`: 실제 가격 확인 ISO 시각, 확인 실패 시 null
- `priceSource`: `encar-api.com` 또는 검증된 출처, 확인 실패 시 null
- `priceStatus`: `verified` 또는 `unavailable`

메타데이터는 기존 소유자 범위와 장부 revision CAS로 저장한다. 중첩 `priceWon`은 기존 만원 저장 형식으로 재변환하지 않는다. 판매예정가는 기존 저장 아이콘의 검증·동시 수정 감지·금액 변환을 그대로 사용한다. 반영할 때 현재 계정·상사·차량·번호판·상세창 세션·광고 ID와 저장된 가격 레코드가 모두 일치해야 한다.

합성 계정·광고·API 응답으로 서버, 저장 경로, PC·모바일 화면을 검증한다. 실제 운영 키의 공급자 응답과 운영 계정의 가격 입력 시험은 이 검증과 구분한다. 세부 결과는 `docs/encar-price-verification.json`에 기록한다.
