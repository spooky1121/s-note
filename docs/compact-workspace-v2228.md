# 화면 밀도·통합검색·대시보드 펼침 (v2.228)

기준 main은 `afe29cf0166c4795ecf91b9868fca6799451ce1f`이다. 업무 데이터·권한·계산식과 문서 본문은 유지하며 화면 스타일과 요청한 탐색 동작을 보완한다.

- 화면 글씨를 대체로 1px 줄였다. 기존 화면 보정은 +2px에서 +1px로, 명시적 신규 UI와 고객·운영자·복구 화면은 정적 CSS로 조정한다. 모바일 텍스트 입력은 16px를 유지하고 문서 미리보기 본문의 기존 보정·인쇄 글꼴은 유지한다.
- 1440px 기준 메뉴 폭은 216→198.6px, 메인 로고는 148×40→134×36px 및 y20→12px이다. 1024px 아이콘 메뉴는 76→70px, 심볼은 38×40→34×36px이다. 그림 비율은 contain으로 보존한다.
- 계약서·인수증·견적서 하단 서비스 로고를 공식 이미지의 18×5mm 박스로 통일했다. 기존 서비스 로고 crop 규칙을 제거하고 상사별 로고·직인·서명 위치와 A4 양식·페이지 수는 유지한다.
- 상단 중앙 통합검색은 차량·고객·허용 메뉴를 함께 검색한다. 돋보기 또는 Enter 제출 때만 검색 자료를 읽으며 기존 4px 배경 흐림·닫기·모바일 뒤로가기 효과를 공유한다. 여러 검색어, 차량명·번호·VIN·차량 메모와 고객명·전화·주소·연결 차량을 지원한다.
- 검색 차량은 현재 검증된 본인/상사 자료만 포함하고, 공유 차량은 기존 incoming/read 흐름으로 권한을 새로 확인한다. 고객은 본인 소유 자료만 기존 읽기 경로로 조회하며 경리는 고객 조회를 실행하지 않는다. 금액·주민번호/암호문·계좌·계약 원문은 검색 필드/결과에 넘기지 않는다. 계정/상사 전환과 늦은 응답을 격리하고, 결과 선택 시 기존 상세·고객 목록 필터·메뉴 이동 경로로 다시 검증한다.
- 차량 목록 하단의 총 대수/현재·전체 페이지 요약만 제거하고 이전·다음·번호 이동은 유지한다. 고객 목록 요약은 그대로다.
- 대시보드 7개 지표는 총투자금이 위에 있는 카드 묶음으로 시작하고 클릭/Enter/Space 시 오른쪽으로 펼친다. 수익 정산은 제목만 표시하다 클릭하면 아래로 펼친다. 수익 정산 바로가기 화살표를 제거했다. 금액 잠금, 화면 크기에 따른 배치, 접힌 카드의 비활성화, 빠른 반전과 동작 줄이기를 유지한다.

애니메이션 방향은 사용자가 제공한 [카드 펼침 참고](https://codemyui.com/card-stack-with-multiple-reveal-animation/)를 바탕으로 기존 S-NOTE 카드와 반응형 배치에 맞췄다. 외부 애니메이션 라이브러리는 추가하지 않았다.

운영 API/실제 고객 자료 없이 가상 계정·데이터와 실제 Chromium으로 확인한다.

- `unified-search-shares-v2228.browser.cjs`: 1440/390px 공유 권한 재확인·단일 요청·목록 유지·철회·실패·전환·비동기 이동 승인/거절 24개 검사.
- `dashboard-reveal-v2228.browser.cjs`: 4개 폭·동작 줄이기·금액 잠금·상사 전환 6개 사례, 7개 값/원본 불변·키보드·빠른 반전·가로 넘침·비활성 상태 검사.
- 화면 밀도 A/B 1440/1024/390px 6개 흐름. 1024px의 기존 넓은 표에 의한 페이지 폭은 기준 1189→1150px로 감소했다. 기존 표 가로 넘침을 완전히 제거한 변경은 아니다.

기존 문서 검사의 로고 기대값만 새 요청에 맞춰 공식 이미지로 바꿨다. 기존 공유 목록 fixture에는 현재 대시보드의 읽기 전용 일정 RPC 응답을 추가했다. 초기 검증 중 소스를 수정해 발생한 로그인 해시 불일치는 소스 고정 후 전체 재실행으로 해소했다.

운영 DB·인증/Cloudflare/NAS 설정은 변경하지 않는다. Safari/iPhone 실기기와 실제 운영 계정 검증은 포함하지 않는다. 배포는 검증한 트리와 정확한 커밋의 Cloudflare Pages `s-note` 성공을 대조한다.
