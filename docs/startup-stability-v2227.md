# 초기 표시 안정화 (v2.227)

기준은 v2.226 (`c5f78954333632565de934d2d30e30d2d459741b`)이다. 기존 서비스 로고 영역과 최종 화면 디자인을 유지하면서 로딩 중 글꼴·로고가 재배치되는 경로를 정리했다.

- 공식 서비스 로고 CSS를 메인 문서 head에서 읽고, 외곽 박스와 contain 비율을 처음부터 고정한다. 이미지 디코딩 전에는 같은 자리를 비워 두고 준비 후 짧게 표시한다. 축소 사이드바의 S 심볼 전환과 이미지 오류·재시도도 같은 규격을 유지한다.
- 예전 서비스 로고의 200% 확대, S/NOTE 분할 crop, 축소 사이드바 강제 crop과 사용하지 않는 변환 코드를 제거했다. 문서용 기존 그림은 삭제 대상이 아니다.
- 로그인·메인·운영자·고객 입력·계정 복구·월결산·소득정산의 첫 표시를 정적 스타일과 화면 글꼴 준비 뒤에 진행한다. 인증·데이터 요청이나 숨긴 문서 이미지는 기다리지 않는다. 기존 인증, 금융 잠금, 역할 권한, 화면 전환 로직은 변경하지 않는다.
- 이미 사용하는 로컬 UI 글꼴을 미리 요청한다. 글꼴 또는 지연 스크립트가 1.8초 안에 준비되지 않으면 정적 스타일과 HTML 준비 후 로컬 화면 글꼴·현재 글자 크기를 유지해 늦은 응답의 재배치를 막는다. 실패한 stylesheet도 대기를 해제한다. 동작 줄이기 설정에서는 표시 애니메이션을 생략한다.
- 메인 화면의 이전 로컬 로그인 shell을 초기에는 숨기되 기존 fallback의 표시/로그아웃 경로는 유지한다. 전체 stylesheet 순서와 기존 readable-type의 인쇄 제외 규칙도 유지한다.
- 고객 입력 페이지는 기존 CSP가 허용하지 않아 적용되지 않던 동적 글씨 보정 스크립트 요청을 제거한다. CSP를 완화하지 않고 운영 화면의 실제 글자 크기를 유지한다.

`startup-presentation`은 화면 표시만 관리한다. 상사 로고·도장·서명, 견적서·계약서·인수증 양식과 문서용 `assets/snote-logo.png`, 출력용 글꼴은 유지한다. 화면 전용 대체 글꼴을 인쇄에 적용하지 않고 `beforeprint`에서 표시 대기를 해제한다. 운영 데이터와 DB·Cloudflare·NAS 설정은 변경하지 않는다.

## 검증

실제 Chromium과 가상 계정·차량·고객 자료로 검증한다. 운영 API를 호출하지 않는다.

- `tests/startup-stability-v2227.browser.cjs`: 느린 글꼴·글씨 보정 스크립트·브랜드 CSS/JS/이미지와 숨긴 문서 이미지, 390/1440px 첫 표시, 실제 CSP, 지연 응답 뒤 글꼴·좌표 고정, 공식 로고 디코딩과 비율을 검사한다. `SNOTE_STARTUP_BASELINE=1`은 보관된 기준 소스를 사용한다.
- `tests/service-brand-v2226.browser.cjs`: 로그인·가입·업무·모바일 메뉴 1440/1024/850/390/360px, 운영자·고객·복구 1440/390px의 기존 로고 박스 23곳 및 아이콘 8개 검증.
- `tests/normal-login.browser.cjs`, `tests/operator-console.browser.cjs`, `tests/route-transition.browser.cjs`: 로그인·동시 세션·유휴/명시 로그아웃·권한·배경 이미지·운영자 업무·빠른/느린 화면 전환 회귀.
- `tests/company-document-assets.browser.cjs`, `tests/document-refinement-v2160.browser.cjs`: 회사 자산과 지연 응답 격리, 문서 3종의 1440/390/320px 미리보기·A4 PDF·고객 입력 회귀.
- `tests/monthly-first-use.browser.cjs`: 딜러·경리·관리자, PC·모바일의 최초 열기·저장·인쇄·재시도·이탈·로그아웃/재로그인 15개 시나리오.
- `tests/income-settlement-ui-v2174.browser.cjs`: 저장소 밖에 설치된 가상 DB/Playwright 의존성을 `NODE_PATH`로 지정한다. 운영 DB를 사용하지 않는다.
- `node --test tests/service-brand-boundaries.test.mjs`, JS 문법 검사, `git diff --check`.

인위적 지연 조건의 전후 비교는 로딩 안정성 검증이며 운영 속도 측정값이 아니다. 실제 Safari/iPhone 실기기와 운영 계정의 최초 접속 속도는 별도 확인 대상이다. 운영 사이트 직접 브라우저 접근은 실행환경 제약이 있어 검증한 소스 트리와 정확한 커밋의 Cloudflare Pages `s-note` 성공을 대조해 배포를 확인한다.

고객 입력 페이지는 실제 `_headers`의 CSP를 적용해 v2.226과 비교했다. 기존 inline 보정 스타일은 차단됐으며, 무효 스크립트를 제거한 뒤에도 390px 제목의 17px/28.05px 글자 크기·줄 높이와 위치·실제 글자 영역이 일치했다. 해당 정책 차단 오류만 없어졌다.

최종 초기 표시 검사 22개는 모두 통과했다. 전 케이스의 관측 CLS는 0이며 보이는 이전 로고는 없었다. 숨긴 문서 로고를 2400ms 지연한 경우에도 FCP가 2140ms에 발생해 해당 문서 그림을 기다리지 않음을 확인했다. 이는 가상 지연 시험 결과이며 운영 응답 시간의 추정값으로 사용하지 않는다. 위 기능·문서·정산 회귀 검사도 통과했다.
