# v2.209 모바일 달력·차량 카드

모바일 달력의 날짜·일정 글씨와 안쪽 여백을 줄여 하루의 내용을 더 많이 표시한다. 좁은 화면에서도 개인 일정과 읽기 전용 차량 매입·판매일을 함께 확인하고, 남은 일정은 정확한 더보기 건수로 안내한다. 일정 편집 화면의 입력 글씨·저장·뒤로가기 동작은 유지한다.

일정 제목은 모바일에서 9.5px·최대 두 줄, 날짜는 10px로 표시한다. 360px 미만은 하루 최대 3개, 360~760px는 최대 4개 항목을 표시하며 개인 일정과 차량 날짜를 섞어 보여준다. 거래 구분은 좁은 칩의 공간을 아끼기 위해 범례·색상·접근성 이름에 유지한다. 비어 있는 주는 낮추고 내용이 많은 주만 늘어난다. 같은 가상 일정 16건의 390px 화면에서 달력 높이가 800px에서 602px로 줄었으며 더보기 전체 조회·입력 16px·편집 내용 보존·데스크톱 원래 배치를 확인했다.

모바일 차량 목록은 카드가 목록의 전체 폭을 사용하도록 도구·아이콘 영역과 분리한다. 차명·차량번호·연식·주행거리·판매가격·상태 중심으로 정리하고, 기존 선택 항목과 허용된 작업 버튼은 접근할 수 있게 유지한다. 사진 확대, 공유·계약중 표시, 역할·금융 잠금·상사 범위와 차량 상세 기능은 변경하지 않는다.

변경 전 390px 화면에서 패널은 356px인데 목록은 276px만 차지하는 현상을 가상 앱으로 재현했다. 부모 패널의 명시된 두 열과 도구 버튼의 세 번째 열 배치가 충돌해 암시적 열이 만들어진 것이 원인이다. 가로 넘침을 숨기는 방식 대신 부모 열과 본문의 전체 열 차지를 명확히 맞춘다.

데스크톱 배치, 금융 계산·일정 저장 모듈 및 출력 서류는 기존대로 유지한다. 검증에는 가상 계정·차량·사진·일정과 외부 요청 가로채기를 사용하며 운영 데이터나 설정을 변경하지 않는다.

최종 실제 앱 검증은 320/360/390/430/768/1440px에서 달력과 카드, 관리자·경리 권한, 판매완료, 선택한 금융·차대번호·견적서 항목을 확인했다. 390px 카드 폭은 276px에서 332px로 늘었으며 상태와 경과일을 같은 행으로 정리했다. 엔카 저장 상태 검증을 우회하지 않고 가상 저장본·서버 리비전을 맞춘 광고와 실제 견적서 항목 선택으로 엔카·견적서·상태 버튼을 함께 표시해 320~430px에서 44px 클릭 영역·겹침·가로 넘침을 확인했다.

날짜·상사 범위 2개 회귀 그룹, 사진 확대·축소·공유/계정 전환 7개 그룹, 기존 모바일 도구 메뉴 4개 그룹도 통과했다. 도구 메뉴 테스트의 이전 배경색 단정은 수정 전 main에서도 현행 테마와 불일치하므로 해당 기대색 한 개만 현재 테마에 맞췄다. 제품 색상은 바꾸지 않았다. 오래된 별도 카드 테스트의 엔카 가상 저장본 문제는 기준 main에도 있어 제품 코드를 변경하지 않고 현재 저장 구조를 사용하는 추가 검증으로 확인했다.
