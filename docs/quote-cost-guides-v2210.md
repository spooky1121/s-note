# v2.210 견적서 비용 항목·안내 편집

견적서의 증지대·성능보증보험료·번호판 교체비·매도비·수수료 행에서 항목명과 안내를 편집한다. 차량대금·취득세·공채의 자동 계산 항목과 계산식은 그대로 둔다. 입력 완료(Enter 또는 포커스 이동) 시 알려진 항목의 안내를 채우며 같은 항목의 안내를 직접 수정한 뒤 다시 포커스를 옮겨도 덮어쓰지 않는다. 처음 쓰는 항목에는 추측한 설명을 넣지 않고 직접 입력할 수 있다.

| 항목 | 기본 안내 |
| --- | --- |
| 탁송료 | 차량 운송에 필요한 비용 |
| 전기차 감면 | 전기차 관련 감면 금액 |
| 할인 | 견적 금액에서 차감되는 금액 |
| 수리비 | 차량 수리에 필요한 비용 |
| 정비 | 차량 점검·정비에 필요한 비용 |

띄어쓰기와 일부 통상적인 별칭도 인식한다. 할인·전기차 감면 행은 입력한 금액을 차감으로 반영하고 모든 수동 비용 행에서 명시적인 음수를 입력할 수 있다. 전기차의 감면 자격·법정 한도·금액을 판단하거나 자동 계산하지 않는다. 소계·최종 금액·이전비 입금 안내는 같은 계산 결과를 사용한다. 차량에 저장된 비용과 판매금액은 변경하지 않는다.

항목명은 24자, 안내는 60자로 제한하고 안내의 줄바꿈·탭은 공백으로 정리한다. 한글 입력 중 Enter로 조합이 끊기지 않게 하며 화면과 인쇄에서 긴 문구를 줄바꿈해 전부 표시한다. 인쇄 직전 현재 입력을 반영하고 별도의 텍스트 표시로 A4 한 장에 출력한다. 모바일에서 편집 중인 글씨는 화면상 16px를 유지한다.

기본 프리셋은 앱에 등록되며 직접 고친 문구·금액은 현재 견적서에만 적용한다. 새 견적서를 열거나 다른 차량으로 바꾸면 원래 기본값과 해당 차량의 보험료로 시작한다. 로그인·로그아웃·계정/상사 전환의 기존 문서 정리 경계에서도 견적서를 닫고 임시 문구·고객/차량 필드·금액을 지운다. 인증·역할·상사 권한이나 Supabase 설정은 변경하지 않는다.

검증은 가상 계정·차량·입금계좌와 네트워크 가로채기를 사용한다. 운영 고객 데이터·DB 설정·문자 서비스는 변경하지 않는다. 비용 안내 생성용 AI나 외부 요청, 별도 저장·마이그레이션은 추가하지 않는다.
