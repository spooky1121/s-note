# 메뉴 로고 정렬·문서 로고 표시 보완 (v2.231)

기준 main은 `b3936b08ea8e3a54b26c1687091c7f5c449cf1cb`이다. 기존 미커밋 변경이 없는 별도 브랜치에서 작업했다.

왼쪽 메뉴와 모바일 메뉴의 공식 로고 그림만 기존의 70% 크기로 줄이고 기존 브랜드 영역 가운데에 정렬한다. 원본 PNG와 S 심볼, 메뉴 폭, 버튼 클릭 영역, 로고 슬롯, 설명과 메뉴 항목 위치는 유지한다. 로그인·회원가입·운영자·고객 화면의 로고 규격은 변경하지 않는다.

견적서·계약서·인수증 하단의 공식 PNG는 정상이며, 실제 PC/모바일 미리보기와 A4 PDF에서 손상은 재현되지 않았다. 다만 기존 준비 함수가 공식 이미지 decode 실패를 삼켜 깨진 이미지 상태로 인쇄를 허용할 수 있었다. 공식 문서 로고에 버전 주소를 적용하고 정상 decode 후 표시하며, 일시적인 이미지 실패를 제한적으로 재시도한다. 로고를 준비하지 못하면 출력 전 안내하고 재시도할 수 있게 한다. 상사 로고·도장·서명과 업무 자료·권한·인증 처리는 변경하지 않는다.

문서 하단 로고 슬롯은 18×5mm, A4 페이지 수는 견적서 1장·계약서 2장·인수증 1장을 유지한다. 문서 내용, 인쇄 양식, 여백, 글씨 크기, 다른 규격은 변경하지 않는다.

검증에는 합성 계정·차량·이미지만 사용하며 운영 데이터나 서버 설정은 읽거나 수정하지 않는다. 실제 운영 브라우저 접근은 실행환경의 도메인 접속 제한으로 수행하지 못한다. 배포는 검증한 소스 트리와 정확한 커밋의 S-NOTE Cloudflare Pages 성공으로 확인한다. 실제 Safari/모바일 기기는 별도 확인 대상이다.
