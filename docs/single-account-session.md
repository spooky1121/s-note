# 일반 로그인 복원 — v2.118

사용자 요청에 따라 v2.114의 계정 동시접속 제한을 제거한다. 같은 계정으로 여러 기기에서 로그인할 수 있으며, 기존 접속을 해제할지 묻는 확인창·5초 주기 검사·접속 강제 종료·API별 세션 소유권 검사를 사용하지 않는다.

일반 로그인과 저장된 로그인 복원을 사용한다. 같은 컴퓨터의 다른 창에서 정상 로그인해도 기존 창의 업무 화면을 강제로 닫지 않는다. 로그아웃은 현재 접속에만 적용한다. 기존 미사용 자동 로그아웃과 계정·상사별 자료 접근 권한, 운영자 권한 확인은 유지한다.

DB 제거 파일은 `supabase/migrations/20261114060423_remove_single_active_account_session.sql`이다. 동시접속 제한의 요청 훅·추가 RLS·RPC·신호와 전용 표를 제거하고 운영자 인증 함수를 이전 정의로 복원한다. Auth 계정·유효한 로그인 세션·차량·고객 자료와 원래 RLS/Storage 정책은 변경하지 않는다. 새 프런트와 DB 제거가 함께 반영돼야 한다.

이전 버전이 열린 창은 새로고침해 최신 버전을 사용한다. v2.114 검증 JSON과 과거 migration은 이력이며 현재 로그인 방식의 지침이 아니다. 별도 작업 폴더의 미배포 Android 단일접속 시험 APK도 현재 웹 복원 상태와 맞지 않으므로 배포 대상으로 사용하지 않는다.
