# 차량 광고가·재고 시작일

## 엔카 광고가

차량 상세의 판매자 광고·엔카 믿고 링크 다음에 **엔카 광고가 N원**과 **판매가 변경** 버튼을 표시한다. `화면에서 찾은…` 문구는 표시하지 않는다. 공급자·정적 페이지·자동 OCR의 원래 출처와 검토 상태는 데이터에 보존한다.

`판매가 변경`을 누르면 별도의 확인창 없이 해당 광고가를 판매예정가로 저장한다. 다른 메모·추가비용·입력 중인 항목은 함께 저장하지 않는다. 직접 수정 중인 판매예정가, 다른 차량·계정·상사, 판매 완료·읽기 전용, 미확정 저장 상태에서는 변경을 제한한다. 저장 응답을 받지 못하면 원래 금액과 광고를 보존한 채 같은 요청의 저장 여부를 확인한다.

매입 목록·카드의 Encar 아이콘을 누르면 해당 차량 상세창에서 같은 광고를 새로 확인한다. 광고가와 판매예정가가 다르면 기존 변경 안내창을 띄우고, 같으면 안내창 없이 광고를 연다. 다른 차량의 미저장 상세창을 덮어쓰지 않으며 현재 차량의 미저장 입력도 유지한다. 변경 저장이 확인되면 목록·카드 금액도 갱신한다.

## 재고 시작일과 이자

재고이자 옆에는 해당 재고금융사에 등록된 연이율을 작게 표시한다. 재고이자에 마우스를 올리면 시작일 말풍선이 나오고, 클릭하면 시작일 설정창을 연다. 저장할 날짜는 실제 달력 날짜이며 오늘까지 선택할 수 있다. 실제 금융 시작일이 매입일보다 이른 경우도 허용한다.

차량마다 `inventoryStartedAt`을 `YYYY-MM-DD`로 저장한다. 이 값이 없는 기존 차량은 매입일을 시작일로 사용한다. 대출 원금 × 연이율 ÷ 100 × 경과일 ÷ 365를 계산해 최종 금액을 원 단위로 한 번 반올림한다. 당일 경과일은 0일이며 한국 날짜를 사용한다. 금융사 이율이 없거나 날짜가 잘못되면 임의의 이자를 만들지 않고 기존 수동 입력 경로를 유지한다. 명시적인 0%는 유효한 이율이다.

시작일 저장은 기존 소유자별 장부의 revision 확인을 거쳐 날짜와 그 날짜에서 계산한 이자·계산 스냅샷만 반영한다. 저장 중 작성한 메모, 추가비용, 대출금·금융사·매입일 입력은 별도로 보존한다. 차량 비용 합계·현재 투자금·대시보드·수익 및 소득 정산은 같은 이자 계산을 사용한다. 판매 완료 차량은 판매일과 저장된 이율·시작일 기준을 유지하며 이 팝업에서 날짜를 수정하지 않는다.

재고 중 저장한 계산은 확정된 판매 이율로 취급하지 않는다. 판매 완료 시점에 적용 이율을 확정하고 이후 금융사 이율 변경에도 완료된 거래의 계산을 유지한다. 기존 판매 스냅샷과의 호환성도 보존한다.

기존 `zc_datasets.payload` JSONB에 차량 속성을 저장하므로 새 표나 열을 만들지 않는다. 소유자·상사·계정 권한과 기존 장부 저장 RPC를 유지한다. 기존 차량을 일괄 수정하거나 시작일을 임의로 채우지 않는다.

## 로그인 화면

사진 위의 `WORK, WELL ORGANIZED.`를 제거하고 `좋은 거래의 시작, 정돈된 업무에서.`를 이미지 상단으로 올린다. 선명도를 개선한 별도 사진을 적용하고 기존 사진은 보존한다. 두 사진 모두 1086×1448이며 해상도 확대를 주장하지 않는다. 채도를 낮추던 필터를 제거하고 어두운 덮개를 줄여 사진 디테일을 더 잘 보이게 한다.
