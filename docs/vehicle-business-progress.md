# 차량 통합 업무 진행 기록

기준: v2.180 / `7c21e340ad3ccaa0c4282cb304d99a4f62a5b80f`. 작업 브랜치: `codex/vehicle-business-v2181`, 준비 버전 v2.181.

## 재사용과 구현

기존 차량 등록·수정, 회사/소유자 범위, 판매고객, 비공개 차량 사진·서류, OCR, 견적서·계약서·인수증, 세무용 소득정산, 기존 금융 한도를 유지했다. 점검 판정과 저장 계약은 `vehicle-business-workspace.md`에 있다.

차량 상세의 통합 요약과 8개 탭에서 거래·원가·발생/지급 비용·부분 입출금·금융 사건·서류/명의이전·복수 상담/다음 업무·광고/상품화·매입 검토·감사 이력을 관리한다. 매입 검토는 기존 내부 차량에 연결하며 비교 자료와 증빙을 저장한다. 별도의 미등록 차량 시세 서비스나 외부 메시지 자동화는 만들지 않았다.

원 단위 계산 모델은 대출 원금을 비용에 중복 반영하지 않는다. 판매 후에도 실제 잔액으로 이자를 계산하고, 부분 상환·금리 변경·청구 기간·원 단위 반올림을 구분한다. 판매·입금·대출 상환·명의이전·정산 마감을 자동으로 함께 완료하지 않는다. 취소·재판매는 별도 거래 ID로 원본 사실을 보존한다.

입출금이 전혀 등록되지 않은 미수·미지급을 0원 또는 전체 거래금액으로 단정하지 않는다. 일부 기록으로 산출한 잔액은 등록 기준으로 표시한다. 투입 자금은 판매 회수 전후를 나누며 고객 이전비 보관금·다른 입출금과 분리한다. 기존 차량 금액을 신규 원장에 가져오는 작업은 사용자가 거래 시작을 눌러 확인한다. 과거 누락 내역을 추정해 생성하거나 기존 원가·세무 양식을 일괄 변경하지 않는다.

오늘 업무는 실제 원장에서 파생하고, 원본을 완료하면 다시 계산한다. 관리자 상사 전체 조회는 명시적인 선택이다. 경리는 기존 업무 첫 화면과 금융 관리에서 회사 범위를 사용한다. 본인 외 상담·개인 후속 업무와 증빙은 서버에서도 차단하며, 기존 차량 공유가 새 재무/CRM 접근을 부여하지 않는다. 자료는 페이지 단위로 지연 조회하며 로그인 경로에 await를 추가하지 않았다.

## 운영 반영 상태와 다음 시작점

Supabase apply_migration 요청 두 번이 실행 결과 없이 종료됐다. 이후 read-only 조회에서 새 스키마와 write RPC가 모두 미설치임을 확인했다. 적용 여부를 추측하여 재시도하거나 다른 경로로 변경하지 않았다. 연결의 실행 확인 상태를 사용자에게 요청했으며, 답변 전 운영 DB 반영을 완료로 표시하지 않는다.

DB 적용 후에는 메타데이터로 7표 RLS/직접 ACL, public INVOKER wrapper/anon 실행 불가, 새 버킷 전용 정책, 기존 정책 보존과 advisors를 확인해야 한다. 실제 고객 자료로 쓰기 테스트하지 않는다. DB 준비가 확인된 뒤 검증한 코드 트리를 main에 반영하고 정확한 merge SHA의 `Cloudflare Pages: s-note` 성공을 확인한다. 현재 운영 v2.180은 유지한다. 검증한 변경은 DB 반영 확인을 기다리는 검토 가능한 PR로 보관하며, PR 번호와 빌드 결과를 아래에 남긴다.

증빙 버킷은 첫 실제 첨부 시 기존 서버 환경 변수로 준비된다. 첫 운영 파일 전송·Auth 역할별 수동 흐름은 미검증이다. 기존 백업 도구는 재사용 가능하지만 외부 보관·PITR·정기 복구의 실제 운영은 확인하지 못했으며 활성화하지 않았다.

복구 시 이전 프런트 배포를 사용하고 새 원장/증빙은 보존한다. 저장된 업무 자료를 삭제하는 스키마 롤백은 하지 않는다.

## 사용자 확인 순서

1. 차량 상세 → 통합 업무 → 거래 시작. 기존 가격/비용/날짜를 확인한다.
2. 입출금에 확인한 입금과 예정 금액을 구분해 기록한다. 금융에서 실행·부분 상환·금리 변경을 입력한다.
3. 서류 접수와 내용 확인, 명의이전 전달/완료를 각각 기록한다. 고객 상담과 다음 연락 기한을 추가한다.
4. 거래를 마감해도 미수·대출·이전·사후 업무가 남는지 확인한다. 대시보드 오늘 업무에서 원본으로 이동한다.
5. 경리의 업무 첫 화면·재고금융 관리, 관리자 내 업무/상사 전체 선택을 확인한다. 원래 견적서·계약서·인수증 인쇄도 확인한다.
