# 매입 차량 계약중 상태 — v2.144

매입 차량 상태 선택에 `계약중`을 추가하고 빨간색으로 표시한다. 상태 변경은 기존 확인·취소·저장 절차를 사용하며 판매 날짜나 실제 판매가를 생성하지 않는다. `판매완료` 차량만 매입 목록과 보유 재고 계산에서 제외하므로 계약중 차량은 목록·대수·재고금액에 계속 포함된다. 목록형·카드형·모바일과 경리의 읽기 전용 상태에도 같은 표시를 사용한다.

기존 상태 필터가 판매중으로 남아 있더라도 계약중 전환에 성공하면 전체 상태로 돌려 차량이 숨지 않도록 한다. 계약중 필터를 통한 조회도 지원한다. 기존 취소·판매완료·재고 복귀 절차와 소유자·공유 권한은 유지하며 판매완료 차량을 임의 이벤트로 계약중으로 되돌리는 것은 허용하지 않는다.

운영자 차량 편집의 상태 선택과 API 검증도 새 상태를 보존하며, 연결 고객 목록에는 해당 차량의 계약중 상태를 표시한다. 고객 휴대폰 정보 접수의 기존 재고 상태 검증에는 계약중만 추가한다. migration은 현재 운영 함수 원문에서 상태 목록 한 곳만 바꾸며 소유권·금액·휴지통·잠금·권한 검사를 보존한다. 실제 차량·회원·고객 자료를 변경하지 않는다.

검증은 실제 앱과 합성 서버 응답을 사용한 PC 1440px·모바일 390px 목록/카드, 상태 변경 취소·확인, 저장 ACK 및 새 브라우저 복원, 판매중 복귀와 판매완료 조건 검사로 진행했다. 운영자 API 30개 및 회귀 1,175개 테스트, 운영자 저장·재열기와 빨간 표시를 확인했다. DB 변경은 합성 트랜잭션을 롤백하여 계약중 고객접수 허용과 다른 소유자·상사·익명·판매완료 거절, 권한 보존 및 임시 자료 잔존 없음으로 검증했다.
