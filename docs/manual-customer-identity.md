# 판매 진행에서 주민번호 수동 저장·전체 표시

v2.14부터 판매 진행에서 입력한 주민번호는 **고객정보 저장**으로 서버에 저장합니다. 계약서·인수증을 바로 열어도 같은 저장 처리를 거칩니다. 다시 판매 진행을 열거나 고객 관리·계약서·인수증을 조회하면 저장한 번호 전체가 표시됩니다. 사업자번호 10자리도 같은 방식으로 보관합니다.

## 사용하는 방법

1. 본인 담당 차량의 **판매 진행**에서 고객정보와 주민번호를 입력합니다.
2. **고객정보 저장**을 누르면 화면을 유지한 채 저장합니다. 계약서·인수증 버튼은 저장이 완료된 뒤 문서를 엽니다.
3. 화면을 닫았다 다시 열어 전체 번호가 복원되는지 확인합니다. **고객 관리** 목록에서도 전체 번호를 확인할 수 있습니다.
4. 계약서·인수증에서 번호를 수정하면 같은 서버 보관 경로로 반영합니다. 저장 실패 시 성공으로 표시하지 않고 입력값을 유지합니다.

## 서버 적용

**추가 SQL이나 별도 암호화 키 등록은 필요하지 않습니다.** 기존 `zc_customers.payload`의 `identityCipher` 항목에 암호문을 넣어 일반 고객정보와 한 번에 저장합니다. 이번 수동 저장 기능에는 회사의 기존 `rrn_enabled` 플래그나 SOLAPI 발송 설정을 요구하지 않습니다.

Cloudflare Pages에 v2.14 전체 파일을 배포해야 합니다. 새 `functions/api/customer-identity.js`와 이를 연결한 `index.html`, 기존 `functions/api/customer-intake.js`를 포함합니다. 운영 주소의 `/api/customer-identity`에서 `configured: true`를 확인할 수 있으며, 이 진단은 번호나 키 값을 반환하지 않습니다.

암호화는 이미 설정한 `CUSTOMER_INTAKE_RRN_KEY`가 있으면 사용하고, 없으면 기존 `CUSTOMER_INTAKE_OTP_SECRET`에서 분리한 키를 사용합니다. 이 키는 번호를 다시 읽을 때도 필요하므로 자료가 남아 있는 동안 임의로 교체하거나 삭제하지 않습니다. 키 값을 HTML·GitHub·채팅에 올리지 않습니다.

## 저장·조회 방식

- 번호는 서버 API에서 AES-GCM으로 암호화합니다. 회사·담당자·차량에 묶어 다른 고객에게 암호문을 옮겨도 복호화되지 않습니다. DB의 일반 고객정보에는 번호 평문을 넣지 않습니다.
- 현재 로그인한 활성 담당자의 소속과 본인 고객·차량을 확인합니다. 고객 목록의 번호는 제한된 묶음으로 조회하며 서버에 저장된 암호문만 복호화합니다.
- 빈 입력은 기존 번호 삭제로 처리하지 않습니다. 새로운 번호를 입력해 저장하면 교체합니다. 고객 기록을 삭제하면 같은 고객 payload에 있는 암호문도 함께 삭제됩니다.
- 같은 차량의 저장을 순서대로 처리하고, 다른 탭의 수정과 충돌하면 최신 암호문을 확인해 다시 저장합니다. 이전 버전이 열린 탭은 업데이트 후 새로고침해야 합니다.
- 기존 별도 주민번호 저장 함수를 통해 보관한 자료는 새 암호문이 없는 경우에만 기존 조회 경로를 사용합니다. 새 암호문의 조회 실패를 과거 번호로 대체하지 않습니다.
- 이 보관은 고객 접수함의 30일 정리와 별개입니다. 고객 기록 삭제 전까지 기존 고객 데이터와 함께 보관합니다.

개발 검증에는 가상 번호·가짜 인증 응답·격리 DB를 사용합니다. 실제 고객의 번호를 테스트 파일이나 로그에 넣지 않습니다.

API 검증은 `node tests/customer-identity.test.mjs`로 실행합니다. 실제 Cloudflare 실행 엔진의 호환성은 `tests/customer-identity.workerd.cjs`로 별도 확인하며, 테스트 도구는 저장소 외부에 설치합니다. 실제 Supabase·문자 서비스에 연결하지 않습니다.

전체 화면 저장·재조회와 동시 수정 검증은 `tests/customer-identity.browser.cjs`를 사용합니다. 파일 상단의 안내대로 Playwright와 PGlite를 저장소 외부에 설치해 실행합니다. 회사의 기존 주민번호 설정이 꺼진 조건에서도 가상 번호의 저장·전체 표시를 확인합니다.
