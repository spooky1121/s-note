# 첨부 실사진 자료 연결 — v2.236

사용자가 직접 첨부한 `중고차_현장_실사진_매뉴얼.pdf`를 기존 차량 검수 도우미의 **사진으로 배우기** 화면에 연결했다. 29쪽의 JPEG 56개를 빠짐없이 사용하며, 실사진·제조사 도면·기록부 도해의 성격을 설명에 구분했다. 합계 이미지 용량은 7,302,923바이트다. 가상 테스트 이미지는 제품 자료에 포함하지 않았다.

기존 검수 화면 내부 제목·설명 블록의 삭제 상태를 유지한다. 검수 체크와 접속 중 메모, 계정·상사·역할별 범위, 로그아웃·상사 전환 시 이전 화면과 응답을 차단하는 동작은 유지한다. 기존 메뉴 구조와 서비스 로고·글꼴·업무 기능은 바꾸지 않는다.

## 학습 구성

원본의 순서대로 10개 부위 필터를 제공한다. 기존 7단계 `stageId`도 유지해 단계 기반 자료와 호환한다. 각 항목에는 이미지 설명, 볼 곳, 다음 확인, 원문 자료와 저자를 표시한다. 명확하게 확인한 이미지 위치에는 관찰 지점을 연결했다.

## 최초 사용 로딩

`assets/feature-loader.js`의 `inspection` 그룹은 최초 진입 시 `vehicle-inspection-learning-data.js?v=2.236`과 `vehicle-inspection.js?v=2.236` 두 모듈을 불러온다. 라우트가 `vehicle-inspection.css?v=2.236` 하나를 함께 준비하고, 공통 로딩이 완료된 후 유효한 계정·상사·역할에서 화면을 연결한다. 로그인 화면의 정적 선로딩에는 추가하지 않았다. 실패 시 재시도와 이전 컨텍스트의 늦은 응답 차단을 유지한다.

이미지에는 고유 경로와 실제 가로·세로를 지정했다. 원본을 다시 다운로드하거나 외부 서버에서 가져오는 기능은 추가하지 않았다.

## 설명 범위

사진 관찰만으로 사고·침수·안전 상태를 확정하지 않는다. 볼트 흔적·실러·도막·물 유입은 다른 원인과 기록을 함께 확인하도록 안내한다. 작은 위치 사진은 부위 위치 학습으로 설명하고 미세 손상 판정을 제공하지 않는다. 도막 측정 사진의 숫자를 정상 기준으로 사용하지 않는다.

차대번호 각인 도면은 해당 연식·미국 사양 아이오닉 5에, 차체 치수 도면은 해당 모델 3에 한정한다. 배터리 손상은 모델 Y 구조형 팩 사례로 한정하고 정비사 리프트 확인, 고전압 부품 접촉·탈거 금지, 외함이 벌어진 경우 시운전·충전 보류와 제조사 점검을 안내한다. 국내 기록부 도해는 부위·작업표시·원문 유의사항 대조용이며 사진 단독 법적 판정을 하지 않는다.
