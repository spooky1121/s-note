# v2.208 대시보드 요약 정리

달력 옆의 ‘기한 지난 미완료’와 ‘오늘 처리할 일’ 영역을 제거하고 최근 3개월 흐름과 수익 정산을 작은 카드로 배치한다. 기존의 큰 하단 그래프·정산 행은 중복 표시하지 않는다. 지난 개인 일정은 삭제하지 않으며 달력에서 계속 확인·수정할 수 있다.

상단 7개 지표의 제목과 금액 글씨를 조금 줄인다. 금액과 단위를 함께 표시해 좁은 카드에서도 ‘원’만 다음 줄로 내려가지 않도록 한다. 정확한 금액, 음수 표시, 수익 숨김, 금융 잠금 및 계정·상사 범위는 유지한다.

실적 지표 선택과 키보드 조작, 월별 값 확인, 수익 정산 메뉴 이동은 기존 기능을 유지한다. 개인 일정 저장·수정과 차량 매입·판매일 표시는 변경하지 않는다. 메뉴 구조·인쇄 양식·금액 계산·운영 데이터와 설정도 변경하지 않는다.

검증에는 실제 앱과 가상 계정·차량·일정을 사용한다. 화면 폭별 배치, 큰 금액·음수와 단위, 중복 영역 제거, 그래프 조작, 금융 잠금·수익 숨김 및 일정의 기존 동작을 확인한다. 브라우저 요청을 가상 응답으로 처리해 운영 고객 데이터나 외부 서비스를 사용하지 않는다.

금액이 길면 실측한 너비에 따라 7개 한 줄, 4+3, 2열 또는 1열로 배치한다. 숫자를 생략하거나 반올림하지 않는다. 1440/1024/390/320px에서 10억대·음수와 큰 안전 정수 금액을 시험했으며 숫자와 단위의 줄바꿈·잘림·가로 넘침 없이 표시됐다. 1440px 큰 금액 화면은 4+3의 균형 배치로 독립 시각 검토했다.

금액 계산 모델·판매 달력 모델·일정 저장 모듈·반응형 메뉴는 이전 운영판과 동일하다. 관련 Node 테스트 3개 파일과 기존 견적서 1쪽·계약서 2쪽의 원래 인쇄 동작을 확인했다. 지난 일정의 달력 수정, 편집 중 화면 크기 변경, 오늘·다가올 일정의 정확한 건수와 더보기, 화면 이동도 가상 브라우저로 확인했다.
