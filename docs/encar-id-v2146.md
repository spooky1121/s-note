# 광고 ID 조회 v2.146

## 요청 제한과 반복 조회

기존 `UPSTREAM_RATE_LIMITED` 문구는 Cloudflare Browser Run이 브라우저 생성 요청에 HTTP 429를 반환한 경우였다. 앱의 분당 30회 제한은 별도의 `RATE_LIMITED`였으며 이번 버전에서 광고 ID 경로의 앱 자체 횟수 제한을 제거했다. 인증·활성 멤버십·동일 출처·입력 크기 확인은 유지한다.

요청마다 새 브라우저를 종료/재생성하던 방식 대신, 이 기능이 직접 만든 세션 ID만 짧게 재사용한다. HTTP 생성 결과의 명시된 `sessionId`를 계정·토큰 지문·정책 버전에 연결해 서버 메모리와 named Cache에 보관한다. 캐시에는 세션 ID·만료 시각만 있으며 토큰·차량·고객 자료·WebSocket을 넣지 않는다. 캐시는 데이터센터별 best effort이며 분산 잠금이 아니다. 같은 isolate의 생성 대기는 메타데이터 Promise만 공유한다.

조회마다 새 WebSocket과 `disposeOnDetach` 격리 컨텍스트를 만든다. 차량 검색은 그 컨텍스트에서만 실행하고 종료 시 컨텍스트와 연결을 정리한다. 다른 요청의 WebSocket을 재사용하지 않는다. 브라우저는 30초 미사용 후 만료되며 메타데이터는 25초로 제한한다. 생성 전체는 8초로 제한하고 `waitUntil`에는 메타데이터 생성만 등록한다.

기존에 캐시한 세션이 실제 404/410일 때만 한 번 교체한다. 새로 생성한 세션의 첫 연결 실패, 429, 409에서는 재생성을 반복하지 않는다. `Retry-After`를 존중하며 세션·IP·토큰을 회전해 한도를 우회하지 않는다.

Cloudflare와 외부 사이트의 한도 자체는 코드로 제거할 수 없다. 공식 Free 한도는 새 브라우저 20초당 1개, 브라우저 사용 하루 10분이다. 현재 계정의 요금제·실제 잔여 한도는 확인하지 못했다. Paid에도 동시 실행·생성 속도 제한은 있다. [공식 한도](https://developers.cloudflare.com/browser-run/limits/)와 [세션 재사용](https://developers.cloudflare.com/browser-run/reuse-sessions/)을 참고한다.

## 검색 애니메이션

광고 ID 팝업은 검색 중 문서·돋보기 스캔과 점 애니메이션을 표시한다. 성공·오류·취소·기한 초과·계정 변경 시 숨긴다. 동작 줄이기 설정에서는 정적인 검색 표시를 유지한다. 성공한 팝업은 광고 ID와 확인 버튼만 표시한다.

## 누락 및 대조 수정

- 인라인 요소로 나뉜 숫자·한글·숫자와 지역 번호판의 공백을 같은 차량 값 안에서 합쳐 읽는다. 다른 행·카드의 텍스트는 번호판으로 합치지 않는다.
- 페이지 전환 중의 알려진 CDP 컨텍스트 오류는 결과 읽기만 다시 확인한다. 검색 제출 중 문맥이 사라지면 검색을 다시 제출하지 않는다.
- 화면 틀만 표시된 상태를 즉시 결과 없음으로 판단하지 않고 차량 정보와 원본 ID가 표시될 때까지 제한된 시간 안에서 기다린다.
- 러시아어·한국어 추천 차량 경계와 명시된 추천 영역을 제외하고, 차량 레코드 밖의 번호판·ID를 빌리지 않는다.
- 공백뿐인 검색 아이콘은 실제 폼의 접근성 라벨도 확인한다.

Carnect → GLOAR → Trust의 순서와 첫 번째 검증 결과에서 종료하는 동작은 유지한다. 번호판 전체와 원본 광고 ID 증거가 필요하며, URL 숫자를 광고 ID로 추정하거나 차대번호·연식·트림을 추가로 요구하지 않는다. 광고 열기·가격/OCR·판매가 변경·차량 저장·DB 변경은 없다.

## 검증 범위

활성 회귀 318개, PC·모바일 검색 애니메이션과 동작 줄이기, 실제 Wrangler 빌드와 workerd의 합성 API/CDP 검증이 통과했다. 동시에 들어온 cold 요청과 뒤이은 warm 요청이 브라우저 생성 1회를 공유하고 요청별 격리 컨텍스트를 모두 정리하는 것을 확인했다. 실제 번들의 검색 함수도 별도 DOM 환경에서 실행했다.

합성 검증의 실제 외부 요청은 0건이다. 현재 실행환경의 공급자 접속 제한으로 실제 Cloudflare 계정·세 사이트의 차량 검색 성공률은 검증하지 못했다. 특정 광고의 누락이 계속되면 해당 차량번호와 운영 응답을 대조해야 한다. 명시된 원본 광고 ID가 없는 자료와 검사 한도를 넘는 결과는 추정해서 표시하지 않는다.
