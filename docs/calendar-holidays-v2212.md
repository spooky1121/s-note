# v2.212 달력 공휴일과 일정 색상

대시보드 달력에서 일요일과 확인된 한국 공휴일의 날짜 숫자를 빨간색으로 표시한다. 데스크톱·모바일 모두 적용하며 오늘과 앞뒤 달에 걸친 날짜도 표시한다. 오늘은 원형 강조를 유지하되 빨간 글씨가 읽히도록 연한 배경을 사용한다. 공휴일명은 날짜 버튼의 툴팁과 접근성 이름에 포함하고 기존 일정 표시 공간은 늘리지 않는다.

판매 일정은 밝은 빨간 테두리·연한 분홍 배경, 매입 일정은 밝은 하늘색 테두리·연한 하늘색 배경으로 구분한다. 일반 일정 제목은 검정색이며 완료 일정의 취소선은 유지한다. 범례와 전체 일정 목록에도 같은 색상 구분을 적용한다. 작은 일정 글씨와 배경의 대비는 판매 4.85:1, 매입 4.74:1, 일반 15.16:1이다. 일정 생성·수정·삭제, 개인/상사 범위, 기존 더보기와 날짜별 표시 개수는 변경하지 않는다.

공휴일 자료는 공식 확인된 **2024~2027년** 연도별 날짜를 작은 동기 모듈에 보관한다. 양력 공휴일·설·추석·부처님오신날·대체공휴일 및 공표된 선거·임시공휴일을 포함한다. 2026년부터 적용된 노동절·제헌절과 시행일도 구분하고 과거 연도에는 소급하지 않는다. 같은 날의 두 공휴일명은 함께 보관한다. 음력 추정이나 주말 일괄 대체일 계산은 사용하지 않는다.

확인 범위 밖 연도로 이동하면 ‘이 연도 공휴일 정보가 없습니다.’를 표시한다. 일요일 색상과 일정 추가·수정·월 이동은 계속 이용할 수 있다. 2028년 공개 천문자료는 공식 발표본이 아니라고 명시되어 있어 이번 확정 자료에 포함하지 않는다. 이후 확정 공표나 새로운 임시공휴일 지정 시 모듈의 연도별 날짜와 검증일을 갱신해야 한다.

모듈은 네트워크 요청·API 키·로컬 저장소·날짜/음력 계산을 사용하지 않는다. 저장된 고객·차량·일정 데이터 및 운영 DB·인증·권한 설정에는 변경이 없다. 반환 Map은 복사본이며 전역 API와 지원 범위 정보는 읽기 전용이다. 연도 경계의 각 날짜는 해당 연도로 조회한다.
