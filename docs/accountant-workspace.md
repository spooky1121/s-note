# 경리 업무와 직원 ID — v2.130

경리의 첫 메뉴는 **계약서 업무**입니다. 대시보드는 숨기고, 경리의 중복 메뉴였던 상사매입을 제거합니다. 대표 관리자의 상사매입 메뉴는 유지합니다.

경리의 매입관리·판매완료·재고금융은 현재 소속 상사의 전체 딜러 자료를 조회합니다. 매입관리는 미판매 차량, 판매완료는 선택한 판매월의 차량을 표시하며 담당 딜러로 필터할 수 있습니다. 퇴사·비활성 직원의 보관 차량도 포함합니다. 재고금융은 미등록 금융사와 금융사 미지정 대출을 누락하지 않고, 같은 차량을 중복 합산하지 않습니다. 검색창은 PC에서 300px로 줄이고 모바일에서는 사용 가능한 폭을 사용합니다.

자료를 불러오는 동안이나 연결 실패 시 이전 상사의 목록을 표시하지 않습니다. 관리자·딜러의 기존 개인 매입 범위와 경리의 차량 수정 제한은 유지합니다.

## 계약서 업무

첨부한 자동차양도증명서(매매업자용)의 앞·뒷면을 원본 그대로 보관하고 벡터 배경으로 출력합니다. 매도인·매수인, 매매업자, 차량, 대금·날짜·비용, 특약 등 39개 항목을 입력하여 같은 상사의 DB에 저장하고 다시 열 수 있습니다. 차량을 선택하면 검증된 소속 차량 정보만 가져옵니다. 금액은 원 단위 정수이며 빈칸과 0원을 구분합니다.

미리보기와 출력은 A4 2장입니다. 원본의 10개 약관과 수기 서명·날인 칸을 유지하며 서명이나 도장을 임의 생성하지 않습니다. 긴 입력값이 인쇄 칸을 벗어나면 해당 항목을 안내하고 인쇄를 중단합니다. 저장 전에는 초안을 유지하고, 다른 직원의 수정과 충돌하면 덮어쓰지 않습니다. 계정·상사·권한 변경 시 편집 중인 개인정보를 지웁니다.

이 업무의 저장소는 기존 고객 계약서·주민번호·서명 저장소와 독립적입니다. 브라우저 localStorage에 계약서 개인정보 초안을 추가 저장하지 않습니다.

## 대표 관리자 직원관리

설정 → 직원관리에서 직원 이름 옆에 실제 로그인 ID인 이메일을 읽기 전용으로 표시합니다. 모바일에서는 이름 아래에 배치하고 이름 입력칸·저장·삭제 아이콘의 중심을 맞춥니다. 이메일이 없는 계정은 `ID 확인 필요`, 조회가 실패하면 `ID 조회 확인 필요`로 표시합니다. 내부 UUID를 로그인 ID로 대체하지 않습니다.

활성 상태인 같은 상사의 대표 관리자만 직원 ID를 조회할 수 있습니다. 이름 저장은 기존 기능을 유지하며 이메일·비밀번호를 변경하지 않습니다. 직원 ID 조회는 설정 화면에서만 실행하고 로그인·세션 검사를 추가하지 않습니다.
