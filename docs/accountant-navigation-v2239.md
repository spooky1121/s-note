# 경리 메뉴 구성 — v2.239

경리 메뉴를 대시보드, 서류함, 은행, 세금, 재고금융, 조회, 정산, 정보 순서로 구성한다. 서류함에는 차량서류·양식지·매입·매도·운영 서류함, 정산에는 딜러소득·운영정산, 정보에는 계좌·전화번호·직원을 둔다. 각 하위 메뉴는 접거나 펼칠 수 있으며 모바일 메뉴에도 같은 계층을 사용한다.

기존 실제 경로를 유지해 저장·뒤로가기·권한·지연 응답 검증을 바꾸지 않는다.

| 표시 | 기존 경로와 동작 |
| --- | --- |
| 차량서류 | `contractArchive`: 상사 차량의 기존 6열 서류 목록 |
| 양식지 | `contractOffice`: 기존 문서 작성·양식 카드 보존 |
| 매입·매도 | `buy` / `sell`: 매입 관리·판매 완료 탭 |
| 재고금융 | `inventoryFinance` / `prestock`: 재고금융 관리·선재고 관리 탭 |
| 운영정산 | `monthly`: 기존 월정산 iframe, 저장·인쇄와 최초 진입 로딩 유지 |
| 딜러소득 | 기본 화면에서 판매 완료 목록의 기존 소득정산으로 연결 |

은행·세금·조회·운영 서류함·계좌는 이번 요청의 메뉴 틀과 기본 화면을 제공한다. 은행 연동, 세금 장부, 새로운 파일 보관소를 구현한 것으로 표시하지 않는다. 기존 선재고 계좌·거래 내역과 저장 문서에는 연결 버튼을 제공한다. 기존 양식의 준비 상태도 바꾸지 않는다.

직원·전화번호는 로그인 시 기존 권한으로 조회한 현재 상사의 활성 직원 이름·역할·선택적 전화번호만 읽기 전용으로 투영한다. 인증·상사 확인 전에는 표시하지 않으며 다른 상사·비활성 직원·로그인 ID는 제외한다. 관리자 직원 관리 RPC, 계좌 설정 권한, DB 스키마를 확장하지 않는다. 전화번호 필드가 없는 구형 응답은 기존 호환 경로를 유지한다.

경리의 새 메뉴는 요청 순서를 고정하고 기존 개인 메뉴 순서 설정을 삭제하지 않는다. 다른 역할의 메뉴 순서 및 서류 카드 순서 변경은 유지한다. 신규 기본 페이지는 경리 전용이며 메뉴·직접 이동·해시·통합검색 모두 기존 페이지 권한 검증을 거친다.

통합검색 차량 결과의 `판매중` 글자는 초록색, `판매완료` 글자는 파란색으로 표시한다. 공유 표기, 배경, 글자 크기와 결과 동작은 유지한다.

검증은 합성 계정·상사·차량·문서로 진행하며 실제 고객 자료와 운영 DB 설정은 변경하지 않는다. 상세 브라우저 결과와 화면 증거는 작업 환경의 `/workspace/work/accountant-navigation-v2239/qa`에 기록한다.
