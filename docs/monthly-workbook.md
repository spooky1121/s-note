# 엑셀 결산표형 월정산

v2.16의 월정산은 첨부한 월별 결산표의 구조를 기준으로 구성합니다. 실제 인명·계좌·금액은 배포 파일에 넣지 않고, 빈 월별 양식과 일반 지출 항목으로 시작합니다.

## 입력과 계산

- **딜러 입금:** 성명, 매입·매도 대수, 매입비·매도비·마당비를 셀에 직접 입력합니다. 행 합계와 월 합계가 바로 바뀝니다.
- **상사 지출:** 항목·금액을 입력하고 필요한 행을 추가하거나 삭제합니다.
- **이월·조정:** 전월 마감액을 이어받거나 기초잔액을 직접 입력합니다. 조정금액은 양수·음수로 기록합니다. 전월 자료가 없거나 이월액을 입력하지 않았다면 마감잔액을 확정된 0원으로 표시하지 않습니다.
- **계좌 대사:** 입력한 계좌잔액 합계와 장부 마감액의 차이를 확인합니다. 미입력 계좌는 실제 0원과 구분합니다.
- **재고금융·미수:** 금융한도·사용액·잔여한도, 미수·정산 보조항목을 별도로 관리합니다. 금융 잔여한도나 미수 보조합계를 현금잔액에 자동 합산하지 않습니다.

매입비·매도비는 이 결산표의 상사 수입 항목이며 차량 매입·판매 대금과 구분합니다. 월 결산은 `상사 수입 − 지출 + 조정금액`, 월말 자금은 여기에 이월잔액을 더한 값입니다. 금액 입력·저장은 원 단위이고 대수는 정수입니다.

## 저장

입력 중 합계는 즉시 계산하고, 잠시 입력을 멈추면 자동 저장합니다. **저장** 버튼으로 바로 저장할 수도 있습니다. 온라인 화면의 **서버 저장 완료**는 실제 서버 응답을 확인한 뒤 표시합니다. 저장 중 다시 수정하면 최신 내용이 이어서 저장됩니다.

실패·연결 끊김·동시 수정 충돌 시 현재 입력을 보존하고 재시도 또는 서버 내용 확인을 안내합니다. 미저장 초안은 회사·계정·월을 구분해 보관하며 다른 회사나 계정에서 자동 표시하지 않습니다. 같은 월을 다른 기기에서 동시에 바꾼 경우 현재 입력으로 원격 장부를 조용히 덮어쓰지 않습니다.

다른 기기에서 수정한 자료는 **새로고침**으로 읽습니다. 자동 이월을 사용할 때도 직전 월을 다른 기기에서 수정했다면 최신 자료를 다시 읽어 확인합니다.

새 장부는 기존 `monthly` 데이터셋 배열의 월별 버전 레코드로 저장합니다. 기존 입출금 거래와 알 수 없는 원본 항목은 보존하며 **기존 거래원장**에서 확인할 수 있습니다. 이 자료는 새 결산표에 중복 합산하지 않습니다. **추가 SQL이나 새 키 설정은 필요하지 않습니다.**

## 출력과 참고

- **인쇄:** 현재 월의 입력값과 계산 결과를 A4 가로 방향으로 출력합니다. 기본 양식은 한 장에 정리하며, 행이나 긴 메모가 많으면 여러 장으로 나눕니다. 브라우저 인쇄 화면에서 PDF로 저장할 수 있습니다. 미저장 상태라면 출력에도 표시합니다.
- **엑셀(CSV):** 한글을 지원하는 CSV로 내려받습니다. Excel에서 열 수 있으며 숫자와 메모를 함께 확인합니다.
- **엑셀 참고:** 원본 표의 딜러 입금·지출·이월·계좌·금융·미수 영역이 웹의 어느 항목에 대응하는지 확인합니다.

행 추가·버튼·저장 상태에 짧은 전환 효과를 적용합니다. 운영체제의 동작 줄이기 설정을 사용하면 애니메이션을 줄입니다.

## 배포·확인

v2.16 전체 파일을 배포합니다. `index.html`뿐 아니라 `monthly.html`과 `assets/monthly-workbook-*` 파일을 함께 포함합니다. 기존에 열어 둔 이전 버전 탭은 새로고침합니다.

테스트 계정에서 딜러 입금과 지출을 입력하고 합계 → 서버 저장 표시 → 새로 열기 → 인쇄·CSV를 확인합니다. 별도 회사·동시 기기·저장 실패 경로는 가상 자료로 검증하며 실제 재무자료를 테스트 파일에 포함하지 않습니다.

개발 중 원본 Excel의 작성된 9개 월에 대해 수입·지출·현금증감·마감잔액·계좌 대사 차이·미수 보조합계 54개를 캐시된 수식 결과와 비교해 일치를 확인했습니다. 이 검증의 원본 금액은 배포 코드나 테스트 자료에 포함하지 않았습니다.
