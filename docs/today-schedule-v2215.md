# v2.215 오늘 일정 강조와 남은 일수

대시보드의 오늘 일정 카드에 표시할 일정이 있으면 S-NOTE 하늘색 테두리를 적용하고 3.6초 주기로 진한색과 연한색 사이를 부드럽게 반복한다. 테두리 색만 바꾸고 두께·카드 크기·글씨·배경·투명도·위치는 바꾸지 않는다. 모션 감소 설정에서는 하늘색 테두리를 고정한다.

강조 여부는 기존 서버 확인 상태(ready 또는 saving)와 오늘 일정 개수가 1개 이상인지로 판단한다. 기존 오늘 목록에는 완료된 일정도 포함되므로 완료 후에도 오늘 일정이 남아 있으면 강조를 유지한다. 빈 상태·로딩·오류에서는 강조하지 않으며 마지막 오늘 일정을 삭제하거나 날짜가 바뀐 후 새 응답이 반영되면 해당 상태에 맞춘다. 개인 일정 범위·권한·기존 저장/완료/삭제 절차는 바꾸지 않는다.

다가올 일정의 날짜 안내 옆에는 ‘1일 후’, ‘3일 후’처럼 남은 달력 일수를 표시한다. 요약 카드와 ‘그 외 일정 보기’ 목록에 동일하게 적용하며 달력의 작은 일정 칩·오늘 일정·일반 날짜별 목록에는 추가하지 않는다. 남은 일수는 같은 서버 응답의 한국 기준 오늘 날짜와 일정 날짜를 UTC 자정으로 정규화해 계산한다. 선택한 달, 브라우저 시간대, 일광 절약 시간이나 현재 시각의 시·분에는 영향받지 않는다. 1~99년도 Date.UTC 보정 문제를 피하도록 setUTCFullYear를 사용한다.

배지는 줄바꿈하지 않으며 긴 일정 제목의 기존 줄임표를 유지한다. 버튼의 접근성 이름에도 남은 일수를 포함한다. 기존 KST 자정·창 복귀 감지와 새 서버 응답 처리로 표시를 갱신하고 별도 타이머나 서버 요청은 추가하지 않는다.

가상 계정·일정 및 가로챈 응답을 사용하는 Chromium 브라우저로 검증한다. 운영 고객 데이터·DB·인증·Cloudflare 설정에는 변경이 없고 실물 모바일 기기는 별도로 검증하지 않는다.

달력의 요일과 날짜 숫자는 기존 각 화면 폭의 설정에서 2px씩 키우고 일반 글씨 두께를 550으로 조정한다. 오늘 날짜의 기존 700 강조는 유지한다. 날짜 칸·오늘 원형 표시·달력의 열 구성과 일정 제목 크기는 유지한다. 모바일 날짜·요일의 줄 간격은 커진 글씨에 맞게 소폭 보정한다.

가상 브라우저의 오늘 일정 표시·추가/완료/삭제·연말 KST 자정·윤년 4개 그룹을 통과했다. 배지를 날짜 안내 옆으로 옮긴 뒤 1440/390px 표시를 다시 확인했다. 최종 폰트 검증에서 1440px의 요일은 12→14px·날짜는 13→15px, 390px에서는 각각 10→12px로 정확히 2px 증가했고 일반 두께 550·오늘 700을 확인했다. 날짜 원형 크기·텍스트 범위·가로 넘침도 검증했다. 기존 일정 저장소와 차량 거래일 모델 회귀도 통과했다. 표시 변경 후 재실행한 그룹과 계산 로직 변경 전 통과한 그룹은 QA 기록에서 구분한다.
