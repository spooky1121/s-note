# 양도증명서 미리보기·날인·출력 — v2.143

매입·매도 서류의 프린터 버튼은 먼저 인쇄 미리보기를 연다. 서식·폰트·현재 회사 인감과 선택한 이름 도장 이미지를 읽고 칸 안에 들어가는지 검증한 뒤 미리보기의 프린터 버튼을 사용할 수 있다. 미리보기에서 확인 후 다시 누를 때만 브라우저 인쇄를 실행한다. 오류, 디코딩 중 닫기, 권한 또는 회사 변경은 기존처럼 인쇄를 차단한다.

서류 제목과 뒤로가기·작업 아이콘을 같은 행에 배치한다. PC에서는 기존 크기를 유지하고 모바일은 아이콘 그림을 유지하면서 버튼 간격과 영역을 줄여 한 줄에 맞춘다. 서류함에서 연 문서에도 같은 배치를 적용한다.

회사 인감은 원본 비율과 잉크 모양을 보존한 고해상도 PNG로 렌더링하고 원본 획 안에서 경계 대비를 높인다. 최소 긴변 2048px, 최대 4096px·8MP 상한과 비공개 원본의 범위·재확인·폐기 절차를 유지한다. 회사와 이름 도장 잉크를 선분홍 계열로 맞추며, 이름 도장은 기존 캔버스와 물리 슬롯 안에서 세로를 10% 눌러 더 둥글게 하고 넓고 옅은 압력 자국을 보강한다. 사용자가 동의한 현재 이름 전체를 유지한다.

표 외곽선은 0.9pt에서 0.7pt로 낮추고 내부선은 유지한다. 마지막 행의 위쪽 경계를 435pt에서 431pt로 조정하여 압류·저당권 두 줄 라벨이 431~452pt 안에 들어오도록 한다. 자동차 인도일과 위 수수료 행의 입력 위치도 맞춘다. 새 문서의 압류·저당권 기본값은 `압류 : 없음    저당 : 없음`이며 출력에서 간격을 유지한다. 기존 저장 문서와 수동 입력, 공란을 덮어쓰지 않는다.

고정 서식의 임베디드 고딕 글꼴과 선은 벡터로 출력하고 도장만 투명 PNG로 배치한다. 기존 법정 조항·유의사항·특약·헤더·날인 위치와 원본 PDF/SVG 백업 및 39개 저장 항목·CAS는 유지한다. 브라우저 검증은 실제 앱과 합성 RPC/이미지를 사용하며 사용자 데이터는 조회하거나 수정하지 않는다. 물리 프린터 출력은 별도 확인 대상이다.
