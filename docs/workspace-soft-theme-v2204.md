# v2.204 업무 화면 스타일

승인된 메뉴별 시안을 바탕으로 선과 선택 배경을 더 옅게 하고 카드·입력창 모서리를 부드럽게 정리했다. 로고 S의 대표색 `#0096FE`, 차콜·남색 본문, 짙은 파란 보조 강조색을 사용한다. 하늘색 버튼의 글씨는 읽기 대비를 위해 `#192C41`로 표시한다. 읽기 대비가 필요한 작은 글씨는 옅은 회색으로 지우지 않는다.

## 적용 범위

- `assets/workspace-soft-theme.css`: 기존 업무 영역과 팝업 외곽
- `assets/operator-soft-theme.css`: 운영자 영역
- `assets/monthly-soft-theme.css`: 월정산 화면 편집 영역

세 스타일시트는 기존 화면 스타일 뒤에서 로드하며 `data-snote-type-scale`로 명시한 글씨 크기의 중복 확대를 방지한다. 월정산은 기존 첫 사용 iframe 로딩을 유지한다. 모든 새 규칙은 화면 매체로 한정한다.

메뉴·역할 권한·컨트롤·표 항목·금액 잠금·저장 경로·수식·모바일 뒤로가기 동작을 변경하지 않는다. 계약중·공유·정산완료·음수 금액과 빨간 미확인 알림은 기존 의미 색상을 유지한다. 로그인 구성, 계약서·인수증·견적서의 종이 내용, 서명·도장·출력 양식도 유지한다. DB/API/외부 서비스 설정 변경은 없다.

## 검증

`tests/workspace-soft-theme.browser.cjs`는 실제 HTML에 연결된 스타일시트를 수신하는지 확인한다. 가상 자료로 역할별 메뉴와 화면을 열고, 새 스타일 활성 전후의 버튼·입력창·표 헤더·텍스트·이미지 주소가 같은지 비교한다. 모바일 대표 화면과 팝업의 가로 넘침, 상태 표시 및 인쇄용 문서의 영향을 함께 확인한다. 실제 운영 계정이나 고객 자료·문자 발송은 사용하지 않는다.

운영자·월정산 및 기존 로그인·메시지·모바일 팝업·차량 등록·문서 출력의 관련 회귀 검증은 배포 기록에 별도로 남긴다. 화면 캡처와 가상 테스트 산출물은 제품 정적 파일에 포함하지 않는다.
