# 매입·매도서류 첨부 양식 — v2.138

매입서류와 매도서류의 미리보기·인쇄를 첨부 이미지의 표 구성에 맞춘 **A4 한 장**으로 교체합니다. 계약 당사자, 매매업자, 차량·금액, 계약 조항, 특약사항, 하단 서명란과 유의사항을 같은 페이지에 배치합니다. 스캔의 기울기와 이미 입력된 개인정보·가격·도장은 새 서식에 포함하지 않습니다.

이전 원본 `assets/forms/vehicle-transfer-dealer-2021.pdf`와 앞·뒤 SVG는 백업으로 보존합니다. 새 빈 서식은 `assets/forms/vehicle-transfer-reference-front.svg`, 출력 좌표는 `assets/transfer-document-layout.js`에서 관리합니다. 한글 글꼴은 서식 안에 포함해 화면과 PDF의 칸 배치 차이를 줄입니다.

법인도장의 출력 높이를 기존 28.5pt에서 **57pt로 두 배** 확대합니다. 등록 이미지의 비율을 유지하며, 가로 비율 2 이하의 직사각 도장도 높이가 줄어들지 않도록 이미지 너비를 계산합니다. 상단·하단 서명란에서 입력 이름과 겹치지 않게 배치합니다. 기존 비공개 상사 이미지 조회, 계정·상사 연결 확인, 디코딩 실패 시 출력 중단은 유지합니다.

상대방 이름도장은 36.48×57pt의 세로 타원형으로 출력합니다. 붉은 인주색, 미세한 투명 잉크 결손과 불균일한 농도를 적용하고 배경은 투명하게 유지합니다. `도장날인`을 선택한 경우 현재 입력 이름으로만 생성하며, 같은 이름은 같은 그림을 만듭니다. 선택 해제·이름 공란·다른 문서·계정 또는 상사 변경 시 이전 이미지를 정리합니다.

기존 39개 저장 항목과 문서 종류별 읽기·저장, 리비전 충돌 검사, 하단 이름 자동 연결은 유지합니다. 상사의 사업자번호는 기존 상사 정보에서 읽어 서식의 해당 칸에 표시합니다. 새 고객 식별정보 입력이나 DB 변경은 추가하지 않습니다. 이름도장 이미지·선택 상태를 저장 자료 또는 브라우저 저장소에 추가하지 않으며, 고객 제출 서명·인증·동의 상태도 변경하지 않습니다.

검증에는 합성 인명·상사 도장만 사용합니다. 실제 앱의 PC·모바일에서 매입·매도 각각을 열어 한 장 A4 출력, 입력값 정렬, 도장 확대·투명도, 이름과 본문 겹침, 미리보기·인쇄 취소, 이미지 실패 및 상사 변경 보호와 기존 저장 동작을 확인합니다. 물리 프린터 출력은 PDF 검증과 구분합니다.
