# 자동차양도증명서 도장 — v2.132

경리의 **매입 업무 → 매입서류**에서 자동차양도증명서를 미리보기·인쇄하면 설정에 등록한 상사 도장을 양도인의 상단 성명 옆과 하단 양도인 성명 옆 `서명 또는 인` 두 곳에 표시합니다. 원본의 해당 칸에 맞춰 비율을 유지하고 이름·전화번호·다른 당사자 칸을 가리지 않습니다.

양수인 성명을 입력하고 **출력용 이름 도장**을 선택하면 현재 이름으로 투명 배경의 빨간 도장 이미지를 만듭니다. 하단 양수인 확인자 이름도 일치하면 하단 서명란에 함께 표시합니다. 이름을 바꾸면 새 이름을 반영하고, 이름 공란·선택 해제·다른 문서 열기·계정 변경 시 이전 이미지를 정리합니다. 선택은 현재 작성·출력 화면에 적용하며, 저장 후 바로 인쇄할 때는 유지합니다. 문서를 새로 열면 다시 선택합니다.

회사 도장은 기존 비공개 Storage와 인증된 이미지 로더를 사용합니다. 같은 상사·계정의 최신 등록 파일인지 확인하고 이미지가 준비된 뒤 출력합니다. 등록 이미지 조회·다운로드·디코딩이 실패하면 인쇄를 중단하고 다시 확인하도록 안내합니다. 등록 도장이 없는 경우는 공란으로 두어 직접 날인할 수 있습니다. 다른 상사의 도장이나 기본 도장을 대신 표시하지 않습니다.

양수인용 도장은 입력 이름으로 생성하는 출력용 이미지입니다. 기존 고객 제출 서명·고객 인증·동의 상태를 수정하지 않으며, 도장 이미지나 선택을 계약서의 39개 저장 필드·localStorage에 추가하지 않습니다. 기존 문서 저장 RPC·원본 PDF/SVG·양면 A4 2장 구성은 유지합니다. 추가 DB 마이그레이션은 없습니다.

검증은 합성 투명 도장과 가상 인명으로 실행합니다. 운영에서는 정책·버킷 설정만 읽어 경리의 기존 소속 상사 이미지 조회 권한을 확인했고, 실제 등록 도장 파일이나 고객 자료는 추출하지 않았습니다. [검증 기록](transfer-document-seals-verification.json)을 참고하세요.
