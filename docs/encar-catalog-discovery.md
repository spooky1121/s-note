# 엔카 카탈로그 탐색 — v2.124

검색이 실행되어도 무관한 광고만 나오는 경우를 보완한다. 실제 실패 진단은 검색 2회, 결과 7개, 후보 6개 모두 다른 차량번호였으며, 직접 차량번호 검색 폼은 지원되지 않았다. 이 경우를 검색 키 누락이나 해당 차량의 광고 부재로 해석하지 않는다.

## 자동 조회

1. 기존 저장 후보와 공식 엔카 상세를 먼저 확인한다. 지원되는 GET 번호 검색 폼도 유지한다.
2. 차량에 선택된 제조사(`make`)와 모델 그룹(`group`)을 최소 탐색 힌트로 보낸다. 자유 입력 차명 전체나 고객 정보는 보내지 않는다. 힌트는 NFKC·공백 정규화와 길이·제어문자 검사를 거친다. 잘못된 힌트가 있으면 화면은 힌트를 생략하고 기존 번호 조회를 계속한다.
3. 공개 `https://encar.spb.ru/catalog/`에서 실제 제조사 링크, 다음 화면의 실제 모델 링크를 찾는다. 제조사·모델 값으로 주소를 생성하지 않는다. 정적 링크는 필터 폼 안에 있어도 읽을 수 있으나 폼 제출이나 스크립트 실행은 하지 않는다.
4. 같은 매물 카드 안에서 전체 차량번호와 광고 ID를 대조한다. 힌트·연식·VIN 일치는 최종 조건이 아니다. 모호한 카드나 추천 차량의 정보는 제외한다. 같은 모델의 실제 다음 링크만 최대 3페이지, 이 단계 8초 안에서 읽는다. 읽은 디렉터리는 한 요청 안에서 재사용한다.
5. 못 찾으면 기존 검색 API로 이어간다. 두 번째 검색도 전체 번호를 따옴표로 묶고 Trust Encar 범위를 추가하며, 유효한 모델 힌트가 있으면 함께 사용한다. 검색 횟수와 기본 검색 깊이는 늘리지 않는다.

탐색은 검색 키가 없어도 동작한다. 실제 페이지의 정적 링크·카드가 없거나 원문을 읽을 수 없으면 성공으로 처리하지 않는다. 전체 35초, 기존 외부 원문 최대 6개·누적 8초와 기존 후보 한도를 유지한다. 다음 페이지를 추측하거나 전체 사이트를 무제한 순회하지 않는다.

## 이미 아는 외부 주소

`광고 주소로 확인`은 기존 공식 엔카 주소 외에 허용된 Trust Encar 계열의 HTTPS `/auto/{광고ID}/` 주소를 받는다. 서버에서 호스트·경로·개수 한도를 다시 검사하고 주차량 번호를 대조한 뒤 한국 엔카 주소를 제공한다. 위장 도메인, 사용자 정보, 포트, 리디렉션, 쿼리·fragment·인코딩 우회는 허용하지 않는다. 외부 사이트로 인증 정보를 보내지 않는다.

기존 `encarLinks`의 출처 메타데이터와 소유자·revision CAS 저장을 사용한다. 공식 페이지가 명시하는 다른 번호·광고 종료·삭제·불명확 상태는 외부 확인으로 덮어쓰지 않는다. 외부 확인만 있으면 자동 촬영·가격 안내·판매예정가 변경을 실행하지 않으며 서버 가격 API를 직접 호출해도 같은 제한을 적용한다.

## 검증과 운영 범위

```sh
npm test --prefix tests/encar
node tests/encar/model-catalog-discovery.browser.cjs
node tests/encar/external-confirmation.browser.cjs
node tests/encar/detail-action.browser.cjs
node tests/encar/direct-price-change.browser.cjs
```

새 브라우저 검증은 실제 앱·`onRequest`·HTMLRewriter 파서를 합성 원문과 인증/DB에 연결한다. 기존 실패와 동일한 검색 결과 수·다른 번호 후보 수를 재현한 뒤, 제조사→모델 탐색·서버 확인·저장·복원·목록 재열기를 PC와 두 모바일 폭에서 확인한다. 실제 외부 원문 HTML을 fixture로 수집한 시험은 아니다.

연구용 웹 도구로 실제 공개 카탈로그의 제조사→모델 링크와 같은 카드의 번호·광고 ID는 확인했다. 사용자 요청 차량 1건은 확인한 링크 메타데이터만 DB에 연결하고 read-back과 링크 제외 전체 자료 해시를 대조했다. 실제 Cloudflare 원문 수신·운영 자동 탐색 종단 검증은 실행환경의 도메인 제한 때문에 별도 확인 대상이다. 운영 링크 연결과 자동 탐색 시험을 같은 증거로 취급하지 않는다.

진단에는 안전한 단계명·설정 여부·요청/페이지/일치 개수만 추가하며 원문·차량번호·고객 정보·자격증명을 넣지 않는다. 자세한 자동 시험 수와 소스 해시는 [검증 기록](encar-catalog-discovery-verification.json)에 남긴다.
