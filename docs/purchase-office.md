# 매입 업무 타일과 매입서류 — v2.131

경리의 기존 계약서 업무 메뉴를 **매입 업무**로 변경합니다. 첫 화면은 큰 서류 아이콘 4개를 **매입서류 · 매도서류 · 제시표 · 계약서** 순서로 표시합니다. PC는 한 줄, 모바일은 두 줄로 배치합니다.

매입서류를 누르면 기존 자동차양도증명서 입력폼이 열립니다. 다른 세 타일은 이후 업무를 위한 자리이며 현재는 준비 중 안내를 표시합니다. 폼의 타일 화면 복귀 버튼은 저장하지 않은 변경이 있을 때 확인합니다.

상단의 새 계약서 문구와 저장 문서 선택 드롭다운을 제거합니다. 저장한 문서는 **문서 목록** 아이콘의 목록 패널에서 다시 엽니다. 저장·미리보기 기능과 39개 필드는 유지합니다.

새 매입서류의 자동차 인도일은 한국 시간 기준 오늘로 설정합니다. 양도인 갑에는 확인된 소속 상사의 상사명·사업자 전화번호·사업장 주소를 넣고 하단 양도인 성명도 상사명으로 채웁니다. 저장한 문서와 사용자가 작성 중인 값은 자동으로 덮어쓰지 않습니다. 상사 등록값이 서식의 입력 한도를 넘으면 원문을 보존하고 해당 항목의 수정을 안내합니다.

폼 상단의 빨간 프린터 아이콘은 현재 입력값으로 원본 미리보기를 준비한 후 인쇄합니다. 글꼴·원본 이미지·입력 칸 넘침 검사와 현재 계정·상사 확인을 거치며 준비 중 중복 클릭을 막습니다. 미리보기 안의 인쇄 버튼도 유지합니다. 양도증명서 앞뒤 원본과 서명·날인 공란, A4 2장 출력은 그대로입니다.

기존 상사별 문서 저장 RPC와 데이터 구조를 사용하므로 추가 DB 마이그레이션은 없습니다. 검증 결과는 [purchase-office-verification.json](purchase-office-verification.json)에 기록합니다.
