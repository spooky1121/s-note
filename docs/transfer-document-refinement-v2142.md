# 양도증명서 날인·법인정보·서체 — v2.142

매입·매도 서류의 등록 법인인감 경계를 선명하게 하고 잉크 농도를 약 7% 낮췄다. 선택한 이름으로 생성하는 타원형 도장은 약 8% 연하게 하면서 네 곳의 낮은 압력 얼룩과 부드러운 가장자리를 적용했다. 등록 원본 이미지와 기존 물리 크기, 현재 회사의 원본 재확인·로그아웃 및 회사 전환 시 폐기 절차를 유지한다.

서류 입력값은 고딕체 500 굵기를 사용한다. 고정 라벨도 500으로 낮추고 제1~10조는 7pt, 유의사항은 5.4pt로 확대했다. 조항·유의사항 원문은 공백을 제외한 해시로 보존을 확인한다. 계약 당사자와 중고자동차매매계약서 위에는 2pt 간격 이중선을 그린다. 하단 테두리는 804pt, 안내는 826pt 이내에 배치하여 한 장 A4를 유지한다.

법인등록번호는 상사별 `zc_companies.corporate_number` 선택 필드로 관리한다. 설정의 상사 정보에서 조회·수정하며 관리자 RPC가 형식과 권한을 검사한다. 키를 보내지 않는 기존 클라이언트는 기존 값을 보존한다. 운영 제로카의 기존 사업자번호 842-86-03481을 확인하고 해당 상사 한 행에 법인번호 110111-0933056을 등록했다. 동명 상사를 포함한 다른 회사 값, 권한과 RLS는 변경하지 않았다.

등록된 법인번호가 있는 회사의 새 서류는 회사 명칭을 `(주) 상사명 (상품용)`으로 입력한다. 회사 측 상·하단 이름 옆에는 해당 회사 사업자번호를 출력한다. 기존 문서에서 동일 회사인 경우만 출력 이름을 정리하며 원래 저장값·편집 입력값을 덮어쓰지 않는다. 다른 회사나 수동으로 달리 입력한 이름에는 현재 회사 정보를 붙이지 않는다. 실제 인감 너비를 고려해 이름 영역을 제한한다. 한 줄에 읽을 수 있는 크기로 들어가면 한 줄을 우선하며, 매우 넓은 인감일 때만 두 줄로 표시한다. 취급상사와 법인번호의 라벨 크기는 같고 번호는 모두 9pt다.

새 서류 취급자 기본값은 작성자이며 차량을 선택하면 소유 딜러명으로 바뀐다. 사용자가 직접 수정한 취급자, 저장된 서류, 상대 매매업자 입력은 보존한다. 기존 39개 저장 항목·CAS, 이름 도장 선택 여부, 저장과 출력 권한, 비공개 회사 이미지 경로는 유지한다.

검증은 합성 자료만 사용하는 PC 1440px·모바일 390px × 매입·매도 브라우저 흐름과 A4 PDF, 도장 처리 전후 합성 이미지, 실제 운영 DB의 상사 정보 및 권한 검증으로 진행한다. 실제 종이 프린터 출력과 사용자 원본 인감의 해상도 자체 향상은 별도 확인 대상이다. 저해상도 원본에 없는 세부 획을 새로 만들지는 않는다.
