# 광고가격 캡처 OCR 시험

v2.111부터 일반 Encar 버튼에는 [자동 가격 확인](encar-auto-price.md)을 추가한다. 아래 수동 업로드는 별도의 보조 기능이다.

차량 상세 상단에서 Encar 옆의 이미지 아이콘(`광고 가격 캡처 인식`)을 누르면 캡처 업로드 시험창을 연다. 기존 엔카 가격 API와 별개의 수동 이미지 인식 경로이며, 엔카 새 탭을 자동 촬영하거나 읽지는 않는다.

## 사용 순서

1. 엔카의 판매가격이 선명하게 보이는 JPG·PNG·WEBP 캡처를 선택한다(최대 6MiB).
2. 미리보기와 입력 대상 차량을 확인한다. 큰 전체화면 캡처는 `원본 크게 보기`로 원금액을 대조할 수 있다.
3. `캡처에서 금액 찾기`를 누른다. 기존 Google Vision 인증·이미지 업로드 경로로 실제 인식을 요청한다.
4. `5,490만원 → 54,900,000원`처럼 표시된 **OCR 금액 후보**를 원본과 대조하고 직접 선택한다. 후보가 하나여도 자동 선택하거나 입력하지 않는다.
5. `금액 확인 후 입력`을 누르면 현재 차량의 판매예정가 입력칸만 바뀐다. 다른 미저장 메모·비고는 유지한다. 기존 파란 저장 아이콘으로 변경사항을 확정한다.

만원은 10,000원이므로 항상 **만원 × 10,000 = 원**으로 환산한다. 0원·음수·지수표기·상한 초과·잘못된 콤마·소수 원은 후보로 쓰지 않는다. 월납·할부·리스·렌트·보험료·신차가 등 부가 금액과 숫자가 잘리거나 억 단위가 누락될 수 있는 문맥은 보수적으로 제외한다. 여러 금액이 나오면 사용자가 판매가격을 선택한다. 후보가 없거나 불명확하면 `만원` 표시가 포함되도록 가격 부분을 더 선명하게 캡처한다.

## API와 데이터

- 기존 `POST /api/ocr`의 등록증 기본 동작을 보존한다. 가격 모드는 `POST /api/ocr?purpose=encar-price`이다. 잘못되거나 중복된 목적 값은 유료 인식 호출 전에 거부한다.
- 기존 Google Vision 키와 Supabase 로그인·활성 회원 검증, 동일 출처 제한, 이미지 파일 서명·크기·시간 제한을 재사용한다. 키를 브라우저에 전달하지 않는다.
- 가격 응답은 `ok`, `purpose`, `engine`, `requiresConfirmation:true`와 최대 20개의 `{id,display,priceWon}` 후보만 반환한다. 전체 OCR 원문·계정 이름·스크린샷 내용은 반환하지 않는다.
- 원본 미리보기는 로컬 blob URL이다. 이미지와 후보는 S-NOTE 장부·사진 저장소에 기록하지 않는다. 파일 교체·닫기·계정/차량 변경 시 URL과 후보를 정리하고 진행 중 요청을 취소한다.
- 판매예정가 입력은 현재 회사·계정·차량·상세창 세션과 마지막 인식 후보의 ID·표시값·원 환산값이 일치해야 한다. 경리·판매 완료·저장 중·충돌·미확정 쓰기는 입력을 허용하지 않는다.
- OCR 후보는 API에서 검증한 광고가격으로 표시하거나 `encarLinks.priceSource`에 넣지 않는다. 저장은 기존 판매예정가 편집 경로로만 처리한다. 새 DB 표·RLS·권한 변경은 없다.

## 검증 구분

사용자가 채팅에 보낸 모델 Y 화면의 금액은 눈으로 확인한 **5,490만원(54,900,000원)**이다. 인라인 원본 파일이 실행환경에 제공되지 않아 그 원본을 Google Vision으로 처리하지는 않았다.

별도로 `합성 OCR 시험`이라고 표시한 텍스트 이미지로 실제 Google Vision을 **1회 호출해 HTTP 200**을 받았다. `5,490만원 → 54,900,000원`을 읽었으며 함께 넣은 `월 납입금 29만원`은 제외했다. API 키와 전체 원문은 저장하지 않았다. 이 서비스 연결 시험은 사용자 원본이나 Cloudflare 운영 계정 시험과 구분한다.

정상·오류·권한·파일 교체·늦은 응답·기존 저장 및 등록증 회귀는 합성 HTTP/계정과 실제 Chromium으로 검증한다. 세부 결과는 `docs/encar-price-ocr-verification.json`에 기록한다. 배포 후 사용자는 업로드 시험창에서 자신의 원본 캡처를 직접 검증할 수 있다.
