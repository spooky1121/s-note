# 차량 검수 도우미와 목록 표시 안정화 — v2.234

설정 바로 위에 `차량 검수 도우미`를 추가했다. 경리 메뉴에는 설정이 없으므로 마지막에 표시한다. 기존에 저장한 메뉴 순서는 유지하며, 예전 순서에 새 메뉴가 없을 때만 설정 앞에 끼워 넣는다. 이후에는 다른 메뉴처럼 순서를 바꿀 수 있다.

## 검수 화면

- 기본 정보, 외관, 타이어·하부, 엔진룸, 실내·전장, 시동·계기판, 주행·정리의 7단계·21항목이다.
- 자체 SVG 위치 안내도, 단계 전환, 진행 표시, 미확인·확인·추가 확인 상태와 단계별 메모를 제공한다. 움직임 줄이기 설정을 따른다.
- 체크와 메모는 현재 접속의 메모리에만 남는다. 차량 장부에 저장하지 않으며 새로고침, 로그아웃, 계정·상사 변경 시 초기화한다.
- 기존에 검증된 상사 컨텍스트를 사용하고, 지연 로딩 응답은 해당 컨텍스트와 화면이 여전히 유효할 때만 반영한다. 첫 사용 전에는 도우미의 본문 JS와 CSS를 요청하지 않는다. 재진입은 같은 모듈을 재사용하며 실패 시 다시 불러올 수 있다.
- 초보자의 관찰·기록을 돕는 안내다. 법정 성능·상태점검, 전문 진단, 사고·침수·무결함 보증으로 표시하지 않는다. 고전압 작업, 뜨거운 냉각수 캡 개방, 지지되지 않은 차 밑 진입이나 위험한 시운전을 안내하지 않는다.

사용자가 공유한 ChatGPT Library 링크는 이 실행환경에서 본문을 읽지 못했다. 원본을 확인하거나 반영했다고 주장하지 않는다. 직접 첨부받으면 아래 공개 자료와 대조하여 추가할 수 있다.

## 공유 차량 목록

기존 병렬 읽기, 승인·버전 검사, 권한 취소, 상사·계정 분리는 유지했다. 처음 진입하거나 재검증할 때 목록 영역 높이를 예약하고 최종 배치가 준비된 다음 한 번에 표시한다. 여러 차량의 응답이 도착할 때마다 보이는 목록 위로 삽입하는 현상을 방지한다. 변경 없는 주기 갱신에는 로딩 표시나 재진입 애니메이션을 넣지 않는다. 사진의 지연 로딩은 그대로 유지한다.

상단바의 현재 메뉴명과 설명은 시각적으로 숨기되 페이지 제목은 접근성용으로 남겼다. 통합검색·우측 버튼을 유지하고 모바일 검색창의 빈 줄을 제거했다.
