# 공유 차량 수정 알림

공유된 차량을 상대 딜러가 수정하면 원 소유자와 다른 공유 딜러에게 변경 알림을 기록한다. 수정한 본인에게는 만들지 않는다. 원 소유자의 일반 차량 저장과 공유 차량 편집 모두 `zc_datasets`의 실제 갱신 트리거를 통과한다. 동일 값 저장·비공유 차량·고객정보만 바뀐 저장은 알리지 않는다.

상단 종 아이콘, 프로필 오른쪽 위와 프로필 메뉴의 ‘알림’ 옆에 빨간 신규 표시가 뜬다. 종 아이콘 또는 메뉴 알림을 누르면 가운데 팝업에서 차량·수정한 딜러·한국 시간·변경 항목의 전후 값을 확인한다. 표시한 알림 ID만 자기 계정의 읽음으로 처리한다. 알림은 로그인/계정 전환 직후, 화면 복귀 및30초 간격으로 갱신한다. 이메일/문자 발송은 하지 않는다.

기록 필드: 차명, 번호, 제조사, 연식, 차대번호, 주행거리, 색상, 매입일, 매입가, 판매예정가, 상태, 재고대출금, 금융사. 고객/주민번호/서명/암호문은 기록하지 않는다. 돈은 기존 저장 단위와 함께 기록하고 화면에서는 정확한 원 단위 콤마로 표시한다. 최근90일 중 최신100개를 표시하며 읽음 상태는 DB에 남아 다른 기기에서도 유지된다.

DB 파일은 `20261104155050_vehicle_change_notifications.sql`과 `20261104160202_vehicle_notification_scope_guard.sql`. 운영 Supabase에 적용했다. private RLS 표는 브라우저 직접 권한이 없고 public 진입점은 authenticated 전용 invoker다. 실제 함수는 비노출 스키마에서 auth.uid와 활성 회원·정확한 공유·원 소유자의 현재 상사를 검증한다. 다른 계정 ID로 읽거나 읽음 처리할 수 없다. 공유 해제/비활성/상사 변경은 이후 조회를 차단한다.

검증: 공유/알림 PGlite35개(실제 트리거, 전후 값, 본인 제외, 다른 계정 읽음 차단, no-op, 철회, 상사 이동, 익명 포함), Chromium1440/390/320px 알림 UI·금액·한국 시간·이스케이프·읽음·계정 변경·월별 그래프 말풍선. 운영 RLS·RPC 권한·트리거·초기0건·미인증 거부를 확인했다. 임의 운영 고객/차량 수정이나 공유 생성 없이 검증했다. 실제 운영 딜러 간 알림 수신·iPhone/Safari 직접 검증은 미완료다. Advisor 신규 공유/알림 API 경고는 없으며 기존 경고는 변경하지 않았다.
