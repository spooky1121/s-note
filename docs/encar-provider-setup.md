# Encar 분류 샘플 연결

차종 DB에 공급자 자료를 추가하기 전에 관리자 계정으로 제조사·모델·등급 원문과 상세 분류 구조를 소량 확인합니다. 이 단계는 기존 차량과 차종 DB를 변경하지 않습니다.

## 서버 키 등록

Cloudflare에서 **Workers & Pages → s-note → Settings → Variables and Secrets → Add**를 엽니다.

- 환경: **Production**
- 이름: `ENCAR_API_KEY`
- 값: 해당 공급자에서 발급받은 키
- 저장 방식: **Encrypt / Secret**

저장한 비밀값은 이후 배포에 적용됩니다. 기존 Tavily·Supabase·문자 발송 설정은 유지합니다. 키를 브라우저·HTML·Git·채팅에 넣지 않습니다.

[Cloudflare Pages 비밀값 설정](https://developers.cloudflare.com/pages/functions/bindings/#secrets)

## 연결 확인

1. S-NOTE에 상사 관리자 계정으로 로그인합니다.
2. **설정 → 차종 데이터 API**에서 키 등록 상태를 확인합니다. 등록 상태 조회는 공급자 호출 횟수를 사용하지 않습니다.
3. 제조사를 고른 뒤 **샘플 확인**을 누릅니다.
4. 매물 최대 3건과 첫 매물 상세를 조회하며 공급자 요청은 최대 2회입니다. 자동 대량 수집이나 자동 재시도는 하지 않습니다.
5. 제조사·모델·등급 원문과 상세 분류 코드를 확인합니다. **진단 복사**에는 키·로그인 토큰·계정 식별자·판매자 연락처를 포함하지 않습니다.

같은 상사·제조사를 짧은 시간 안에 다시 확인하면 최근 검증 결과를 재사용할 수 있습니다. 원래 확인 시각과 당시 잔여량을 표시하므로 새 공급자 응답과 구분해야 합니다.

키 등록 표시는 키 인증 성공을 뜻하지 않습니다. 실제 샘플 응답으로 연결을 확인합니다. 미등록으로 나오면 Production 설정과 변경 후 배포 여부를 확인합니다.

## 제공자와 자료 범위

- 제공자: Encar.com 본사 공식 API가 아닌 독립 서비스
- REST 주소: `https://api.encar-api.com/api`
- 인증: 서버의 `x-api-key` 요청 헤더
- 이번 조회: `/cars`, `/car?id=...`
- 무료 요금제 문서 기준: 하루 100회

공개 예시의 `Manufacturer`, `Model`, `Badge`를 확인합니다. Badge는 ‘2.4 프리미엄’처럼 등급·트림이 합쳐진 값일 수 있어 임의로 나누어 공식 분류로 저장하지 않습니다. 상세 분류·부모 코드와 자료 범위를 검증한 뒤 공급자 마스터를 설계하며 기존 직접 입력·정적 목록은 보존합니다.

현재 매물이 없는 단종/희귀 트림까지 포함하는 전체 분류 마스터 또는 일괄 자료 제공 여부는 별도 확인이 필요합니다.

가격과 판매자/고객 정보는 이번 응답에 포함하지 않습니다. 향후 금액을 연동한다면 공급자 Price 원본은 만원 단위이므로 S-NOTE의 원 단위와 구분해야 합니다.

[API 문서](https://www.encar-api.com/docs) · [필드 예시](https://www.encar-api.com/docs/listing-fields) · [요금](https://www.encar-api.com/pricing) · [서비스 소개](https://www.encar-api.com/faq)

## 검증 범위

자동 검증은 합성 응답과 가상 키를 사용합니다. 실제 키는 Cloudflare 서버 비밀값에서만 읽고 운영 화면에서 명시적으로 샘플 조회를 실행합니다. 실행 환경에 운영 로그인 세션이나 접속 권한이 없으면 진단 복사 결과로 실제 분류 매핑 검토를 이어갑니다.
