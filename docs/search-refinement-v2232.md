# 메뉴 브랜드 정리와 실시간 통합검색 (v2.232)

기준 main은 `1891e679c0a1673078049d79cd6735d26c7182c3`이다. 작업 트리가 깨끗한 것을 확인하고 별도 브랜치에서 진행했다.

데스크톱/모바일 메뉴의 ‘중고차 매매 관리 시스템’ 문구를 제거하고 로고 주변 간격을 정리한다. 원본 공식 PNG, 가로세로 비율과 최근 30% 축소한 그림 크기는 유지한다. 메뉴 로고 버튼은 44px 높이로 가운데 놓고, 모바일 메뉴 헤더의 좌우 여백을 맞춰 전체 너비 가운데에 정렬한다. 다른 화면의 로고와 문서 규격·상사 자료는 변경하지 않는다.

상단 통합검색창은 기존 폭/높이를 유지하면서 하늘색 테두리·연한 배경·파란 돋보기로 강조한다. 선택 시 기존 배경 흐림과 같은 form의 Popover를 유지하고, 결과는 검색창 아래에 표시한다. 모바일 키보드로 visualViewport가 작아지면 실제 남은 높이로 팝업/결과 높이를 제한하고 결과 내부를 스크롤한다. 다른 검색창의 위치 계산 동작은 유지한다.

입력 후 220ms 동안 추가 입력이 없으면 기존 통합검색 bridge로 자동 검색한다. 한글 IME 조합 중에는 조회하지 않고 완료 후 검색한다. 새 입력은 이전 결과를 즉시 지우고, 이전 검색의 응답은 최신 입력·계정·상사 문맥이 맞을 때만 표시한다. 빈 입력, 닫기, 경로 변경, 로그아웃과 비활성 탭은 대기 작업을 취소한다. 장기 결과 캐시를 추가하지 않으며 기존 진행 중 조회 공유와 돋보기/Enter 재검색을 유지한다. 방향키로 실제 결과 버튼에 이동하고 Enter로 기존 업무 화면을 연다.

기존 권한 확인·비금융 투영·공유차량 권한 재확인·금액 잠금·업무 기능은 유지한다. 인증/DB/RLS/운영 설정·문서/상사 로고/도장/서명은 변경하지 않는다. 모든 검증은 합성 계정·차량·고객을 쓰고 외부 운영 요청을 가로챈다.

운영 웹 직접 열기는 실행환경의 도메인 접근 제한으로 수행하지 않는다. 실제 Safari/모바일 키보드는 별도 확인 대상이며, 자동화는 Chromium과 줄인 visualViewport 모의로 검증한다. 배포는 검증한 소스 트리 일치 및 정확한 운영 커밋의 S-NOTE Pages 성공으로 확인한다.
