# 엔카 광고 검색 보완 — v2.115

차량 상세와 목록의 Encar 버튼은 차량번호로 광고번호 후보를 찾은 뒤, 공식 엔카 상세 페이지의 전체 차량번호와 광고 중 상태를 확인한다. 외부 사이트나 검색 결과만으로 광고를 확정하지 않는다.

## 확인한 문제와 변경

- 실제 차량번호·광고번호가 함께 나오는 지역별 `*.trust-encar.ru` 주소가 기존 후보 인식에서 제외됐다. 엄격히 검사한 해당 주소에서도 광고번호를 추출한다. 외부 주소 자체를 열거나 공식 광고로 저장하지 않는다.
- 검색 결과의 앞쪽에 관련 없는 광고가 많으면 뒤쪽의 정확한 차량번호 결과가 여섯 후보 제한에서 탈락했다. 전체 차량번호가 일치하는 결과를 우선 검사한다.
- 오래된 브라우저·KV 후보가 검사 한도를 모두 쓰면 신규 검색 후보를 검사하지 못했다. 각 힌트 출처 최대 6개, 합계 12개와 별도로 신규 발견 후보 6개를 확보한다. 전체 검사는 최대 18개이며, 실패한 후보는 KV에 다시 저장하지 않는다.
- 공개 카탈로그 홈페이지에는 제조사 선택만 있고 별도 `/catalog/` 화면에 차량번호 입력이 있었다. 홈페이지에서 실제로 관찰한 같은 출처의 카탈로그 링크만 한 번 따라가 기존 GET 폼 탐색을 적용한다. 입력 필드·요청 주소를 추측하지 않는다.
- 느린 카탈로그 조회가 전체 시간을 소진하면 검색 API가 실행되지 못했다. 검색 API가 설정된 경우 카탈로그 단계 전체를 8초로 제한해 다음 검색 시간을 남긴다. 전체 35초, 요청별 10초, 공식 상세 동시 요청 3개의 제한을 유지한다.
- 카탈로그 실패가 이후 검색 API의 인증·할당량 오류를 가리거나, 접속 상태 오류가 일반 네트워크 오류로 표시됐다. 허용된 오류 코드로 원인을 구분하고 기존 로그인 재검사·접속 차단·수동 광고 확인 기능을 유지한다.

`ENCAR_API_KEY`와 자동 촬영 토큰은 이미 찾은 광고의 가격 확인에 쓰인다. 광고번호를 찾는 기능의 설정을 대신하지 않는다. 공급자 문서에 없는 차량번호 검색 매개변수는 추가하지 않았다.

## 실제 차량 대조와 검증 범위

현재 매입 재고 17대의 차량번호·저장된 광고번호를 읽기 전용으로 대조했다. 공개 자료에서 전체 차량번호가 보인 경우는 14대, 차량번호와 광고번호 쌍이 관찰된 경우는 13대였다. 이 13대의 근거는 개별 외부 매물 카드 6대, 카탈로그 카드 3대, 검색에 캐시된 문구 4대다. 캐시된 문구는 현재 광고 중임을 보장하지 않는다. 나머지 3대는 확인되지 않은 상태이며 광고 없음으로 판정하지 않았다.

관찰한 개별 매물 주소 여섯 건을 후보 파서에 넣으면 이전 코드는 다섯 건, 수정 코드는 여섯 건을 인식했다. 실제 일치 결과 앞에 합성 무관 결과를 놓는 별도 순서 검사에서도 누락을 재현하고 수정했다. 이 검사는 실제 검색 API 응답이나 공식 광고 검증을 재생한 것이 아니다.

실행환경의 엔카·카탈로그 직접 접속 제한으로 공식 엔카의 현재 광고 상태를 끝까지 확인한 실제 차량은 **0대**다. 공개 카탈로그의 차량번호 입력은 화면에서 관찰했으나 실제 HTML 폼 속성·요청 매개변수는 확인하지 못했다. 해당 경로의 자동 테스트는 합성 폼을 사용한다. 운영 로그인·유료 검색 API·자동 촬영을 이용한 실제 전체 흐름은 추가 확인이 필요하다.

차량번호와 계정별 대조 자료는 저장소 밖에 비공개로 보관한다. 이 작업은 운영 차량·가격·금융·고객 자료와 DB 스키마를 변경하지 않는다.

## 재현

```bash
npm test --prefix tests/encar
node tests/encar/detail-action.browser.cjs
node tests/encar/direct-price-change.browser.cjs
```

자동 테스트 763개, Chromium의 상세 조회 5그룹과 기존 가격 저장 7그룹이 통과했다. 브라우저 검사는 PC 1440px, 모바일 390px·320px 및 합성 서버 응답을 사용한다. 접속 권한 보류·실패 시 링크 보존, 광고 확인·저장·재열기, 판매 상태 전환, 가격 저장의 미저장 입력 보존을 확인했다. 독립 검토에서 발견한 신규 후보 한도 소진과 시간 초과 안내 누락도 수정했다.

운영에서 문제가 이어지면 Encar 버튼의 **진단 복사** 결과로 검색 후보 수·정확한 차량번호 일치 수·공식 상세 검사 수·오류 코드를 구분한다. API 키나 로그인 토큰을 보내지 않는다.
