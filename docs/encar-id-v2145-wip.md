# 외부 광고 ID 조회 전환 — v2.145 작업본

## 상태: 운영 배포 전, 실제 검색 연결 미완료

기준 운영 커밋은 `07494c5cec445d741267ca0ca3b8a21d4d5eb533`(v2.144)이며 작업 브랜치는 `codex/external-encar-id-v2.145`다. 운영에 병합하지 않는다. 실제 세 사이트의 검색 요청을 확인하고 어댑터를 연결하기 전까지 새 API의 기본 처리기는 인증 후 `503 LOOKUP_NOT_CONFIGURED`를 반환한다. 모의 테스트의 성공은 실제 사이트 검색 성공을 의미하지 않는다.

## 구현한 범위

매입관리·상사매입의 목록·카드와 경리 읽기 화면에 엔카 항목을 복원했다. 저장된 광고가 없어도 차량번호가 유효하면 조회 버튼이 있다. 상세 상단 버튼과 목록 버튼은 새 `SnoteEncarId`를 사용한다. 외부 창을 열거나 한국 엔카를 방문하거나 광고 링크·가격·차량을 저장하지 않는다. 결과 팝업은 광고 ID와 확인 버튼을 표시하고, 실패·취소·계정/차량 전환 시 오래된 결과를 폐기한다.

새 인증 API는 `POST /api/encar-id`의 `{plate}`만 허용한다. 실제 Auth 사용자와 활성 상사 멤버십을 확인한다. 순차 엔진은 Carnect → GLOAR → Trust 순서를 지키고 검증된 첫 결과에서 끝낸다. 번호판 전체·명시 광고 ID·출처 호스트를 확인하고 시간 제한·요청 취소·실패/결과없음 구분을 적용한다. 실제 검색 전송은 주입형 인터페이스로 분리했고 검증되지 않은 기본 전송은 넣지 않았다.

이어받기 검토에서 클라이언트의 세션 토큰 대기·응답 수신·본문 읽기가 취소 신호를 따르지 않아도 전체 시간 제한과 닫기가 완료되도록 보완했다. 본문 취소 완료를 무한히 기다리지 않으며 늦게 도착한 토큰/응답은 새 조회에 영향을 주지 않는다. 서버의 인증/멤버십 통신·본문 오류는 외부 검색 실패 대신 `AUTH_UNAVAILABLE`로 구분한다. 이 보완은 실제 검색 어댑터 연결을 의미하지 않는다.

기존 `snote-encar-link.js`와 캡처 가격 UI를 제거했다. 과거 `/api/encar`, `/api/encar-auto-price`는 외부 호출 없이 410을 반환한다. 옛 광고 저장·자동 가격 변경 브리지를 제거하면서 재고·문서 공유의 공통 차량 범위 가드는 보존했다. 재고 시작일 저장의 직렬 대기열은 전용 `snoteVehicleFinanceTail`로 분리한다. 기존 차량의 `encarLinks` 자료는 삭제하거나 덮어쓰지 않는다.

## 공개 페이지 조사 메모

- Carnect: https://carnect.biz/catalog?tab=encar 는 `License plate` 입력과 상세 보기 UI를 표시한다. 공개 색인에서 `38다6738`의 경로 https://carnect.biz/car/42974024 를 관찰했지만, 이전 한국 광고번호 42974020과의 현재 대응은 미확인이다. 경로 번호만 사용하지 말고 실제 상세의 원본 광고 필드를 확인해야 한다.
- GLOAR: https://gloar-data.com/en/catalog 는 VIN/Lot/번호판 검색 입력을 공개한다. https://gloar-data.com/en/lot/tesla-model-y-2022-43185167-a30e56de-97c3-45e6-913f-587c1d35bdb3 공개 본문에 번호판 `18허0458`과 광고번호 `43185167` 및 원본 엔카 링크가 함께 표시되었다.
- Trust: https://encar.spb.ru/catalog/ 와 https://encar.spb.ru/auto/43185559/ 공개 본문에서 `293오4280`과 Lot `43185559`를 확인했다.
- 위 내용은 공개 본문 확인이고 검색 요청 재현 검증이 아니다. 과거 광고와 현재 광고의 동일성 또는 계속 판매 중인지는 별도 확인해야 한다. 사용자 표의 7건 소요시간은 사용자 제공 정보이며 이 환경에서 재측정하지 않았다.

## 남은 작업

1. 새로 게시한 환경을 선택한 새 작업에서 다음 사이트의 원문 HTML·JS와 실제 번호판 검색 요청을 확인한다: `carnect.biz`, `*.carnect.biz`, `gloar-data.com`, `*.gloar-data.com`, `encar.spb.ru`.
2. `search(provider,{plate,signal})` 계약의 실제 어댑터를 구현한다. 사이트 검색이 실패하거나 제한되면 재시도 폭주·프록시 우회 없이 다음 순위로 진행한다. 공개 UI를 정상 조작하는 경우에도 실제 화면과 요청을 검증한다.
3. 외부 사이트의 내부 경로 번호를 한국 엔카 광고 ID로 추측하지 않는다. 특히 Carnect의 과거 38다6738 경로와 한국 광고 ID가 달라질 수 있어 현재 원본 링크/명시 ID 필드를 확인해야 한다. 재등록 가능성도 있어 과거 값과 다르다는 사실만으로 오답으로 단정하지 않는다.
4. 어댑터를 `createEncarIdHandler({search:...})`에 연결한 뒤 실제 검색·순서·중단·정확성·반복 실행을 검증한다. 그 후 전역 릴리스/캐시 버전을 2.145로 올리고 PR·Cloudflare 사전 배포·운영 배포를 검증한다.

## 환경 제한과 현재 증거

현재 실행환경 ID는 `ccarenv_b64_Y2NhcmVudl8zNDViOWVlYzljYjQ4MTkxODQ4YjU0MzdmNmY4YzcxNA`이며 관측된 spec revision은 1이다. 사용자는 새 도메인을 추가해 게시했다고 확인했지만 현재 인스턴스의 허용 목록은 기존 Supabase/Vision뿐이고 세 사이트의 직접 연결은 모두 CONNECT 403으로 차단된다. 설정을 다시 추가하도록 반복 요청하지 말고 게시된 환경을 선택한 새 작업에서 확인한다.

2026-11-19 이어받기에서도 같은 환경 ID와 revision 1을 확인했다. 사용자는 이어받기 요청을 **새 작업이 아니라 기존 대화에 입력했다**고 확인했다. 게시가 실패했다고 추정하거나 같은 도메인 추가를 반복 요청하지 않는다. 별도 새 작업을 만들고 Cloud의 게시한 S-NOTE 환경을 선택해야 한다. 현재 작업에는 실행환경 설정 변경 도구가 제공되지 않는다. 새 작업에서도 먼저 관측된 허용 목록과 실제 연결을 확인하고, 미반영이면 선택한 환경을 점검한다.

제공된 웹 탐색 도구로 공개 카탈로그·상세의 번호판·ID 표시는 확인했으나 실제 검색의 파라미터/API는 확인되지 않았다. 상세 본문 확인만으로 전체 번호판 검색이 구현되었다고 보고하지 않는다. 실제 사용자 차량·고객 자료나 비밀번호는 조회하지 않았다.

검증 자료는 `/workspace/work/encar-id-v2145`에 있다. 새 API·엔진·폐기 엔드포인트·독립 파서·앱 회귀 248개가 통과했다(클라이언트 대기/취소 5개, 인증 오류 구분 1개 추가). 실제 앱의 PC/모바일 ID 전용 UI 모의 테스트도 이어받기 수정 후 재확인했으며, 기존 재고 시작일 브라우저 회귀는 앞선 작업본에서 통과했다. 기존 흐름을 전제로 하는 테스트는 현재 게이트에서 제외한 이유를 `tests/encar/README.md`에 기록했다. 운영 배포 성공 또는 실제 세 사이트의 검색 성공으로 표현하지 않는다.
