# Windows 스캐너 자동 연결 · v2.254

최초 설치·브라우저 연결 허용 후에는 경리 스캐너 화면의 **스캔**으로 연결, 장치 검색, 스캔을 이어간다. 단일 장치 또는 기억한 장치는 자동 선택하고, 처음 여러 장치가 검색되면 한 번 선택한다. 스캔 결과는 미리보기에서 **저장**을 눌러야 기존 상사별 비공개 보관함에 업로드된다.

## 설치와 연결

- Windows 10/11 x64용 자체 포함 실행 파일 `SnoteScannerSetup.exe`, 도우미 1.1.0 / 로컬 프로토콜 2.
- **설치하고 Windows 자동 실행**으로 현재 사용자 폴더에 설치하고 HKCU 시작 앱을 등록한다. 재시작 시 창 없이 알림 영역에서 준비한다. 관리자 권한·방화벽·인증서·운영 DB 설정을 바꾸지 않는다.
- 브라우저 로컬 연결 권한과 최초 PC 연결 허용은 사용자가 승인한다. 기존 1.0 도우미가 실행 중이면 먼저 직접 종료한다.
- WIA 드라이버로 인식되는 여러 제조사의 스캐너를 지원한다. TWAIN 전용·eSCL 전용·인쇄 전용 장치는 이 구현의 직접 스캔 대상이 아니다.

## 연결 보호

- 브라우저는 IndexedDB에 비추출 P-256 개인키를 저장하고 공개키 소유를 증명한다. 원본 로그인 토큰·스캔 이미지·도우미 접근 토큰을 영구 저장하지 않는다. 저장소를 쓸 수 없으면 현재 화면에서만 연결한다.
- Windows 승인은 사용자별 DPAPI로 보호하며 S-NOTE 출처·상사/사용자 범위·공개키에 묶인다. 새 세션은 새로운 메모리 접근 토큰을 발급받는다.
- 허용 출처, 루프백 Host, 일회용 만료 challenge, 본문 크기, 승인 대기 제한, 작업 소유권 검사를 유지한다. 운영 도우미의 구형 연결번호 경로는 비활성화한다.
- 연결 승인 초기화는 진행 중 승인과 토큰도 함께 무효화한다. 화면 종료·취소·계정 전환 뒤 늦은 장치 응답이나 스캔 결과로 새 동작을 시작하지 않는다.
- 브라우저 신뢰 기록과 장치 선택은 사용자별이다. 실제 업로드는 기존 로그인·역할·상사 범위 검사를 그대로 거친다.

## 재현 검증

실제 고객 자료 대신 가상 계정·가상 장치·생성 이미지만 사용한다.

- `node tests/scanner-view-model-v2247.test.cjs`: 기존 화면 모델 13개.
- `node tests/scanner-client.test.cjs`: 기존 업로드 클라이언트 12개.
- `node tests/scanner-device.test.cjs`: 기존 장치 클라이언트/화면 18개.
- `node tests/scanner-device-autoconnect-v2254.test.cjs`: 키/서명·자동 연결·취소 경계 12개.
- `dotnet run --project tools/scanner-connector/ScannerConnector.Tests/ScannerConnector.Tests.csproj --configuration Release`: 네이티브 프로토콜 38개. Linux와 Windows CI에서 실행한다.
- Windows CI는 자체 포함 실행 파일을 빌드하고 `--self-test`로 이미지 처리와 DPAPI 저장·변조 거부·범위 분리·초기화 및 포함 라이선스를 확인한다. 물리 장치를 열지 않는다.
- `node tests/scanner-device-flow-v2250.browser.cjs`: 실제 Chromium IndexedDB와 합성 도우미로 PC/모바일 원클릭·명시 저장·취소·오류·장치 선택을 검사한다. 18개 검증과 별도로 `SCANNER_DEVICE_FLOW_GROUP=login-memory`로 실제 앱 새로고침·다른 상사 로그인·원계정 재로그인 1개를 통과했다. 비추출 키와 올바른 계정의 장치 설정을 재사용하고 접근 토큰은 새로 발급함을 확인했다. 실행 환경의 브라우저 로컬 네트워크 접근 제한 때문에 실제 사용자 PC의 HTTPS→루프백 권한 확인을 대신하지 않는다.

검증된 `scanner-connector-v1.1.0` 태그 릴리스를 먼저 발행한 뒤 웹을 배포한다. 설치 파일과 ZIP의 SHA256, 소스 커밋을 함께 제공하고 기존 1.0 릴리스는 바꾸지 않는다. 실제 복합기·Windows 자동 시작·사용자 PC 최초 권한·실제 운영 업로드와 설치 파일 코드 서명은 미검증/미제공이다.
