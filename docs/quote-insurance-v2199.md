# 성능보증보험료와 견적서 미리보기

- 차량 상세·신규 등록·비용 설정의 기본 `performanceInspection` 표시 이름을 성능보증보험료로 통일한다. 기존 저장키와 금액, 딜러별 사용자 항목은 유지한다. 예전에 같은 이름으로 만든 사용자 항목도 설정을 불러올 수 있다.
- 견적서를 열 때 차량 상세의 현재 성능보증보험료를 원 단위로 가져온다. 저장 전 수정과 명시적 빈칸·0원도 반영한다. 견적서에서 직접 수정한 보험료는 다른 비용을 고칠 때 유지하며, 차량 비용을 자동으로 덮어쓰지 않는다. 새로 열면 차량의 현재 비용을 다시 가져온다.
- 번호판 교체비는 음수 입력과 쉼표 표시를 지원한다. 음수는 이전비용 소계·최종 견적금액·이전비 입금액에서 차감한다. `-`와 `-0`의 입력 중 상태는 유지하고 합계의 반올림 결과는 `-0` 대신 `0`으로 표시한다.
- 계약서·인수증에 쓰던 화면 맞춤 모듈에 견적서를 연결했다. 문서 전체를 화면 폭과 높이에 맞추고, 동일한 닫기·인쇄 아이콘을 문서 오른쪽 위에 배치한다. 화면 규칙만 확장하며 A4 인쇄 양식은 유지한다.
- 기존 소득정산 문서의 원본 비교 해시와 저장 데이터는 변경하지 않는다. 운영 DB·설정·문자는 변경하지 않는다.

검증은 가상 계정·차량·계좌와 외부 통신을 차단한 브라우저에서 수행한다. 금액 계산·보험료 자동 반영·직접 수정·원/만원 호환·비용 저장 후 재열기, 다양한 화면 크기와 키보드에 따른 가시영역 변화, 인쇄 PDF를 확인한다. 실제 모바일 기기의 키보드 동작은 별도 확인이 필요하다.

기존 공유 변경 알림 브라우저 시험에는 그래프의 이전 문구를 기대하는 정규식이 남아 있다. 알림 라벨과 금액은 현행 그래프 문구를 시험 실행 메모리에서만 맞춰 별도로 검증했으며, 관련 그래프 제품 코드는 수정하지 않았다.
