# v2.207 화면 너비에 따른 대시보드·메뉴

고정된 작은 화면 높이에 맞춰 압축하던 배치를 화면 너비와 실제 본문 공간에 따라 다시 구성한다. 이전의 높이별 압축 규칙과 업무 바로가기를 제거한다. 작은 화면에서 글자를 계속 줄여 모든 내용을 억지로 한 화면에 넣지 않고, 읽을 수 있는 크기를 유지하며 필요한 세로 스크롤을 허용한다.

- 총투자금·재고대출금·현금투자금·이번 달 수익·이번 달 매입·이번 달 판매·올해 수익을 각각 독립 카드로 표시한다. 숫자 아래 설명은 제거한다.
- 넓은 본문은 가로 공간을 활용하고, 좁아지면 카드 행과 달력·일정 목록·실적·정산의 열 배치를 조정한다. 제목과 본문 카드의 시작선을 맞춘다.
- 왼쪽 메뉴는 충분한 화면에서 전체 이름을 표시하며 화면이 좁아지면 폭을 줄인다. 이름이 잘리기 전 아이콘 레일로 전환하고, 마우스·키보드로 메뉴 이름을 확인할 수 있다. 작은 모바일 화면의 기존 메뉴 드로어와 하단 탐색은 유지한다.
- 아이콘 상태에서도 접근성 이름·현재 메뉴·금융 잠금 표시·기존 메뉴 재정렬과 권한을 유지한다. 새 셸 스타일은 로그인·출력 서류에 적용하지 않는다.
- 개인 일정·읽기 전용 매입/판매일·정확한 더보기 건수·금액 및 수익 숨김·소유권 범위·저장과 출력은 유지한다. 일정 요약을 화면 높이 때문에 1개로 줄이던 조건은 제거한다.

검증은 실제 앱을 가상 계정·차량·일정으로 실행해 수행한다. 넓은 화면부터 태블릿·모바일까지 스크린샷과 DOM 크기를 확인하고, 같은 로그인 상태에서 브라우저 크기를 바꿔 입력 중인 일정·현재 메뉴·금액이 유지되는지 확인한다. 금액 계산·역할·금융 잠금·메뉴 이동/재정렬·문서 인쇄도 관련 회귀로 확인한다. 운영 고객 데이터·DB 설정·문자 서비스를 사용하거나 변경하지 않는다.

실제 본문 폭이 1160px 이상이면 7개 지표를 한 줄로, 680px 이상이면 4+3으로, 그보다 좁으면 2열로 배치한다. 달력과 일정 목록도 본문 컨테이너 폭에 따라 나란히 또는 세로로 배치한다. 우측 공간이 좁은 1024px 화면에서는 일정 카드를 한 열로 보여 제목과 시간을 보존한다.

사이드바는 1121px 이상에서 180~228px로 줄어들며, 761~1120px에서는 76px 아이콘 레일, 760px 이하에서는 기존 모바일 메뉴를 사용한다. 대표·딜러·경리와 금융 잠금 유무를 12개 화면 폭에서 각각 확인했다. 확장 메뉴의 가장 좁은 폭에서도 라벨이 잘리지 않고, 아이콘 상태의 설명과 기존 재정렬 접근성 안내가 함께 유지된다.

UI 검토는 1920×1080, 1600×900, 1440×900, 1280×800, 1024×768, 900×900, 768×900, 390×844에서 수행했다. 금융·날짜 계산 모델은 이전 운영판과 동일하며, 견적서 1쪽·계약서 2쪽의 원래 인쇄 호출·A4 규격·서명·도장도 가상 브라우저로 확인했다. 실제 휴대폰 키보드는 짧은 viewport로 모사하며 운영 계정으로 시험하지 않는다.
