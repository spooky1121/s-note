# 웹 로고 눈 애니메이션 · v2.216

로그인과 업무 화면의 S-NOTE 로고에 사용자가 제공한 크리스마스 SVG를 적용한다. SVG는 내용과 애니메이션을 수정하지 않고 그대로 보관한다.

- 대상: 기본/동적 로그인 헤더, 데스크톱 사이드바, 모바일 메뉴, 고객 입력 화면, 계정 복구 화면, 운영자 로그인·메뉴.
- 좁은 사이드바는 기존 S 심볼 자리에 같은 SVG의 S 부분을 표시한다. 기존 PNG 전용 확대·분리 규칙은 계절 로고에 적용하지 않는다.
- 로고의 홈 이동 동작, 로그인·권한·고객 입력 기능은 유지한다. 업무 문서의 인쇄용 로고와 favicon은 기존 PNG를 유지한다.
- SVG 로딩 오류 시 기존 PNG로 복구한다. 동적으로 추가되는 로그인 헤더에도 같은 복구 처리를 적용한다.
- SVG의 모션 감소 설정을 유지한다. Chromium에서 외부 SVG 이미지 내부로 모션 감소 설정을 전달하지 않는 경우를 확인하여, 페이지 설정이 모션 감소일 때는 기존 정지 PNG를 표시한다. 설정을 바꾸면 바로 반영하며, 실제 로딩 실패 상태는 유지한다. 외부 이미지·스크립트 참조를 추가하지 않으며 기존 CSP를 유지한다.
- 계절 로고 CSS는 고객·운영자 웹페이지의 일반 인쇄에서도 크기를 유지한다. A4 업무 문서 양식은 변경하지 않는다.

## 검증

브라우저 검증은 가상 계정·응답만 사용한다. 운영 고객 데이터, DB 설정, 서버 환경 설정은 변경하지 않는다. 테스트 결과와 실제 장치에서 확인하지 못한 범위는 배포 검증 기록에 남긴다.

고객 화면의 기존 `readable-type.js`가 발생시키는 인라인 스타일 CSP 위반 2건은 계절 변경을 제거한 기준 HTML과 동일하다. 이번 변경에서 기존 정책을 완화하거나 다른 모듈을 수정하지 않는다.

- `node tests/seasonal-logo-v2216.browser.cjs`: 3개 그룹 통과. 가상 로그인·홈 이동·반복 메뉴 이동, 1440/1024/390px, 기존 문서 PNG, 초기/동적 SVG 503 복구, 고객·계정복구·운영자 화면과 기존 CSP, 인쇄 시 로고 크기를 확인했다.
- 실제 이미지 캡처에서 일반 모드의 눈 움직임을 확인했다. 모션 감소 모드의 PNG는 480ms 간격 캡처가 동일하며, 실행 중 설정 전환도 반영된다.
- JS 구문 검사와 `git diff --check` 통과. 변경 전후 제품 파일 해시를 고정하여 검사했다.
- 실제 모바일 기기·Safari/Firefox 및 물리 프린터는 검증하지 않았다. 운영 사이트 직접 접속은 실행환경 정책으로 제한되어, 배포는 검증된 파일 트리와 정확한 커밋의 S-NOTE Pages 완료 상태로 확인한다.
