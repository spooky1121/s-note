# 검색창·차량 상태 메뉴 (v2.224)

차량 상태 선택은 둥근 흰색 메뉴로 표시한다. 선택된 상태는 판매중(초록), 계약중(빨강), 판매완료(파랑)의 글씨와 테두리만 사용하며 배경은 투명하다. 계약중 차량 자체의 목록 강조는 유지한다.

원래 `select`의 옵션·값·비활성화·권한과 `changeVehicleStatus`를 유지한다. 다른 옵션 선택 시 기존 `change`를 한 번만 전달하며, 확인 전에는 상태를 바꾸지 않는다. 읽기 전용 상태나 모바일 카드에서 숨긴 상태 항목에 편집 버튼을 추가하지 않는다. 키보드·Esc·바깥 클릭·모바일 뒤로가기로 메뉴를 닫을 수 있다. 인쇄 및 스크립트 미실행 시 기본 select를 사용한다.

차량·재고금융·고객·휴지통·서류함·운영자의 실제 검색 입력을 같은 흰색 검색창으로 표시한다. 검색 시 원본 입력 및 폼의 DOM 관계를 유지한 채 native popover로 표시하고, 주변 화면에 기존 상세 팝업과 같은 4px 흐림을 적용한다. 검색어·조합 입력·필터·폼 제출 이벤트를 복제하지 않는다. 원래 자리는 크기·flex 순서·grid 위치를 가진 placeholder로 유지하고 닫을 때 제거한다. 로그인·주소·금액·메모 입력은 검색 대상으로 취급하지 않는다.

닫기·Esc·바깥 클릭·Tab·모바일 뒤로가기와 화면 전환·로그아웃에서 임시 레이어를 정리한다. 바깥 클릭은 검색을 닫으며 아래 차량이나 버튼을 동시에 실행하지 않는다. Popover 미지원 환경은 기존 검색 입력과 상태 메뉴의 일반 배치를 유지한다. 모바일 팝업 history는 popover와 기존 dialog를 실제 열린 순서에 따라 처리한다.

## 검증

가상 계정·차량·API 응답만 사용하며 운영 데이터 및 설정은 변경하지 않는다.

- `node tests/search-status-style-v2224.browser.cjs`: 1440/390/360px 검색·상태 메뉴, 실제 검색 결과, 원본 DOM·폼·목록 배치, 확인·취소·판매가/판매일 검증, 키보드, 읽기 전용/숨김, 모바일 뒤로가기. 고객·휴지통·서류함·운영자 검색은 1440/390px.
- `node tests/mobile-popup-history.browser.cjs`: 390/320px 기존 팝업과 독립 고객 화면 뒤로가기. 지연 로딩 서류 모듈 및 달력 조회를 가상 테스트에서 명시적으로 준비한다.
- `node tests/normal-login.browser.cjs`: 일반 로그인·동시 세션·로그아웃·권한 확인·배경 이미지 지연 로딩 회귀.
- `node tests/operator-console.browser.cjs`: 운영자 권한·데이터 편집·충돌 방지·로그아웃·1440/1024/390/320px 회귀.
- JS 문법 검사, `git diff --check`, 실제 브라우저 화면 촬영.

브라우저 자동화는 Chromium으로 수행한다. 실제 휴대전화의 OS 키보드와 Safari 실기기는 별도 검증 대상이다. 운영 사이트의 직접 브라우저 접속은 실행환경 제약이 있으므로 운영 반영 확인은 정확한 커밋의 Cloudflare Pages `s-note` 빌드 결과와 검증한 소스 트리 일치 여부로 남긴다.
