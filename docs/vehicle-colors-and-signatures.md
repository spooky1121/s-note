# 차량 목록 색상과 고객 계약서 서명

## 차량 목록

대시보드·차량 관리·매입·판매·재고금융·선재고·차량별 수익 및 정산·고객관리의 차량명 다음에 색상을 표시합니다. 표에는 `색상` 열을, 휴대폰 카드에는 차명 바로 옆에 작은 색상 표시를 넣습니다. 색상명은 툴팁과 접근성 설명으로 확인합니다.

기존 차량에 저장된 `color` 값을 읽습니다. 등록 화면의 기본색·펄·무광 등 35개 색상과 한글·영문 별칭을 지원하고, 인식한 두 색의 투톤은 나누어 표시합니다. 흰색과 밝은 색에도 테두리가 있습니다. 색상이 없거나 인식할 수 없으면 빨간색 물음표 아이콘으로 표시합니다.

선재고와 별도 금융 장부에는 색상이 없는 행도 있습니다. 차량 연결키 또는 차량번호와 소유 직원·담당자 정보가 일치하는 차량 하나가 있을 때만 차량의 색상을 사용합니다. 중복되거나 매칭되지 않은 내역에는 색상을 추측하여 넣지 않습니다. 표시는 차량 및 금융 금액을 변경하거나 추가로 저장하지 않습니다.

## 판매 계약서

판매 진행에서 휴대폰으로 받은 고객정보를 저장하고 계약서를 열면, 매수인 성함 옆 `(인)` 위치에 기존 원제출 서명이 표시됩니다. 고객관리에서 같은 고객의 저장된 계약서를 다시 열어도 표시됩니다. 인수증과 같은 검증된 좌표 기반 서명을 PNG로 그리며, 계약서의 두 인쇄본에도 포함합니다.

현재 직원·소유 직원·차량·계약서 화면 및 고객명이 일치할 때 표시합니다. 서명이 없는 고객을 열거나 다른 차량·계정으로 이동하거나 계약서를 닫으면 이전 이미지를 지웁니다. 고객명을 수정하면 기존 원서명을 숨깁니다. 서명 설명에는 휴대폰에서 제출한 원서명과 제출일임을 표시합니다.

인쇄 버튼은 현재 이미지의 로딩을 확인하고, 기다리는 동안 차량이나 계약서가 바뀌면 인쇄를 중단합니다. 계약서 자동 저장도 현재 차량과 추적 중인 고객 차량이 일치할 때만 실행하여 다른 차량의 계약서 초안을 덮어쓰지 않도록 합니다.

추가 SQL이나 환경변수는 없습니다. 배포에는 `index.html`과 `assets/vehicle-colors.*`, `assets/customer-contract-signature.*`를 함께 포함합니다.

## v2.50 계약서·인수증 투명 원서명

휴대폰 접수로 저장한 좌표 서명을 투명 PNG로 렌더링합니다. 흰 사각형을 채우지 않으므로 문서 배경·선을 덮지 않으며, 원래 필체를 새로 생성하거나 수정하지 않습니다. 계약서는 매수인 성명 옆 `(인)`, 인수증은 확인자 성명 옆 `(서명,날인)` 위치에 자동 표시합니다. 인수증의 원제출 설명은 화면 미리보기의 문서 바깥에 두고 인쇄에서는 제외합니다.

두 문서 모두 직원·소유자·차량·문서 세션·고객명이 일치하는 저장 자료만 표시합니다. 인수증의 고객 성명 또는 확인자명을 수정하면 기존 서명을 숨기고, 서명이 없는 고객/다른 문서를 열거나 닫으면 이미지 데이터를 지웁니다. 인수증 인쇄도 서명 이미지 디코딩을 기다리며, 그동안 문서/계정/차량이 바뀌면 인쇄를 중단합니다. 별도 DB 변경이나 고객 재서명 없이 기존 좌표 자료를 사용합니다.

## v2.51 차량 상세에서 직접 여는 계약서

차량 상세의 계약서를 직접 열어도 같은 직원·차량의 저장된 고객정보와 원서명을 조회합니다. 고객명·연락처·주소 및 기존 계약서 초안을 복원하고 매수인 성명 옆 `(인)`에 서명을 표시합니다. 조회 중 사용자가 입력을 바꾸면 해당 초안을 덮어쓰지 않고, 문서·차량·계정이 바뀌면 오래된 조회 결과를 버립니다. 인쇄는 고객 조회와 서명 디코딩이 끝난 뒤 실행합니다. 판매 진행 경로도 저장 성공 후 최신 고객 자료에서 서명을 읽으며 두 경로의 조회가 서로 경합하지 않게 합니다. 축소된 서명란에서 선이 희미해지지 않도록 문서용 PNG의 선 두께를 조정하며 원본 좌표는 유지합니다.
