# 상단 계산기

v2.17부터 이름·프로필 메뉴 왼쪽의 계산기 아이콘으로 간단한 계산을 할 수 있습니다. 계산기는 아래로 펼쳐지고, 다른 곳을 클릭하거나 Esc를 누르면 닫힙니다. 화면을 이동해도 계산값은 같은 로그인 동안 유지되며, 로그아웃하면 초기화합니다.

- 숫자·소수점·사칙연산을 입력하면 계산 미리보기가 바로 바뀝니다. `=` 또는 Enter로 결과를 확정합니다.
- `AC`는 전체 초기화, `⌫` 또는 Backspace는 입력 취소·한 자리 삭제, `+/−`는 부호 전환입니다.
- `%`는 더하기·빼기에서는 기준 금액의 비율입니다. 예: `200 + 10 % = 220`. 곱하기·나누기에서는 입력값을 100으로 나눕니다.
- 연산은 일반 계산기처럼 입력 순서대로 이어갑니다. 결과 뒤 `=`를 누르면 마지막 연산을 반복합니다.
- 숫자 키·사칙연산 키·Enter·Backspace·Delete·Esc를 지원합니다. 다른 입력칸의 타이핑에는 계산기 단축키를 적용하지 않습니다.

계산값은 이 화면의 메모리에서만 처리하며 장부나 서버 데이터에 자동 반영하지 않습니다. 최대 15자리 유효숫자를 사용하므로 일반적인 업무용 간단 계산에 사용합니다. 작은 화면에서는 패널이 화면 안에 맞춰지고, 동작 줄이기 설정에서는 전환 효과를 끕니다.
