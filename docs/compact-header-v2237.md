# 상단바·메뉴바 정리 — v2.237

사용자 요청에 따라 업무 화면의 상단바 경계와 그림자를 제거하고 통합검색을 왼쪽에 배치했다. 검색창의 푸른색 배경·테두리·버튼을 흰색·회색으로 정리하고, 돋보기를 검색창 안 오른쪽으로 옮겼다. 입력·실시간 결과·주변 흐림·닫기·검색 실행은 기존 모듈을 유지한다. 입력 다음에 검색 버튼이 오도록 DOM 순서도 맞췄다.

프로필은 사진, 이름, 짧은 역할, 펼침 화살표를 항상 표시하는 두 줄 구조로 바꿨다. 추가 요청에 따라 계산기와 프로필 사이의 세로 구분선도 제거하고 간격은 유지했다. 기존 메뉴·사진 원본·알림 숫자·로그아웃·프로필 저장은 유지한다. 계정 이름과 역할을 그리는 화면 경로만 공통 표시 함수로 맞췄으며 인증·권한이나 서버 요청은 바꾸지 않았다. 긴 이름은 말줄임과 전체 이름 title을 제공한다.

왼쪽 메뉴바는 일반 데스크톱 크기에서 약 9~10% 줄이고, 아이콘 메뉴바는 70px에서 64px로 줄였다. 긴 한국어 메뉴가 들어갈 최소 폭을 유지한다. PC·모바일 메뉴의 공식 로고는 원본 크기·비율을 유지하며 왼쪽 정렬하고, 아이콘 메뉴에서는 S 심볼을 중앙에 유지한다. 로그인·업무 문서·상사 로고·도장과 데이터 구조는 변경하지 않는다.
