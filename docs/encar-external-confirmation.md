# 엔카 외부 광고 연결 — v2.123

차량 상세의 Encar 조회는 공식 엔카에서 차량번호와 광고 중 상태를 확인하는 기존 경로를 유지한다. 공식 확인이 접속 차단·통신·페이지 해석 오류로 실패한 경우에는, 허용된 Trust Encar 계열의 공개 원문에서 같은 차량번호와 광고 ID가 확인된 링크도 제공한다.

## 확인 기준

- 개별 광고는 주차량의 `Номер автомобиля`와 `Лот`, 주소의 광고 ID를 함께 확인한다. 공식 엔카로 연결하는 링크가 있으면 같은 ID여야 한다.
- 목록은 하나의 매물 카드 안에 전체 차량번호 하나와 광고 ID 하나가 연결된 경우만 사용한다. 추천 차량의 번호를 현재 페이지 주소에 붙이지 않는다.
- 검색 결과 문구는 원문을 찾기 위한 단서다. 문구에 번호가 있다는 이유만으로 링크를 확정하지 않는다. 연식·차명·차대번호는 일치 판정 조건이 아니다.
- 공식 엔카가 다른 차량번호, 판매 종료, 삭제 또는 광고 상태 불명확을 명시하면 외부 정보로 이를 덮어쓰지 않는다. 외부 원문에서도 명시적으로 종료된 매물은 제외한다.
- 원문이 차단되거나 카드 구조가 불명확하면 링크를 추측하지 않는다. 이 결과는 해당 차량의 광고가 없다는 뜻이 아니다.

## 화면과 저장

외부에서 확인한 매물에는 **외부 광고 확인**을 표시한다. 말풍선에는 한국 엔카의 현재 광고 상태는 미확인이라는 설명, 확인 시각, 원문에 표시된 광고 추가·수정일과 출처를 넣는다. 원문 날짜는 외부 사이트가 표시한 값이며, 한국 엔카의 최초 게시일이나 외부 사이트의 실제 수집 시각으로 단정하지 않는다.

기존 차량 JSON의 `encarLinks`에 `listings[].externalVerification`을 함께 저장한다. 기존 담당자·공유 권한과 revision CAS 저장을 유지하며 SQL 마이그레이션은 필요 없다. 기존 공식 확인 링크도 계속 읽을 수 있다. 저장된 외부 확인 링크는 다음 상세 보기와 목록 버튼에서 바로 열 수 있고, 상세의 조회 버튼은 새 확인을 실행한다.

외부 확인만 있는 매물은 한국 엔카의 현재 광고가격으로 취급하지 않는다. 외부 가격은 저장하지 않으며 자동 촬영·가격 변경 안내·판매예정가 변경을 실행하지 않는다. 공식 확인 매물의 기존 가격 확인과 저장 기능은 유지한다. 엔카 믿고 광고 ID는 숫자 간격으로 추측하지 않는다.

## 서버 설정과 검증

공개 목록의 지원되는 GET 차량번호 검색 폼이 있으면 기존 직접 조회를 사용한다. `TAVILY_API_KEY`가 설정되어 있으면 기존 검색 API로 외부 원문 후보도 찾는다. 키가 없으면 이 검색 API 경로는 사용할 수 없다. `ENCAR_API_KEY` 및 자동 촬영용 토큰은 가격 서비스의 설정이며 광고 검색 API 설정을 대신하지 않는다.

기존에 저장된 광고 ID가 있으면, 직접 목록·검색 API 경로를 처리한 뒤 관측된 `https://nnov.trust-encar.ru/auto/{광고ID}/` 주소로도 최대 3개를 확인한다. 이 경로는 검색 키가 없어도 사용할 수 있다. 기존 ID를 다른 출처에서 대조하는 것이며 새로운 ID를 숫자로 추측하지 않는다. 같은 주차량 번호 검증과 전체 외부 조회/시간 한도는 그대로 적용한다.

외부 요청은 허용된 HTTPS 광고·목록 주소의 GET으로 제한한다. Supabase와 검색 API의 자격증명을 보내지 않고 리디렉션도 따라가지 않는다. 전체 작업 35초, 외부 원문 최대 6개와 외부 단계의 공유 시간 제한을 적용한다. 진단에는 차량번호·고객정보·토큰·외부 원문을 기록하지 않는다.

```sh
npm test --prefix tests/encar
node tests/encar/external-confirmation.browser.cjs
node tests/encar/detail-action.browser.cjs
node tests/encar/direct-price-change.browser.cjs
```

브라우저 검증은 실제 앱의 조회·저장·복원·목록·가격 경로에 합성 인증/서버 응답을 연결한다. 운영 차량과 계정으로 쓰기 시험을 하지는 않는다. 실제 외부 HTML과 운영 검색 공급자의 실시간 응답 검증 범위는 릴리스 검증 기록에서 별도로 구분한다.
