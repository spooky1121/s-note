# 검수 화면 정리와 사진 학습 구성 — v2.235

검수 화면 내부의 `차량 검수 도우미` 제목, `확인 순서대로 살펴보고, 다시 볼 부분을 남겨두세요.` 설명과 함께 있던 아이콘 블록을 삭제했다. 메뉴 이름과 접근성용 페이지 이름, 기존 7단계·21항목·접속 중 메모 기능은 유지했다.

## 사진 학습 준비 범위

사진 선택, 단계 필터, 관찰 포인트 표시, 원본 확대·축소와 다운로드를 제공하는 선택적 학습 화면을 구현했다. 기존 이미지 뷰어·모바일 뒤로가기·움직임 줄이기 동작을 재사용한다. 기존 체크 화면과 사진 학습 화면을 전환해도 현재 계정의 체크·메모는 유지한다. 이전 계정·상사의 DOM 이벤트는 적용하지 않는다.

사용자가 제공한 ChatGPT Library 링크는 공개 페이지 읽기에서 본문 0줄, 새 비로그인 브라우저에서는 실행환경의 `403 Domain forbidden` 응답이었다. 실제 문서·실사진·다운로드 주소를 확인하지 못했다. 공유 설정이나 로그인 필요 여부를 단정하지 않는다.

따라서 **이 배포에는 원본 실사진이나 원본에서 만든 설명이 없다.** 유효한 원본 자료가 등록되지 않으면 사진 탭·갤러리·준비 중 안내를 운영 화면에 표시하지 않으며 사진 요청도 하지 않는다. 테스트용 이미지는 제품 자료로 사용하지 않는다. 직접 첨부받은 원본을 읽고 사진과 설명을 대조한 다음 자료를 연결해야 한다.

## 자료 연결 형식

`SnoteVehicleInspection.mount`의 선택 옵션 `learningData`를 받는다. 경로는 동일 서비스의 정적 `assets/` 이미지로 제한하며 원본 묘사·크기·출처·관찰 설명이 있는 항목만 사용한다. 외부 이미지, data/blob/javascript URL, 경로 이동, 설명이 없는 항목은 배제한다. 이미지 파일명은 영문·숫자·하이픈·밑줄로 정리한다.

단계 ID는 `records`, `body`, `tires`, `engine`, `cabin`, `start`, `finish`다. 좌표는 원본 이미지의 가로·세로를 각각 0~100으로 본 백분율이며, 좌표가 없는 관찰 설명도 표시할 수 있다.

```js
{
  version: 1,
  lessons: [{
    id: 'lesson-id',
    stageId: 'body', // 기존 7단계 중 하나
    label: '원본을 확인한 뒤 붙일 제목',
    image: { src: '/assets/inspection-study/01.jpg', alt: '원본 사진 묘사', width: 1200, height: 800 },
    description: '원본과 대조한 학습 설명',
    observations: [{ label: '확인 부위', description: '관찰 방법과 추가 확인 내용', x: 50, y: 50 }],
    source: { title: '원본 자료명', page: 1 }
  }]
}
```

위 형식은 연결 예시이며 해당 이미지·문구는 등록하지 않았다. 원본 자료를 확보하면 정적 자료 모듈에서 `window.SnoteVehicleInspectionLearning`을 제공하고, 검수 기능의 최초 사용 로딩에 함께 연결할 수 있다. API·DB·스토리지 설정은 변경하지 않는다.

## 검증

기존 검수 통합 테스트는 삭제한 제목 대신 현재 단계 제목으로 실제 폰트와 화면 구성을 확인하도록 갱신했다. 사진 컴포넌트 테스트는 가상 로컬 이미지로 선택·확대·닫기·계정 경계·잘못된 자료 차단을 확인하며, 원본 학습 자료의 정확성 검증을 대신하지 않는다.

사진 컴포넌트의 15개 검증이 통과했다. PC·모바일, 키보드·좌표, 확대 후 Escape·모바일 뒤로가기, 다운로드, 이전 DOM 이벤트와 다른 화면의 동일 원본 뷰어 보호, 잘못된 자료·XSS 차단, 이미지 오류 재시도, 움직임 줄이기를 가상 자료로 확인했다. 운영용 이미지·학습 자료는 추가하지 않았다.

헤더 삭제를 반영한 기존 통합 검증 22개도 통과했다. 360~1920px와 딜러·경리·관리자 화면에서 제목·설명·아이콘 블록이 없고 빈 사진 탭도 없음을 확인했다. 실제 Pretendard 렌더링, 체크·메모·권한 경계·뒤로가기·오류 재시도·재로그인 검증도 유지했다. 운영 데이터 읽기·쓰기와 제품 이미지 설치는 0회다.
