# S-NOTE 스캐너 연결 · Windows

연결 도우미를 한 번 설치하면 Windows 로그인 때 자동 실행되고, 이후 S-NOTE의 **스캔** 버튼으로 이 PC의 스캐너를 사용합니다. 연결번호를 입력하지 않습니다. 스캔 미리보기에서 **저장**을 눌러야 현재 상사의 비공개 스캐너 보관함에 업로드됩니다.

## 처음 한 번 설치하기

1. Windows 스캔 앱에서 사용할 스캐너가 검색되고 정상 스캔되는지 확인합니다. 필요한 경우 해당 제조사의 스캔 드라이버를 설치합니다. 네트워크 복합기는 PC와 연결 가능한 네트워크에 있어야 합니다.
2. 공식 [SnoteScannerSetup.exe](https://github.com/spooky1121/s-note/releases/download/scanner-connector-v1.1.0/SnoteScannerSetup.exe)를 내려받아 실행합니다. Windows 10/11 x64용이며 .NET을 따로 설치하지 않습니다. 이전 1.0 도우미가 실행 중이라면 알림 영역에서 종료한 뒤 새 설치 파일을 실행합니다.
3. **설치하고 Windows 자동 실행**을 누릅니다. 이 버튼은 현재 Windows 사용자 폴더 설치와 시작 앱 등록에 대한 동의입니다. 관리자 권한·방화벽 변경·인증서 설치는 요구하지 않습니다. 설치 후 S-NOTE가 열리고 도우미는 알림 영역에서 계속 실행됩니다.
4. 경리 계정으로 로그인하고 **스캐너 → 스캔**을 누릅니다. 브라우저가 이 PC의 연결 프로그램 접근 권한을 요청하면 허용합니다.
5. 최초 브라우저 연결 시 PC에 뜨는 **S-NOTE 스캐너 연결 허용** 창에서 주소가 맞는지 확인하고 **연결 허용**을 누릅니다. **이 Windows 계정에서 이 브라우저의 연결 기억**을 선택하면 다음 접속과 Windows 재시작 후에도 번호 없이 재연결합니다.
6. 스캐너가 여러 대면 사용할 장치를 처음 선택합니다. 이후에는 선택한 장치를 기억하며, 한 대만 검색되면 자동으로 선택합니다. 종이를 올리고 스캔한 뒤 미리보기에서 **저장**을 누릅니다.

다음 Windows 로그인부터 도우미는 창을 띄우지 않고 자동으로 준비됩니다. 도우미를 종료했거나 Windows 시작 앱을 껐다면 다시 실행해야 합니다. 브라우저·계정·사이트 주소를 바꾸거나 브라우저 저장 데이터를 삭제한 경우 최초 연결 허용이 다시 필요할 수 있습니다. 공용 PC에서는 연결 기억을 해제할 수 있습니다.

## 연결과 자동 실행 관리

- 창을 닫아도 도우미는 알림 영역에서 실행됩니다. 종료는 알림 영역의 S-NOTE 아이콘 → **종료**를 사용합니다.
- 자동 실행을 끄려면 도우미 창의 **자동 실행 해제**를 누릅니다.
- 기억한 브라우저를 모두 해제하려면 **연결 승인 초기화**를 누릅니다. 진행 중 권한을 무효화하고 저장한 공개키 승인을 지웁니다. 다음 스캔 때 연결을 다시 허용하면 됩니다.
- 도우미는 이 PC의 `127.0.0.1:17426`에서만 대기합니다. 허용된 S-NOTE 주소의 브라우저가 소유한 키를 증명하고, 최초 로컬 승인을 받은 연결만 장치를 사용할 수 있습니다. S-NOTE 비밀번호·클라우드 로그인 토큰·서버 키는 도우미에 전달하지 않습니다.
- Windows에는 승인된 브라우저의 공개키만 사용자별 DPAPI로 보호해 저장합니다. 스캔 결과는 짧은 시간 메모리에만 유지하며, 실제 클라우드 저장 권한은 기존 S-NOTE의 로그인·상사 권한 검사가 담당합니다.

## 지원 범위

- 삼성에 한정하지 않고 Windows WIA 드라이버로 인식되는 여러 제조사의 스캐너를 사용합니다. 장치가 요청한 해상도·색상·원고 위치를 지원해야 합니다. TWAIN 전용·eSCL 전용 장치와 스캔 기능이 없는 인쇄 전용 프린터는 이 버전의 직접 스캔 대상이 아닙니다.
- 한 번에 한 장을 스캔합니다. 자동급지도 한 장씩 처리합니다. 기본 300dpi이며 컬러·회색조·흑백과 지원되는 원고 위치를 선택합니다.
- 결과는 JPG, 한 장당 최대 5MB·4천만 화소입니다. 기존 JPG·PNG·WebP 파일 선택과 끌어놓기도 사용할 수 있습니다.
- 취소하거나 화면·계정을 바꾸면 이전 결과가 저장되지 않습니다. 취소 시 장치의 현재 한 장 동작은 완료까지 이어질 수 있지만 결과는 폐기됩니다.

## 연결이 되지 않을 때

- 먼저 Windows 스캔 앱 또는 제조사 스캔 앱에서 장치가 작동하는지 확인합니다. 인쇄가 되는 것만으로 스캔 드라이버 등록을 보장하지 않습니다.
- 브라우저의 S-NOTE 사이트 권한에서 로컬 기기 연결을 허용하고 도우미가 실행 중인지 확인합니다. 임의의 복합기 IP·공유기 정보 입력이나 브라우저 보안 기능 해제는 필요하지 않습니다.
- 설치·업데이트가 안 되면 이전 도우미를 알림 영역에서 종료하고 다시 설치합니다. 다른 프로세스를 강제 종료하지 않습니다.
- 설치 파일은 현재 코드 서명되지 않았으므로 Windows의 파일 확인 또는 보안 경고가 표시될 수 있습니다. 공식 릴리스 파일과 공개한 SHA256을 확인할 수 있습니다.

## 검증 범위

웹·연결 프로토콜은 가상 계정·스캐너·생성 이미지로 검증합니다. Windows 빌드는 GitHub Actions에서 생성하며 native 이미지 변환과 DPAPI 신뢰 저장·변조 거부·범위 분리·초기화를 합성 자료로 검사합니다. 설치 파일·ZIP의 SHA256과 소스 커밋을 함께 제공합니다. 실제 복합기·드라이버·Wi-Fi·Windows 자동 시작·브라우저 연결 권한의 현장 작동은 해당 PC에서 확인해야 합니다. 실제 고객 문서를 시험에 사용하지 않습니다.

참고: [Windows 스캐너 API](https://learn.microsoft.com/en-us/windows/apps/develop/devices-sensors/scan-from-your-app), [브라우저 로컬 연결 권한](https://developer.chrome.com/docs/modern-web-guidance/guides/security/local-network-access).
