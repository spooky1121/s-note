# S-NOTE 스캐너 연결 · Windows

이 연결 도우미를 실행한 PC에서 S-NOTE의 스캔 버튼으로 Windows에 등록된 스캐너를 작동시킵니다. 스캔한 이미지를 미리 확인하고 저장하면 현재 로그인한 상사의 비공개 스캐너 보관함에 등록됩니다.

## 처음 연결하기

1. [삼성 공식 다운로드](https://www.samsungsvc.co.kr/download/view?code=SL-J3560FW)에서 SL-J3560FW용 드라이버를 설치하고 무선 연결을 선택합니다. PC와 복합기를 같은 네트워크에 연결합니다. Windows 스캔 앱에서 스캐너가 검색되고 정상 스캔되는지 확인합니다.
2. `SnoteScanner-Windows-x64.zip`의 압축을 풀고 `SnoteScanner.exe`를 실행합니다. .NET 런타임을 별도로 설치하지 않아도 되는 Windows x64용 프로그램입니다.
3. 매번 실행하지 않으려면 도우미 창에서 이 PC 설치·자동 실행 옵션을 선택합니다. 확인한 경우에만 현재 Windows 사용자의 폴더와 시작 프로그램에 등록합니다.
4. 경리 계정으로 S-NOTE에 로그인하고 **스캐너 → 스캔**을 누릅니다. 브라우저가 이 PC의 연결 프로그램 접근을 요청하면 허용합니다.
5. 도우미 창에 표시된 연결 코드를 입력하고 인식된 스캐너를 선택합니다. 종이를 평판 또는 자동급지 장치에 넣고 스캔을 시작합니다.
6. 미리보기에서 내용을 확인한 뒤 **저장**을 누릅니다. 저장 전에는 상사 보관함에 업로드하지 않습니다.

연결 후 같은 로그인 화면에서 스캐너 메뉴를 다시 열어 사용할 수 있습니다. 페이지 새로고침·로그아웃·도우미 재시작 후에는 연결 코드를 다시 확인할 수 있습니다. 도우미를 종료하면 웹에서 장치를 작동시킬 수 없습니다.

## 지원 범위

- Windows 10/11 x64의 WIA 드라이버로 인식되는 스캐너를 사용합니다. 사용 대상 기종은 SL-J3560FW Wi-Fi이며, 실제 드라이버 인식과 현장 작동은 해당 PC에서 확인해야 합니다.
- 한 번에 한 장을 스캔합니다. 자동급지 장치도 이번 버전은 한 장씩 처리합니다. 기본 해상도는 300dpi이고 컬러·회색조·흑백 및 지원되는 원고 위치를 선택합니다.
- 스캔 결과는 JPG이며 한 장당 최대 5MB, 최대 4천만 화소입니다. 기존 JPG·PNG·WebP 파일 선택과 끌어놓기는 그대로 사용할 수 있습니다.
- 취소하거나 화면·계정을 바꾸면 이전 결과가 저장되지 않습니다. 취소한 경우 장치의 현재 한 장 동작은 완료까지 이어질 수 있으며, 결과는 폐기됩니다.
- 도우미는 이 PC의 `127.0.0.1:17426`에서만 대기합니다. 허용된 S-NOTE 주소와 연결 코드로 승인된 요청만 처리합니다. S-NOTE 로그인 토큰·비밀번호·서버 키를 전달받지 않습니다.
- 스캔 결과는 짧은 시간 메모리에만 유지합니다. 저장 버튼을 누른 이후의 업로드와 계정·상사 권한 검사는 기존 S-NOTE 웹 기능이 담당합니다.

## 연결이 되지 않을 때

- 먼저 Samsung Scan 또는 Windows 스캔 앱에서 장치를 사용할 수 있는지 확인합니다. 인쇄만 되는 상태는 스캔 드라이버 등록을 보장하지 않습니다.
- 스캐너가 검색되지 않으면 [삼성 스캔 드라이버 안내](https://www.samsungsvc.co.kr/solution/38808)를 확인합니다. 웹에 임의의 복합기 IP나 공유기 정보를 입력할 필요는 없습니다.
- 도우미가 실행 중인지 확인하고 브라우저의 S-NOTE 사이트 권한에서 로컬 기기 연결이 허용되어 있는지 확인합니다. 브라우저 보안 기능을 끄도록 요구하지 않습니다.
- 자동 실행을 사용하지 않으려면 도우미에서 해당 옵션을 해제합니다. 종료는 작업 표시줄의 도우미 아이콘에서 선택합니다.

## 검증 기록

웹과 연결 프로토콜은 가상 계정·스캐너·생성 이미지로 검증합니다. Windows 빌드는 GitHub Actions에서 별도로 생성하고 ZIP의 SHA256 및 소스 커밋을 함께 제공합니다. 실제 복합기·드라이버·Wi-Fi의 스캔 성공 여부와 코드 서명은 이 빌드 검증에 포함되지 않습니다. 실제 고객 문서를 시험에 사용하지 않습니다.
