# 산타 썰매 장식 · v2.218

로그인·메인 업무·고객 입력·계정 복구·운영자 웹페이지에 산타 썰매가 한 번씩 지나가는 장식을 추가한다. 상단 iframe이 아닌 페이지에만 한 개를 만들며, 월정산·소득정산 iframe과 인쇄창에는 삽입하지 않는다.

- 사용자가 제공한 오른쪽 방향 참고 이미지를 바탕으로 배경과 불필요한 선을 정리한 투명 이미지를 준비하고 WebP로 보관한다. 순록은 오른쪽, 썰매는 왼쪽에 있다. CSS에서도 좌우 반전 없이 왼쪽에서 오른쪽으로만 움직인다.
- 이미지가 정상 로딩되면 2초 뒤 첫 비행을 시작한다. CSS 주기는 60초이며 그중 9초 동안 화면을 통과하고 나머지는 화면 밖에서 숨긴다. 별도의 반복 타이머나 업무 데이터 요청은 없다.
- 고정 장식 컨테이너는 클릭을 받지 않으며 `inert`와 `aria-hidden`을 적용한다. 모바일 크기를 조절하고 화면 밖 이동으로 가로 스크롤이 생기지 않게 한다.
- 일반 팝업, 견적서·계약서·인수증 미리보기, 인쇄, 모션 감소 설정에서는 숨기고 애니메이션을 멈춘다. 탭이 숨겨지면 멈추며 돌아오면 새 주기로 시작한다.
- 이미지 오류는 한 번만 처리하여 장식을 숨긴다. 로그인·권한·문서 양식·차량/고객 데이터·운영 설정은 변경하지 않는다.

검증은 가상 계정과 가상 응답으로만 진행한다. 실제 60초를 기다리는 대신 브라우저 애니메이션 시간을 이동하여 주기·방향·휴식·다음 비행을 확인한다. 기존 CSP는 유지한다.

`node tests/santa-flight-v2218.browser.cjs`의 app/guards/standalone 그룹으로 1440px·390px, 최초/다음 주기와 휴식, 좌우 반전 없음, UI 클릭, 문서 세 종류의 숨김, 인쇄·모션 감소·탭 숨김, 중복 실행·iframe 방지, 이미지 오류 후 재요청 없음 및 3개 독립 화면을 검증한다. 고객 화면의 기존 readable-type CSP 경고 2건은 기준 화면과 동일하며 새 위반은 없다. 모바일 화면의 일정 오류 표시는 가상 fixture에 선택적 일정 응답을 넣지 않은 결과이며 제품 변경 대상이 아니다.

실제 Safari/Firefox·휴대기기·물리 프린터는 미검증이다. 운영 사이트 직접 접근은 환경 정책으로 제한되어 검증 트리와 정확한 운영 커밋의 S-NOTE Pages 성공 상태로 배포를 확인한다.
