# 재고금융사 항목 통합 — v2.245

차량 목록의 `finance`(재고금융)와 `lender`(재고금융사)는 같은 차량의 `inventoryLender`·`inventoryLoan`을 표시하고 있었다. 이제 `lender` 한 열과 한 표시 설정으로 통합하며 이름은 재고금융사다. 대출금액은 기존 재고대출금 항목에 유지한다.

저장된 금융사명은 잔액이 0원이어도 표시한다. 이름이 없으면 대출 잔액이 있는 차량은 금융사 미지정, 없는 차량은 현금으로 표시한다. 표시와 정렬은 같은 값을 사용한다.

회사·사용자·역할별 기존 표시 설정은 같은 저장 키에서 schema 3으로 이전한다. 딜러·관리자는 실제로 제공되던 finance 열의 숨김 상태를 lender에 잇는다. 경리는 두 열 중 하나라도 보였다면 통합 열을 표시하고, 둘 다 숨긴 경우만 숨긴다. 기존 고정 항목과 schema 1의 추가 항목 기본값을 보존한다. 설정 저장 실패가 차량 목록을 막지 않는다.

정렬의 구 finance ID는 lender로 연결하고 현재 헤더 위치를 다시 찾는다. 금융 프리셋에는 통합 항목을 한 번만 넣는다.

차량 원본·부가 금융 장부·원금·이율·권한은 바꾸지 않는다. 기존 장부가 누락된 차량 금융정보를 보완하는 규칙과 완납 0원 처리를 유지한다. 서로 다른 실제 채무를 합산하거나 알 수 없는 과거 JSON 키를 삭제하지 않는다. 이 변경에는 운영 DB 마이그레이션이 필요 없다.
