# 대시보드 정리와 뉴스 — v2.241

대시보드 상단의 투자금·실적 카드 일곱 개를 제거한다. 총투자금, 재고대출금, 현금투자금, 이번 달 수익, 이번 달 매입, 이번 달 판매, 올해 수익은 수익정산을 펼쳤을 때 일반 항목으로 표시한다. 기존 재고 예상수익과 금액 잠금·수익 숨김은 유지한다.

달력 옆 업무 영역에서 최근 3개월 흐름과 수익정산을 같은 폭으로 나눈다. 공간이 좁으면 세로로 배치하고, 그 아래 자동차 칼럼 카드를 둔다. 뉴스 로딩·빈 결과·오류에도 카드 높이를 확보한다. 경리의 업무 현황 카드와 개인 달력은 기존 위치를 유지한다.

## 경리 일정

수동 일정은 기존 서버에서 소속 상사와 본인 UUID로 이미 분리되어 있다. 이 변경은 경리 달력에 추가되던 딜러 차량의 매입·판매 자동 날짜와 해당 범례를 제거한다. 경리는 본인이 등록한 일정만 확인·수정하고, 딜러·관리자의 본인 차량 날짜 표시는 유지한다. 새로운 일정 권한이나 DB 마이그레이션은 추가하지 않는다.

## 자동차 칼럼

뉴스 카드와 서버 API의 세부 사항은 [자동차 칼럼 API](automotive-columns-v2241.md)를 따른다. 네이버 뉴스 검색 API에는 칼럼 카테고리 매개변수가 없으므로, 서버에서 고정 검색어를 사용하고 자동차 주제와 명시적인 칼럼·기고 제목 표기를 보수적으로 선별한다. 다른 제공처나 일반 기사로 대신 채우지 않는다.

실제 조회에는 Cloudflare Pages `s-note`의 Production 환경에 다음 비밀값이 필요하다.

- `NAVER_NEWS_CLIENT_ID`
- `NAVER_NEWS_CLIENT_SECRET`

값은 클라이언트 코드·Git·로그에 넣지 않는다. 설정 후 새 Pages 배포에 반영해야 한다. 설정이 없으면 `/api/automotive-columns`는 `503 / NEWS_NOT_CONFIGURED`를 반환하고 카드에는 준비 안내를 표시한다. 정상 빈 검색 결과와 제공처 오류는 별도로 처리한다.

제목·원문 링크·게시일·출처만 최대 다섯 개 표시하며 HTML을 실행하지 않는다. API 요청은 서버의 고정 경로로만 보내고 비밀값을 브라우저에 전달하지 않는다. 로그인이나 다른 메뉴에서는 뉴스 요청을 시작하지 않는다. 공개 뉴스 캐시를 공유하되, 늦게 도착한 응답이 다른 화면을 변경하지 않도록 현재 화면을 확인한다.

## 검증 범위

합성 기사와 가상 계정으로 화면 크기, 지표·잠금, 일정 분리, 뉴스 표시·빈 결과·설정 없음·실패·지연 응답을 점검한다. 실제 Pages Functions 라우터를 빌드해 새 경로가 허용 목록을 통과하고 설정이 없을 때 404가 아닌 503을 반환하는지 확인한다. 실사용 네이버 키로 기사 수신을 확인했는지는 별도로 배포 기록에 남긴다.
