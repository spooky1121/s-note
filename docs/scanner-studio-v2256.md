# 스캐너 문서 작업 화면 · v2.256

기준 main은 `47c85e24a3997df0391da7d49e248d1366e23b51`이다. 스캐너 화면과 대시보드의 계약중 차량 표시를 개편한다. 이번 작업에서 운영 DB·기존 상사 자료를 직접 수정하지 않으며 Cloudflare 설정·Windows 연결 프로그램도 변경하지 않는다.

## 화면과 도구

- PC 상단은 같은 높이의 50:50 카드로 나눈다. 왼쪽은 현재 문서와 보기 도구·스캔 설정/저장, 오른쪽은 이번 로그인에서 추가한 문서의 작은 미리보기다. 모바일은 순서대로 세로 배치한다.
- 작은 미리보기를 선택하면 큰 문서를 확인할 수 있다. 확대·축소·화면 맞춤·90도 회전·원본 다운로드를 제공한다. 회전은 보기만 바꾸며 저장 파일과 다운로드 원본 바이트는 바꾸지 않는다.
- 아래 이력은 스캔·등록일, 시간, 내용, 용량, 관리로 나눈다. 내용은 저장된 원본 파일명이고 시각은 서버 등록 시각을 한국 시간으로 표시한다. 장치의 실제 촬영 시각이나 OCR 본문을 수집했다고 표시하지 않는다.
- 파일명과 날짜로 불러온 이력을 좁힐 수 있고 더 불러오기로 과거 목록을 읽는다. 완료한 저장 처리 목록은 숨기고 대기·실패·불확실 결과와 재시도는 유지한다.
- 큰 미리보기의 저장 안내도 해당 파일의 실제 대기·저장 중·실패·결과 확인 필요 상태를 표시한다. 불확실 결과를 성공이나 계속 진행 중으로 표시하지 않는다.
- 기존 연결 설정, 번호 없는 Windows 연결, 미리보기 뒤 명시적 저장, 이미지 불러오기/드래그, 파일 제한·삭제 확인·불확실 ACK 재시도는 유지한다.

## 로그인 모음·이미지 수명

- 상사·사용자·검증된 로그인 세션의 `deviceKey`를 SHA256으로 변환한 키 아래 UUID ID만 sessionStorage에 보관한다. 파일명·이미지·로그인 토큰·장치 접근 권한은 저장하지 않는다. 최대 200개·JSON 16KB이며 저장소를 쓸 수 없으면 현재 페이지 메모리에서만 동작한다.
- 메뉴 이동과 새로고침은 같은 로그인 ID를 복원하되, 현재 상사의 서버 메타데이터를 다시 확인한 행만 표시한다. 다른 로그인·상사와 로그아웃은 이전 모음을 지운다. 저장되지 않은 장치 미리보기는 영구 모음에 넣지 않는다.
- 큰 문서는 기존 `ensure → target → readAsset` 검증을 거쳐 읽는다. 권한·상사·세션 검사와 [비공개 Storage 접근 경로](https://supabase.com/docs/guides/storage/buckets/fundamentals#private-buckets)를 유지한다.
- 썸네일은 최대 320px로 만든다. 동시 처리 2개, 대기 24개, 대기 원본 File 12개, 완료 URL 24개를 제한하며 화면에 들어오는 항목을 우선 처리한다. 전체 이력은 자동 이미지 다운로드 없이 메타데이터만 읽는다.
- 선택·삭제·계정 변경은 세대를 바꿔 늦은 이미지 응답을 차단하고 URL을 회수한다. 경로 이탈·페이지 숨김은 메모리 이미지를 정리하며, 로그아웃은 ID 모음도 지운다.
- 장치의 작은 미리보기를 큰 문서 영역으로 통합했다. 자식 컨트롤러는 `inlinePreview`에서 중복 이미지/URL을 만들지 않으며 기존 독립 호출 방식도 지원한다.

## 계약중 차량 달력

- 확인된 날짜의 계약중 차량은 연한 핑크색으로 표시한다. 실제로 계약중으로 전환하는 저장에서 한국 날짜의 `contractAt`을 함께 기록하며 저장 실패 시 상태와 새 날짜를 모두 되돌린다.
- `contractAt`은 계약중 전환일이다. 고객의 계약서 자료를 별도로 읽어 개인 정보를 노출하거나 서로 다른 장부에 이중 저장하지 않는다. 과거 날짜 없는 차량은 임의 날짜에 넣지 않고 달력 안의 `계약일 미등록` 목록으로 표시한다.
- 딜러·대표의 기존 차량 범위를 유지하고, 경리는 확인된 소속 상사의 계약중 정보만 읽는다. 경리의 개인 일정은 계속 딜러 일정과 분리하며 차량 매입일·판매일도 새로 노출하지 않는다.
- 상태가 판매중·판매완료로 바뀌면 현재 계약중 표시는 제외한다. 공유 API에 없는 날짜·고객 정보를 추정하거나 공유 권한을 확대하지 않는다.
- 저장소 정의와 합성 round-trip에서 새 필드가 차량 정규화·금액 변환·JSON 저장·개인정보 scrub·회사 조회·휴지통 복원에 보존됨을 확인했다. 기존 과거 거래를 수정하거나 스키마 마이그레이션을 적용하지 않는다.
