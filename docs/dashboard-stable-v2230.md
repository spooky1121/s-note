# 대시보드 상단 카드 펼침 시 위치 고정 (v2.230)

기준 main은 `54a450ac6439704cb2670a835655711aae21055e`이다. 상단 KPI를 펼칠 때 그리드의 높이를 바꾸던 애니메이션과 접힌 상태의 별도 열 배치 때문에 아래 달력·일정·그래프·수익 정산이 이동했다. 기준 화면에서 1440px은 위로 10px, 1024px은 아래로 92px 이동하는 것을 재현했다.

접힌 상태에도 7개 카드의 최종 그리드 공간을 확보한다. 나머지 카드는 보이지 않고 비활성 상태를 유지하지만 해당 칸의 크기는 그대로다. 브라우저 폭과 전체 금액을 기준으로 접힘 여부와 무관하게 같은 열 수를 계산한다. 카드 묶음의 높이 애니메이션을 제거하고 개별 카드의 이동·투명도 효과만 유지한다. 접을 때는 다시 총투자금 위치로 모인다. 장식 겹침도 실제 첫 카드의 규격에 맞춘다.

애니메이션 도중 다시 크기를 계산할 때는 화면에 적용된 scale을 보정해 일시적인 열 수 변경을 막는다. 화면 폭을 실제로 변경할 때의 반응형 배치는 유지한다. 금액·계산식·인증·금융 잠금·일정·차트·문서·로그인 복구 코드는 변경하지 않는다.

검증은 실제 앱과 가상 자료로 수행한다. 신규 `tests/dashboard-stable-layout-v2230.browser.cjs`는 1440/1024/850/761/390/360px, 동작 줄이기와 큰 금액·화면 크기 변경을 포함한다. 펼침·접힘·빠른 반전 및 펼침 중 글꼴 재계산의 각 animation frame에서 KPI 영역 높이, 첫 카드 위치, 달력·오늘/다가올 일정·그래프·정산 위치와 스크롤이 고정되는지 확인한다. 영역 겹침, 가로 넘침과 금액 줄바꿈도 검사한다.

기존 `dashboard-reveal-v2228.browser.cjs`는 카드 7개 금액/원본 불변·키보드·숨김/비활성·반응형·금액 잠금/상사 전환 회귀를 확인한다. 대시보드 모델 13개 검사와 JS 문법·diff·브랜드 경계도 확인한다. 운영 자료나 서버 설정은 변경하지 않으며 실제 Safari 기기는 별도 확인 대상이다.

신규 8개와 기존 펼침 회귀 6개는 모두 통과했다. 44회 전환의 1859개 프레임에서 예약 영역과 아래 카드들의 위치 변화는 최대 0px였으며 겹침·가로 넘침·금액 줄바꿈도 없었다.
