# 딜러 간 차량 공유

차량 상세의 저장 아이콘 옆 공유 아이콘에서 등록된 딜러 이메일과 권한을 선택한다. 다른 상사의 활성 딜러·관리자도 지정할 수 있으며, 상대방이 프로필 알림에서 수락한 차량만 공유받은 목록에 나타난다.

## 공유 권한

| 선택 | 차량 조회·사진/서류 보기 | 차량 정보 수정 | 차량 삭제 |
| --- | --- | --- | --- |
| 읽기 | 가능 | 불가 | 불가 |
| 수정 | 가능 | 가능 | 불가 |
| 삭제 | 가능 | 불가 | 가능 |
| 모든 권한 | 가능 | 가능 | 가능 |

새 초대의 기본값은 읽기다. v2.107 이전 공유는 기존 동작을 유지하도록 수정 권한으로 이관한다. 소유자와 소유 상사의 관리자는 공유 대상별 권한을 바꾸고 파란 저장 아이콘으로 확정하거나 초대·공유를 해제할 수 있다. 같은 이메일을 다시 초대해 권한을 덮어쓰지는 않는다. 기존 계정·상사 관리자의 자체 권한은 공유 선택으로 축소하지 않는다.

공유받은 딜러는 매입관리 목록 위의 공유받은 차량 아이콘에서 수락한 차량을 연다. 수정 가능한 정보는 차명·차량번호·제조사·연식·차대번호·주행거리·색상·매입일·매입가·판매예정가·차량 메모다. 금액은 원 단위 천 단위 콤마로 표시하며, 기존 KRW/레거시 저장 형식의 왕복 변환을 보존한다. 차량 메모는 2,000 UTF-16 단위 이내다.

삭제는 영구 삭제가 아니라 소유자의 휴지통으로 이동한다. 연결된 고객정보·주민번호·사진/서류와 표지 자료는 기존 휴지통의 비공개 스냅샷에 보관하고 해당 차량의 공유와 고객 입력 링크를 해제한다. 복원은 기존 소유자·소유 상사 관리자 권한으로 처리하며 복원해도 이전 공유가 자동 복구되지는 않는다. 공유받은 사람에게 소유자의 다른 차량·고객정보·휴지통 내용은 반환하지 않는다.

모든 권한도 해당 차량의 위 작업에만 적용한다. 고객 개인정보·주민번호·서명·정산 자료, 판매 처리, 재공유·공유 대상 관리는 포함하지 않는다. 공유 사진·서류는 조회/다운로드만 가능하며 업로드·교체·개별 삭제 권한은 추가하지 않는다.

## 화면과 동시 변경

서버의 최신 권한에 따라 입력칸과 저장·삭제 아이콘을 표시한다. 공유 창을 연 동안 15초마다 권한을 재조회하고, 다시 화면을 볼 때와 공유 변경 이벤트에서도 확인한다. 권한을 확인하지 못하면 수정·삭제를 잠근다. 서버는 매 작업마다 권한을 검사하므로 갱신 전 화면이나 직접 API 요청으로 제한을 우회할 수 없다.

권한 변경은 초대 버전을 증가시킨다. 오래된 초대 수락 화면과 이전 권한으로 보낸 저장·삭제는 충돌로 거부하며, 해제 후 재초대한 경우에도 이전 초대의 입력으로 새 권한을 사용할 수 없다. 차량 수정은 기존 소유 장부 revision CAS를 유지해 다른 차량이나 먼저 저장한 변경을 덮어쓰지 않는다. 실패한 저장 입력은 보존한다.

공유 자료를 수신자의 localStorage/IndexedDB 장부에 복사하지 않는다. 로그아웃·사용자·상사 변경 시 공유 화면과 임시 이미지 URL을 비운다. 이미 내려받은 자료는 원격에서 회수하지 않는다.

## DB 및 API

- 최신 마이그레이션: `supabase/migrations/20261109020649_vehicle_share_permissions.sql`.
- `snote_private.vehicle_shares.permission`은 `read/edit/delete/all`만 허용하며 신규 기본값은 `read`다. private 표의 RLS와 직접 접근 거부를 유지한다.
- 새 `public.snote_vehicle_share_v2`는 authenticated 전용 SECURITY INVOKER다. 비노출 private 함수에서 실제 사용자·활성 회원·회사·소유권·수락 상태·권한을 검증하며 search_path는 비운다.
- 공유 수정·삭제와 권한 변경은 정확한 `invitationId/version`을 요구한다. 권한은 회사 잠금과 장부 행 잠금 이후에도 다시 검사한다. 쓰기 필드는 고정 허용 목록이며 다른 차량·민감한 기존 필드는 보존한다.
- 삭제 전용 private 함수는 원 소유자의 전체 장부를 반환하는 기존 휴지통 ACK를 재사용하지 않는다. 응답은 대상 차량 ID·요청 UUID·삭제 확인만 포함한다. 재시도는 같은 사용자·차량·초대에 고정한 요청 UUID로 처리한다.
- 기존 8인자 API의 공유받은 딜러 수정은 거부한다. 기존 화면은 새로고침 후 v2 API로 저장할 수 있다. 기존 소유자/관리자 작업과 읽기는 유지하며, 구 API의 신규 초대도 읽기다. 새 프런트는 구 API로 우회하지 않는다.
- 기존 datasets/customers/media/Storage RLS를 넓히지 않는다. 사진·서류 SELECT만 기존 수락 공유와 정확한 경로에 연결한다. 생성·수정·권한 변경·해제·삭제는 기존 감사 기록에 남긴다.
