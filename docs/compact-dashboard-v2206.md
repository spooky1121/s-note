# v2.206 대시보드 크기·차량 거래일

v2.205의 달력(실측 높이 885px)과 요약 카드를 줄이고, 데스크톱에서 요약 → 달력·일정·차량 할 일 → 실적·정산·바로가기를 한 화면에 배치한다. 확대/축소나 전체 화면의 글자를 일괄 축소하지 않고 카드 여백·행 높이·배치를 조정한다. 모바일은 읽을 수 있는 글자와 입력 크기를 유지하고 정상적으로 스크롤한다.

- 달력의 `내 일정` 제목·안내 줄과 일정 추가 버튼을 제거한다. 날짜 클릭으로 개인 일정을 등록하고 기존 일정 클릭으로 수정·완료·삭제한다.
- 일정 카드에는 요약과 전체 건수를 표시하고 더보기로 불러온 전체 목록을 연다. 모든 일정 종류와 기존 오늘 처리할 일·지표·차트는 유지한다.
- 매입은 파란색, 판매는 초록색과 각각의 텍스트로 구분한다. 유효한 매입일을 표시하고 판매일은 판매완료 차량의 유효한 날짜만 표시한다. 거래일은 읽기 전용이며 개인 일정으로 저장하지 않는다.
- 날짜 칸에는 개인 일정과 차량 거래일을 합쳐 요약하고, 추가 건수와 목록에서 두 종류를 함께 확인한다. 개인 일정 서버 응답의 500건 제한과 정확한 건수/생략 안내는 유지한다.

차량 거래일은 이미 로드한 본인 차량만 읽으므로 추가 네트워크 요청이나 DB 변경이 없다. 날짜 전용 브리지는 차명·차량번호·날짜·판매 상태만 전달하고 금액·고객·메모·서류는 전달하지 않는다. 금액 잠금 중에도 거래일은 표시할 수 있으며 기존 금액 잠금을 해제하지 않는다.

차량 로드가 성공한 상사·계정·역할·클라이언트·화면 사용자·데이터 세대를 기록하고 현재 범위와 모두 일치할 때만 거래일을 전달한다. 기존 차량 출처 정보가 있으면 행의 상사·담당자·차량 ID·데이터 세대도 확인한다. 로그아웃과 범위 초기화 때 기록을 지워 이전 상사의 차량이 새 상사 달력에 표시되지 않도록 한다. 대표 계정도 본인 담당 차량만 대상이다.

검증은 가상 계정·차량·일정과 차단된 외부 네트워크 fixture로 수행한다. 데스크톱 1280×720, 1366×768, 1440×900에서 달력 크기·모든 카드 위치·문서 넘침·브라우저 배율을 확인하고, 모바일 360/390/430px에서 일정 편집·뒤로가기·입력 크기를 확인한다. 실제 휴대폰 키보드는 짧은 화면으로 모사한다. 기존 개인 일정 저장·충돌 처리·금융 잠금·정산 계산·문서 인쇄 동작은 유지한다.

실측은 장기 재고 3대와 각 분류에 여러 일정이 있는 상태에서 브라우저 배율 100%로 수행했다.

| --- | ---: | ---: | ---: | ---: |
| 1280×720 | 885px | 346px | 710px | 720px |
| 1366×768 | 885px | 346px | 726px | 768px |
| 1440×900 | 885px | 391px | 862.3px | 900px |

세 규격 모두 가로·세로 넘침 없이 모든 카드와 7개 요약 지표를 표시했다. 모바일은 카드·문서 읽기와 일정 편집을 위해 자연스러운 세로 스크롤을 유지한다. 기존 견적서 1쪽·계약서 2쪽의 인쇄 액션·서명·도장·A4 규격도 별도 가상 브라우저 fixture에서 확인했다.
