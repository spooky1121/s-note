# 수입차 공식 자료 조사 — 2026-11-06

`import-official.json`에 한국 공식 자료 19곳에서 확인한 77개 판매명 관측을 보관했다. 본문·PDF 직접 확인 73건, 공식 사이트 검색 발췌 4건이다. BMW 30, 벤츠 4, 아우디 7, 볼보 12, 폭스바겐 6, 토요타 14, 렉서스 4건을 포함한다.

판매명은 확인한 그대로 `grade`에 보관하며, `subgrade`를 임의로 나누지 않았다. 자료 기준월·출시일과 모델연식을 분리했다. 모델연식은 공식 발표에서 명확히 2026년식이라고 부르는 XC40 세 구성에만 기입했다. 연식이 비어 있다는 이유로 조사일의 연식을 채우면 안 된다.

BMW의 직접 읽을 수 있는 2026년10월 한국 가격표는 새 iX3 50 xDrive 구성을 포함한다. 이 이름을 기존 `iX3 G08` 세대와 자동으로 연결하면 안 된다. BMW 판매명에 엔진·구동·패키지가 같이 들어 있어도, 그것이 엔카의 세 단계 분류와 일치한다는 뜻은 아니다.

아우디 A5 공식 발표는 7개 출시 구성을 명시한다. 이 중 S5는 별도 모델로 보관했다. 옵션 패키지나 외관 테마를 새로운 세부등급으로 늘리지 않았다. 볼보의 Bright/Dark는 XC40처럼 공식 판매명에 붙은 경우 해당 이름을 보존한다.

토요타의 현재 Highlander 페이지에서는 PLATINUM을 직접 확인했고, 2023년6월 기준 제원표에서는 LIMITED도 확인했다. 과거 제원표 근거를 현행 판매 증거로 바꾸지 않는다. RAV4의 ‘5세대 하이브리드 시스템’은 차량의 세대 숫자와 다르다. 현재 Prius PDF에는 AWD XLE/XLE만 있어 검색에 남은 과거 LE 구성을 최신 본문에 있다고 기록하지 않았다.

렉서스 NX의 이전 PDF 주소는 검색에는 남아 있지만 직접 요청은 삭제 안내를 반환했다. 설정기는 로드 오류, 인증중고차 직접 본문은 JavaScript 안내만 반환했다. 따라서 NX 4건은 검색 발췌 단계로 두었으며 자동 병합 대상에서 제외한다. 미국·캐나다의 동명 트림을 한국 판매 구성으로 대체하지 않았다.

이 자료는 출처를 갖춘 별도 참고 자료집이다. 각 브랜드의 모든 과거 세대·연식·파워트레인·단종 트림을 포괄하는 마스터가 아니며, 원본 앱의 차량·고객·차종 DB를 변경하지 않았다. 모든 항목의 `mappingStatus`는 `review_required`이며 세대 매핑을 확정하기 전 운영 선택지로 자동 반영하지 않는다.
