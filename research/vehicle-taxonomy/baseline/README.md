# 기존 차종 번들 기준 자료

`catalog.json`은 v2.80 코드의 세 정적 배열을 실제 공개 목록 선택 규칙대로 합친 **1,615개 원본 레코드**다. 키·토큰·사용자 차량·고객·상사 DB는 포함하지 않는다. 원래 문자열과 출처 메타데이터를 보존하며, 관측된 API 자료나 새 조사 결과를 기존 자료로 오인하지 않도록 별도로 보관한다.

| 구분 | 전체 정적 자료 | 현재 국내 선택 목록 |
|---|---:|---:|
| 레코드 | 1,615 | 1,383 |
| 제조사 표기 | 46 | 46 |
| 모델군 | 491 | 480 |
| 세대·세부모델 | 1,197 | 1,089 |
| 등급이 하나 이상 있는 세대 | 211 | 103 |
| 등급을 아직 모르는 세대 | 986 | 986 |
| 등급이 있는 레코드 | 629 | 397 |
| 기존에 공식 확인으로 표시된 레코드 | 365 | 365 |
| 별도 세부등급이 있는 레코드 | 0 | 0 |

현재 국내 선택 목록은 `market=KR_REVIEW`인 참고 자료 232개를 제외한다. 따라서 전체 자료 수를 화면에서 선택할 수 있는 자료 수라고 표현하면 안 된다. 공식 확인 표시 365개도 **이전 코드의 표시를 그대로 집계한 값**이며 이번 추출에서 공식 문서를 다시 검증했다는 뜻은 아니다. 한 세대의 등급이 하나 있다고 모든 연식·동력계통·등급을 조사했다는 뜻도 아니다.

## 파일

- `catalog.json`: 출처 커밋·파일 SHA-256과 원본 레코드. 통합 조사 빌더의 기준 입력이다.
- `catalog.csv`: 동일 레코드와 현재 국내 선택 목록 포함 여부.
- `coverage.json`: 원시 배열 수, 중복, 시장 구분, 제조사별 범위와 확인 한계.
- `manufacturer-coverage.csv`: 제조사별 선택 가능 세대와 등급 누락 수.
- `missing-trims.csv`: 등급이 하나도 없는 세대 986건. 조사 우선순위 원장이다.
- `sources.csv`: 기존 출처 이름·주소별 관련 레코드 수. 이번에 재검증한 출처 목록은 아니다.
- `manifest.json`: 생성 파일의 바이트 수와 SHA-256.
- `generate-baseline.py`: 저장소 최상위의 `index.html`에서 다시 추출하는 도구. 런타임·운영 DB는 변경하지 않는다.

재생성 명령: `python research/vehicle-taxonomy/baseline/generate-baseline.py`

## 기존 데이터 결합 규칙

원시 배열은 `BUNDLED_CATALOG_V118` 1,493개, `HEYDEALER_PUBLIC_REFERENCES` 33개, `ZEROCAR_ADDED_MODELS_V194` 90개로 합계 1,616개다. `snote220PublicRows()`는 제조사·모델군·세대·등급·세부등급이 같은 행을 하나로 합친다. 먼저 나온 행을 보존하되 뒤의 공식 표시 행은 앞의 비공식 행을 대체할 수 있다. 혼다 어코드 10세대 1.5 터보가 중복되어 최종 1,615개가 된다. 해당 중복의 시장 구분이 다르므로 단순한 마지막 행 우선 결합은 현재 화면과 다른 결과를 만든다.

`domesticTaxonomy()`는 국내 시장 및 미지정 시장만 선택한 뒤 NFKC·공백·영문 대소문자를 정리한 5개 분류 필드로 다시 결합한다. 이번 기준 자료에서 이 단계의 추가 중복은 없다.

`taxonomyKey()`와 클라우드 차종 identity 모두 **연식을 독립 키로 쓰지 않는다**. 연식마다 다른 등급을 추가할 때는 기존 세대 명칭과 실제 적용 연식을 대조해야 한다. 연식이나 엔진이 다른 이름을 하나의 등급으로 임의로 합치면 안 된다. KGM/쌍용, 르노/삼성, 쉐보레/GM대우도 검토 대상 별칭이지 자동 통합 허가가 아니다.

기존 IndexedDB `mergeBundledCatalog()`는 사용자 입력과 기존 공식 자료를 보호한다. 공개 번들의 검증된 새 행을 추가하는 방식과 상사 공용 `zc_vehicle_taxonomy` 사용자 입력 저장은 별개다. 기존 CSV 가져오기는 모든 외부 행을 `source_unverified`로 처리하고 이 브라우저에서만 보관하므로, 공식 자료 배포나 공유 DB 저장을 대신하지 않는다.

## 완성도 판단 기준

범위를 정한 전체 제조사 목록, 세대·연식 범위, 동력계통, 등급·세부등급의 부모 관계와 원문 출처를 확인해야 전체 분류표 완성을 말할 수 있다. 현재 레코드의 개수나 매물 API에서 관측한 이름만으로 국내 전체 출시 등급의 전수 확보를 주장하지 않는다. 새 자료는 출처·시장·연식·검증 수준을 보존하고, 불명확한 부모 관계는 비워 둔다.
