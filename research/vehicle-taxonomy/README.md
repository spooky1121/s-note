# S-NOTE 차종 조사 자료집

자료집 갱신일: **2026-11-07, 한국시간 기준**. 국내 유통 중고차의 제조사·차명군·모델·등급을 보강하기 위한 별도 자료집이다. 출처별 실제 관측일은 원문 메타데이터를 따른다. 사용자에게 받은 실제 API 진단, 기존 번들, 제조사 자료, 공개 분류표와 해외 참고 원본을 각각 보관한다. 차량·고객·상사 공용 차종 DB는 수정하지 않는다.

통합 원문 관측은 **3,128행**이며 출처 원장에는 **563개 URL**이 있다. 관측행의 직접 출처는 470개이며, 나머지는 보강·목록·격리 원천 등으로 출처 문맥에 보존한다. 한국시장 문맥 2,974행과 해외시장 154행을 구분한다. 이 수치는 새로운 고유 판매등급 수가 아니다.

|---|---:|
| 제조사·공식 딜러·제조사 작성 배포본문 직접 관측 | 1,895 |

자동화 응답의 진위를 확인할 수 없는 44행과 SM5 시점 셀 충돌 1행, 총 **45행을 정상 관측에서 제외해 격리**했다. 제목과 본문이 충돌하는 원천 1개도 별도로 기록한다. 기존 자료 1,615행, API 매물 3건, 정부 인증 20행은 각각 보존한다. 46개 제조사 표기 중 39개에는 한국시장 관측이 있고 4개에는 해외 참고만 있다. KGM·르노코리아·쉐보레의 별도 표기 3개는 기존 표기와의 별칭 대조 대상으로 남아 있다. 테슬라와 지프도 한국 출시 원문 관측을 추가했다.

공개 모델 검색 화면에 표시된 **1,858행**도 표시 순서대로 전부 보관했다. 중복 이름·일반 ‘기타’가 있어 서로 다른 이름은 1,805개이며, 제조사·부모 코드가 모두 확인된 1,858개 독립 차종을 뜻하지 않는다. 별도 글로벌 원본은 **164개 제조사·2,649개 모델·7,217개 세대·30,535개 엔진**이며 한국 판매 확인 수에 합산하지 않는다.

정부 2026년 기준가격 **기본본과 재산정·추가산정 반영본 ZIP을 모두 사용자 첨부로 수신해 전량 보존·검증**했다. 기본본은 차량 관측 105,370행·개조 431행, 현행 반영본은 차량 관측 **105,383행·개조 431행**이다. 두 원본과 원문 JSONL·출처 행·자료형·해시를 분리 보관하며, 이 수치를 위 3,128개 조사행이나 새로운 판매등급 수에 합산하지 않는다.

**전 연식·단종 트림을 망라한 공식 전수 마스터는 아니다.** 전체 제조사 표기 46개를 조사 원장으로 관리하며, 실제 확인한 기록과 자료원만 발견한 브랜드를 구분한다. 세부 수치는 [통합 범위](exports/coverage.json)와 [제조사별 원장](sources/brand-source-ledger.json)에서 확인한다.

[최종 검토 보고서](bulk/encar-final-audit/FINAL_REVIEW.md)에 확인 범위·추가·교정·원천 충돌과 미대응 검토 목록을 정리했다. 전역 모델명 목록의 584개 미대응 표시는 제조사·부모 코드가 없는 이름 대조 결과이며 확정 누락 수가 아니다. 현재 엔카의 전체 검색 계층·모든 연식별 판매등급 완성을 의미하지 않는다.

## 자료 구분

### 실제 API 관측

[별도 원문](observations/encar-api.com-2026-11-06T13-57-31-629Z.json)은 사용자가 배포된 관리자 화면에서 얻어 제공한 진단이다. 확인 시각은 `2026-11-06T13:57:31.629Z`, 재확인 응답은 캐시이며 추가 호출은 0회, 원래 한도 100·잔여 98이다. 이번 조사에서 사용자 키를 읽거나 추가 API 호출을 하지 않았다.

세 매물은 현대 캐스퍼/인스퍼레이션, 그랜저 하이브리드(GN7)/캘리그래피, 더 뉴 그랜저 IG 하이브리드/캘리그래피다. 상세 분류 11개 필드는 첫 매물에 관한 한국어 3개와 영문·독일어 각 4개다. 번역의 `modelGroup`을 한국어 모델군 코드로 바꾸지 않는다. Badge를 두 단계로 쪼개거나 엔진·연식을 추정하지 않는다.

### 새 조사

- `official_direct`: 제조사 홈페이지·가격표·제조사 작성 배포자료 또는 출처가 구분된 공식 딜러 본문을 직접 확인한 **사실 기록**이다. 공식 5단계 분류 코드나 기존 번들과의 매핑 완료를 뜻하지 않는다.
- `official_search_excerpt`: 공식 원천의 검색 색인에서 확인했지만 본문 재조회가 완료되지 않은 자료다. 직접 확인 자료와 구분한다.
- `provider_catalog_direct`: 엔카 등 공개 분류표의 실제 부모 페이지·ENG/CLS 표를 읽은 관측이다. 원천의 자체 분류이며 제조사 공식 수입사양·모델연식·전체 등급 완성을 보증하지 않는다.
- `reference_direct`: 자동차 전문 참고자료의 본문을 직접 읽은 관측이다. 제조사 작성 원문과 구분하며, 편집 오류와 카탈로그 기준연도/MY 차이를 검토한다.
- `candidate`: 추가 근거가 필요한 후보다. 본문을 못 읽은 Tesla 후보 등은 원본 자료의 `unverifiedCandidates`에 따로 두고 검증 행에서 제외한다.
- `listing_observed`: 실제 API 매물에서 관측한 표기다. 단종·희귀 등급의 존재 여부를 판단하는 전수 자료가 아니다.
- `certification_observed`: 정부 인증표의 관측이다. 인증 보유자와 브랜드, 인증일과 모델연식, 인증명과 판매트림을 서로 구분한다. 이번 KENCIS 표본 20행은 공식 검색 색인을 읽은 것이며 직접 재조회는 502/시간 초과였다.
- `baseline_not_reverified`: 기존 정적 자료를 보존한 행이다. 기존의 공식 표시가 이번 재검증을 뜻하지 않는다.

뉴스와이어 자료는 제조사를 `publisher`, 배포 호스트를 별도로 기록한다. 공식 딜러 자료도 `sourceKind`에 표시한다. 자료에 쓰인 `group`은 S-NOTE에서 검토하기 위한 묶음이며 외부 공급자의 공식 부모 코드가 아니다.

공식 사이트 이외 호스트에 보관된 제조사 가격표는 인쇄된 작성자·한국시장·기준월을 확인하고 제3자 보관본이라는 한계를 적는다. 자동화 요청에 합성·변형 응답을 줄 수 있다고 명시한 카위키 자료는 44행 모두 격리했다. 원문의 일부 사양 오류도 대조해 제외하거나 미확정 상태로 남겼다. `officialResearch`라는 JSON 키와 `official-research.*` 파일명은 기존 도구와의 호환용 이름이며, 모든 행이 제조사 공식 자료라는 뜻은 아니다.

### 기존 자료

전체 1,615행·46개 제조사 표기·1,197개 모델/세대를 보존했다. 현재 국내 선택 목록은 `KR_REVIEW` 232행을 제외한 1,383행·1,089세대다. 기준 자료에서 등급이 하나도 없는 세대는 986개다. 새 조사에는 같은 이름의 재확인·파워트레인·옵션·변속기별 관측이 포함되므로 조사 행 수를 그대로 신규 등급 수로 세거나 986에서 차감하지 않는다.

이 986개는 전부 추적한다. 빈 등급이 별도 판매트림의 존재를 뜻하지 않는 모델 파생형도 있다. 모델명 직접 일치나 같은 차명군 자료가 있어도 해당 세대의 전 연식·엔진·트림을 모두 확보했다고 처리하지 않으며 각 행의 전수 확인 상태는 `not_attested`다.

[기준 자료 설명](baseline/README.md)에 원본 상수, 중복 제거, 파일 해시와 시장 구분이 있다. KGM/쌍용, 르노코리아/삼성, 쉐보레/GM대우 표기를 임의 병합하지 않았다.

### 정부 차량 형식·기준가격 원본

[기본본](bulk/government-tax-2026/base/)은 행정안전부 고시 제2025-83호(2025-12-29, 2026-01-01 시행), [현행 반영본](bulk/government-tax-2026/amended/)은 제2026-37호(2026-05-27 제정·시행, 홈페이지 게시 2026-07-06)의 별표에 해당하는 사용자 제공 사본이다. 두 ZIP을 `source-original.zip`으로 각각 보존했다. 공식 공고·첨부 이름과의 대응은 확인했으며, 별도로 내려받은 공식 서버 파일과 바이트·해시를 대조한 것으로 표시하지 않는다.

반영본은 전체 대체 자료다. 43개 시트 중 차량 28개·개조 15개를 모두 읽었고, 차량 신규 16행·삭제 3행·가격만 변경 2행을 대조했다. 내용은 그대로이고 연번·행만 이동한 51,048행은 변경에서 제외했다. 외산 친환경 승용 형식 시트의 TESLA Model 3 Premium Long Range RWD는 원문 연번이 비어 있어도 완전한 차량 관측으로 보존한다. 연번 숫자 행 105,382개와 이 행 1개를 합쳐 105,383행이다.

워크북 43개 시트에 표시된 단위는 모두 **천원**이다. 원문 가격·단위·숫자/문자 자료형을 남기고 `Decimal`로 원 단위를 계산한다. 소수 표현 오류가 있는 원가격 2행은 정확한 계산값과 검토용 반올림 후보를 함께 남기며 확정 정수 원 값은 비워 둔다. 개조가격의 `-`·`－` 33개도 0으로 바꾸지 않는다. 이 금액은 **지방세 기준가격**이며 차량 판매가격·소매가격으로 사용하지 않는다.

형식·기종명·제작사 표기는 판매 모델·세대·등급 계층과 목적이 다르다. 자료 연도 2026을 각 차량의 모델연식으로 복사하지 않으며, 동일 제작사·형식에 여러 차명이 있어도 원문을 합치지 않는다. [후보 대조 원장](bulk/government-tax-2026/crosswalk/amended-2026-reviewed/target-ledger.json)과 [기존 조사 비교](bulk/government-tax-2026/crosswalk/research-comparison-amended-2026/)는 근거를 찾기 위한 연결이며 등급 확정이나 자동 가져오기 승인이 아니다.

| 현행 정부 자료 대조 대상 | 이름 후보 있음 | 가족·시리즈 단서만 | 해당 후보 없음 |
|---|---:|---:|---:|
| 기존 모델/세대 1,197개 | 248 | 880 | 69 |
| 그중 등급 공백 986개 | 211 | 721 | 54 |

후보 연결 300,616건은 같은 이름·차명군·형식의 검토용 연결을 모두 보존한 수다. 기존 개별 출처 조사에서 해당 근거를 못 찾았던 437개 중 391개에 정부 자료 단서가 있고, 양쪽 모두 단서가 없는 대상은 46개다. 이 대조로 확정한 판매등급과 전수 완료 항목은 **각각 0개**다. 원장별 구분·검토 사유는 [현행 요약](bulk/government-tax-2026/crosswalk/amended-2026-reviewed/summary.json)을 따른다.

공식 고시의 별표라는 사실과 출처·시행일을 기록한다. ZIP 전체를 공공누리 1유형으로 표시하지 않으며, 정부 자료의 권리 근거를 글로벌 ODbL 자료나 다른 공급자 자료에 확장하지 않는다. 자세한 원본·검증·권리 범위는 [대규모 자료 설명](bulk/README.md)과 각 원본 매니페스트를 따른다.

## 중요한 대조 결과

캐스퍼의 공식 가격표는 기본 1.0 가솔린과 액티브Ⅰ/Ⅱ의 터보 엔진 선택을 구분한다. ‘인스퍼레이션’ 단독으로는 일반·터보를 결정할 수 없다. 새 자료는 옵션임을 보존한다.

더 뉴 그랜저 IG 하이브리드의 2.4 하이브리드 프리미엄·익스클루시브·캘리그래피는 제조사 작성 2019년 배포본문으로 확인했다. 보관 가격표의 르블랑은 별도 시점 근거로 보존한다. 출시일이나 가격표 발행일을 모델연식으로 복사하지 않는다. 같은 Model Y 퍼포먼스라도 2021년과 2024년 발표 관측은 sourcePublicationDate로 분리해 보존하며, 두 발표연도를 모델연식으로 간주하지 않는다.

BMW의 새 iX3 명칭을 기존 G08에 붙이지 않으며, 한국 GMC 허머 EV SUV의 2X에 해외 3X를 복사하지 않는다. JLR의 `2025.5` 연식과 MINI의 특정 2024년형 각주도 원문대로 보존한다.

## 재생성과 추가 보관

```sh
# 새로운 정제된 진단 JSON을 분류 근거만 골라 별도 보관한다.
node scripts/archive-taxonomy-probe.mjs /path/to/diagnostic.json

# 기존 번들 기준 자료는 필요할 때만 재추출한다.
python research/vehicle-taxonomy/baseline/generate-baseline.py

# 출처·연료·연식·옵션·좌석·변속기를 보존해 CSV/JSON을 다시 만든다.
python scripts/update-vehicle-brand-source-ledger.py
node scripts/build-vehicle-taxonomy-research.mjs
python scripts/build-vehicle-gap-ledger.py
# 대조표를 포함한 최종 파일 해시 갱신
node scripts/build-vehicle-taxonomy-research.mjs

# 원문 보존, 분류 혼합 방지, 파일 해시와 CSV 안전성을 검사한다.
node tests/vehicle-taxonomy-research.test.mjs

# openpyxl이 있는 검토 환경에서 선택적으로 엑셀 자료집을 만든다.
python scripts/export-vehicle-taxonomy-workbook.py /path/to/research.xlsx

# 두 검색 DB를 별도로 생성한다. 운영 서버에 접속하지 않는다.
python scripts/export-vehicle-research-databases.py /path/to/databases
python scripts/verify-bulk-vehicle-references.py

# 정부 현행 반영본을 별도 검색 DB/정리 CSV로 재생성·검증한다.
python scripts/build-government-tax-2026.py --input-dir research/vehicle-taxonomy/bulk/government-tax-2026/amended --output-dir /tmp/snote-government-amended
python scripts/verify-government-tax-2026.py --database /tmp/snote-government-amended/government-tax-2026.sqlite --expected-vehicle-rows 105383 --output /tmp/snote-government-amended/acceptance-checks.json
```

같은 시각의 기존 진단 파일을 다른 내용으로 덮어쓰지 않는다. 새 출처는 `sources/`에 독립 JSON으로 추가하며 출처 URL·조회일·직접/색인 확인·불명확한 항목을 기록한다. 통합 JSON은 원본 행을 `sourceRecord`와 복수 `evidence`에 보존한다. `researchId`는 내부 중복 확인용 해시이며 공급자 분류 코드가 아니다.

## 남아 있는 범위

전체 연식·엔진·단종 트림과 단계별 부모 관계를 보증하는 원천은 이번 조사에서 확보하지 못했다. [자료원 조사](sources/master-source-survey.md)는 현재 공급자의 매물 조회, 별도 공급자의 활성 매물 CSV, 정부 통계·연비·인증 데이터의 범위를 구분한다. 별도 공급자에 기존 키를 보내지 않았다.

국내 세대와 연식에 대한 연결이 불명확한 기록은 검토 상태를 유지한다. 이미 입력된 차량 분류·사용자 직접 입력·고객 데이터·금액 계산에 조사 자료를 자동 적용하지 않는다.

정부 기본본·현행 반영본은 원본 보존과 전량 대조를 마쳤다. 이후 작업은 [후속 작업 안내](CONTINUE_RESEARCH.md)에 따라 정부 차명·형식 후보를 기존 세대·연식·엔진·등급 근거와 교차 검토하는 것이다. 서울시 차량 CSV 등 별도 자료도 추가 대조 원천으로 사용할 수 있다. 이번 자료집은 GitHub에 보관하며 운영 앱 v2.80·차량·고객·상사 DB와 분리하고 Cloudflare 앱 배포는 수행하지 않는다.
