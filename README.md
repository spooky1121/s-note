# S-NOTE

**중고차 매매상사 통합 전산 관리 시스템**

S-NOTE는 중고차 매매상사를 위한 온라인 업무 관리 서비스입니다.

## 주요 기능

- 차량 매입 및 재고관리
- 차량 판매 및 계약서·인수증 관리
- 고객정보 및 판매이력 관리
- 재고금융 및 선재고 관리
- 수익·정산 및 월별 회계관리
- 차량 사진·등록증·성능점검기록부 관리
- 온라인 회원가입 및 직원별 권한 관리
- 문자 인증번호 확인을 거친 고객 휴대폰 정보 입력·서버 접수
- 엑셀 결산표형 월정산 입력·자동 저장·CSV 및 인쇄 출력
- 상단 프로필 옆 계산기·키보드 사칙연산
- 직접 입력한 차종의 상사 공용 DB 저장·다음 등록에서 재사용
- 판매 완료 차량별 카드형 소득정산·실시간 자동 계산·서버 저장·인쇄/PDF
- 차량 목록의 외장색 표시·고객 휴대폰 서명의 판매 계약서 반영
- 판매 완료일 기준 월별 조회·이번 달 기본 표시
- 차량 상세의 엔카 공개 목록 조회·전체 차량번호와 광고 상태 검증·복수 광고 선택·알고 있는 광고 주소 재검증

고객 휴대폰 입력 기능의 문자 서비스 준비, 서버 설정, DB 적용과 개통 시험은
[고객 입력 운영 절차](docs/customer-intake-setup.md)를 따릅니다.

월정산의 계산 기준과 저장·출력 방식은 [월정산 결산표 안내](docs/monthly-workbook.md)를 확인하세요.
상단 계산기의 조작법과 백분율 계산 방식은 [계산기 안내](docs/quick-calculator.md)를 확인하세요.
직접 입력 차종 공유에는 [차종 DB 적용 안내](docs/vehicle-taxonomy-setup.md)의 SQL을 한 번 실행합니다.
차량별 소득정산의 자동 입력 항목과 원본 수식 기준은 [소득정산 안내](docs/income-settlement.md)를 확인하세요.
목록 색상과 계약서 서명 표시는 [차량 색상·고객 서명 안내](docs/vehicle-colors-and-signatures.md)를 확인하세요.
판매 완료 목록은 한국 시간의 이번 달로 시작합니다. 이전·다음 달, 이번 달 버튼과 월 선택으로 조회하며, `전체 기간`에서는 과거 전체를, `판매일 확인 필요`에서는 날짜가 없거나 올바르지 않은 기록을 확인합니다. 검색·담당 딜러 조건도 함께 적용됩니다. 과거 날짜로 판매를 확정하면 해당 판매 월을 열어 방금 저장한 차량을 표시합니다.

차량 상세의 엔카 광고 연결 방식, 서버 설정과 검증 범위는 [엔카 인계 문서](docs/ENCAR_CODEX_HANDOFF.md)를 확인하세요. 공개 GET 검색 폼을 인식하면 번호 끝 4자리로 목록을 조회하고 같은 카드의 전체 번호를 대조한 뒤 엔카 공식 상세를 검증합니다. 지원하지 않는 폼이나 카드 구조는 오류로 구분합니다. 자동 검색에서 확인되지 않으면 알고 있는 광고 주소를 입력해 같은 서버 검증을 받을 수 있습니다. 검색 실패·차단·시간 초과를 매물 없음으로 표시하지 않으며, 저장된 매물 ID도 열기 전에 다시 검증합니다. 오류가 계속되면 개인정보 없는 `진단 정보 복사`로 조회 단계를 확인합니다.

## 서비스 운영

- **서비스명:** S-NOTE
- **새 도메인:** https://s-note.kr (구매 완료, 연결 준비 중)
- **현재 접속:** https://s-note.pages.dev
- **웹 호스팅:** Cloudflare Pages
- **데이터베이스:** Supabase PostgreSQL
- **파일 저장:** Supabase Storage

새 주소의 DNS·Pages·이메일 인증 설정과 기존 주소 보존 절차는 [도메인 연결 안내](docs/custom-domain-setup.md)를 확인하세요.

현재 온라인 테스트 및 정식 서비스 구축을 진행하고 있습니다.

[백업과 재해 복구 안내](docs/backup-recovery.md)를 확인하세요.
