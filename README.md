# S-NOTE

**중고차 매매상사 통합 전산 관리 시스템**

S-NOTE는 중고차 매매상사를 위한 온라인 업무 관리 서비스입니다.

## 주요 기능

- 차량 매입 및 재고관리
- 차량 판매 및 계약서·인수증 관리
- 고객정보 및 판매이력 관리
- 재고금융 및 선재고 관리
- 수익·정산 및 월별 회계관리
- 차량 사진·등록증·성능점검기록부 관리
- 온라인 회원가입 및 직원별 권한 관리

## 서비스 운영

- **서비스명:** S-NOTE
- **공식 홈페이지:** www.s-note.co.kr (준비 중)
- **웹 호스팅:** Cloudflare Pages
- **데이터베이스:** Supabase PostgreSQL
- **파일 저장:** Supabase Storage

현재 온라인 테스트 및 정식 서비스 구축을 진행하고 있습니다.
